# NeNe Nib 1.1.0 とメモ帳・サクラエディタの比較（2026-11-23）

README の比較表の元の記録。3 本を同じ条件で、外から同じ方法で測った。

## 結果

速さは各 20 回、メモリは各 10 回の中央値。

| 項目 | NeNe Nib 1.1.0 | サクラエディタ 2.4.3 | Windows メモ帳 11.2609.11.0 |
|---|---:|---:|---:|
| 200 行のファイルで起動して本文が出るまで | **100 ms** | 267 ms | 450 ms |
| 16 MiB のファイルを開いて本文が出るまで | **117 ms** | 383 ms | 908 ms |
| 200 行を開いた後の実メモリ（private working set） | 14.1 MiB | **11.6 MiB** | 40.4 MiB |
| 16 MiB を開いた後の実メモリ（private working set） | **30.4 MiB** | 54.2 MiB | 88.7 MiB |
| 配布一式の大きさ | **4,752,188 B** | 5,616,203 B | 18,548,838 B |
| exe の大きさ | 4,571,648 B | **2,264,064 B** | 3,212,128 B |

- サクラエディタの常駐プロセスを先に起動しておくと、本文が出るまでは 200 行で 217 ms、16 MiB で 325 ms だった。
- サクラエディタのメモリは、エディタ本体と常駐プロセスの合計。
- サクラエディタの配布一式は公式のポータブル版（Win32）。約 2.0 MB のヘルプを除くと 3,609,920 B で、Nib より小さい。
- メモ帳の配布一式には、別途必要な Windows App Runtime と VCLibs を含まない。
- 比較ショートの 133 ms と 983 ms は、録画しながら撮った 5 テイクの中央値で、この表の 117 ms と 908 ms より負荷が大きい。

## 条件

- 機械: Windows 11 Pro（build 26300）、Intel Core i9-10850K、RTX 3090、3840×2160。この 1 台だけの結果。
- 3 本ともインストール直後の初期設定。Nib の言語サーバーは既定のオフ。
- 表示領域を 1584×892 にそろえた。起動直後に外部のフックで同じ大きさへ変えている。
- ファイルは UTF-8、改行 LF、日本語を含む `.txt`。OS のキャッシュに載った状態。
- 各 exe を直接起動した。Store のアイコンからの起動は測っていない。

## 測り方

- 速さ: 操作の直前に画面の目印を白くし、画面を 60 fps で録画して、目印から本文が出たコマまでを数えた。判定は各アプリのウィンドウの中だけ。1 コマは約 17 ms。
- メモリ: 開いて落ち着いた後に `GetProcessMemoryInfo` の `PrivateWorkingSetSize` を読んだ。GPU のメモリと共有メモリは含まない。
- Nib は 64 MiB 以下のファイルを同期で全文読み、改行の索引まで作ってから文書を採用する（[ADR 0159](../adr/0159-documents-open-through-one-read-port-that-completes-on-the-worker.md)）。16 MiB の本文が出た時点で全文は読み込み済み。

## 確かめていないこと

他の PC、NVIDIA 以外の GPU、OS のキャッシュに載っていない読み込み、言語サーバーやミニマップを有効にした Nib、1 打鍵の反応。
