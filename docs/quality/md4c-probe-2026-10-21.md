## 4. text pointer が入力バッファの中を指すか

判定は `text >= input && text + size <= input + size_of_input`。

| 入力 | 種類 | 中 | 外 |
|---|---|---|---|
| (i) 16 MiB | `MD_TEXT_NORMAL` | 771,878 | **0** |
| | `MD_TEXT_SOFTBR` | 0 | 96,056 |
| | `MD_TEXT_CODE` | 123,499 | 82,332 |
| (ii) 16 MiB | `MD_TEXT_NORMAL` | 206,488 | **0** |
| | `MD_TEXT_SOFTBR` | 0 | 154,866 |
| 小さな文書（`&amp; &lt; &#x41; &#65; &copy; &nbsp;`・`\` のハードブレーク・2 空白のハードブレーク・`\*` `\_`・code span・HTML block・NUL 1 個） | `MD_TEXT_NORMAL` | 19 | **0** |
| | `MD_TEXT_ENTITY` | 6 | 0 |
| | `MD_TEXT_CODE` | 1 | 0 |
| | `MD_TEXT_HTML` | 1 | 1 |
| | `MD_TEXT_BR` | 0 | 2 |
| | `MD_TEXT_SOFTBR` | 0 | 4 |
| | `MD_TEXT_NULLCHAR` | 0 | 1 |

- **`MD_TEXT_NORMAL` は全件が入力の中**（3 文書で外 0）。`\*` のような escape も入力の部分列として渡る。
- `MD_TEXT_ENTITY` も入力の中（`&amp;` の生の綴り。復号は受け手の仕事）。
- 外を指すのは md4c の静的な文字列: `BR` / `SOFTBR` は `_T("\n")`（md4c.c 4485 行）、`NULLCHAR` は `_T("")`（402 / 4426 行）、
  `CODE` / `HTML` の外は各行の末尾の `_T("\n")` と字下げの `indent_chunk_str`（4714〜4740 行）。(i) の CODE の外 82,332 はこの行末と字下げ。
- 帰結（推測）: 位置の対応（プレビュー ↔ 本文のオフセット）は `MD_TEXT_NORMAL` と `ENTITY` と CODE の本体の行から `text - input` で引ける。
  BR/SOFTBR/NULLCHAR と CODE/HTML の行末は入力の位置を持たないので、直前の text の終わりから位置を補う必要がある。
