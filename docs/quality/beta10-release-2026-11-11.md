## 主な変更（beta.9 `5cc9ffad` から・公開の文に使う）

使う人に見える変化:

- **窓の × □ ＿ は押した要素と離した要素が同じときだけ動かす**（#1464）: `WM_NCLBUTTONDOWN` / `WM_NCLBUTTONDBLCLK` で押した窓の操作を覚えて `SetCapture` し、`WM_LBUTTONUP` か `WM_NCLBUTTONUP` で同じ要素のときだけ動かす。ボタンから外して離すと取り消し・外で押してボタンの上で離しても何もしない（Windows の標準）。「落ちた」の正体の直し。
- **ミニマップの命令の失敗では窓を閉じない**（#1449）: bitmap の道を捨てて直接描き、それでも失敗なら面を出さない。bitmap は `GetMaximumBitmapSize` に収まるときだけ作る。device lost と本文の失敗は今までどおり。
- **起動画面**（D70・ADR 0172・#1442 段 1 / #1455 段 2）: ファイルも前回のタブも無い起動で、空の文書の面に題・最近のファイル 10 件・ブックマーク 10 件（最初の frame の後に裏で 1 回読む）・新しいファイル / ファイルを開く / フォルダを開く・主な鍵。↑ ↓（Vim の NORMAL では `j` `k`）で選び、Enter かクリックで実行。
- **エクスプローラーの見た目の案 B**（D81・#1390）: 帯とつながる面・構文の色の点・UI の字体・行 22 DIP 固定。
- **プレビューのタブ**（D83・ADR 0179・#1397）: 面のクリック 1 回で開いたタブは題名が斜体で、次のクリックで同じ帯の位置を置き換える（履歴に書かない）。未保存になった・保存の成功・面のダブルクリックと Enter・題名のダブルクリック・明示の開くで固定。
- **ルートのフォルダ選びの箱に WSL の場所**（#1450）: 入れ終わったディストリを `\\wsl.localhost\<distro>` として最大 16 件（Docker の内部の 2 つは外す）。読むのは箱を出すときだけ。
- **Markdown プレビューの画像**（D79・ADR 0155）: 段 2（#1412・`Win32Worker` の上で読み WIC で復号し長辺 2048 に縮める・16 MiB まで）と段 3（#1439・`ID2D1Bitmap1` にして本文の流れの中に描く・読む前と失敗は「[画像: alt]」）。
- **通常モードは Windows の標準へ**（D82）: Ctrl+← → の語の境をメモ帳の実測に合わせ、Ctrl+Backspace / Ctrl+Delete を足す（#1394・語の境は core の `ordinary_word_boundary` の 1 本・キャレットの周りの窓だけを読む）。選択があるときの Shift なしの矢印は選択の端から動く（#1393・← は先頭・→ は末尾へ畳む・↑ Home PgUp は先頭、↓ End PgDn は末尾の画面行から）。
- **Vim の VISUAL**: `J` `gJ` `X` `D` `Y`（#1417・矩形の `D` は行末まで）と `C` `R` `s` `I` `A`（#1436）を Vim 9.1 の実測どおりに。
- **再生の上限**（D75・#1351）: いちばん外の `.` `@` が流す鍵は 100,000 で止めて残りを捨て、1 行「再生を 100,000 鍵で止めました（残りは捨てました）」。

## 既知の限界（各 PR の「残るリスク」から）

- 語の境（#1394）: メモ帳は漢字を辞書で切るが Nib は漢字の連なりを 1 語にする。選択があるときの Ctrl+Backspace / Ctrl+Delete は選択を消す（メモ帳の engine は選択を残す）。入力行（検索・置換・Ctrl+P・`:`）の Ctrl+Backspace / Ctrl+← → は語の単位で効かない。
- 選択中の矢印（#1393）: PgUp / PgDn の起点と折り返しの境目の形は Windows で測っていない（設計席の決め）。
- 画像（#1412 #1439）: 枠より高い画像の下は見られない（#1446）。ネットワークドライブ・オンラインのみのファイルで worker が止まりうる（#1430）。EXIF の向き・色の profile は見ない。書いている途中の PNG は欠けた画像として出ることがある。速さ（ゲート・probe）は画像のある文書では測っていない。
- プレビューのタブ（#1397）: 帯の題名のダブルクリックと斜体の見た目は試用で確かめる。読みの途中で打鍵と重なると新しいタブがアクティブになることがある（本文は失わない）。
- エクスプローラーの見た目（#1390）: 背景が黒のテーマ 12 本では載せた行・帯と面の L 字・角が見えず、ライトのテーマでは線が薄い（採用案の限界）。
- WSL の場所（#1450）: 箱の左の一覧に実際に出るか・名前とアイコン・VM が起きる時間は試用で確かめる。
- 起動画面（#1455）: 選んだ行の印 ▸ が小さく見える・履歴の行が出ると下の節が動く。`eng/verify-window.py --start-screen` は書いただけで回していない。起動画面と案内を同時に描かないことの機械の検査は planned。
- 窓の操作（#1464）: × □ ＿ を押したままタブや面の行の上を通ると hover が付く。タッチとペン・Snap Layouts・最大化の途中の DPI の変化は確かめていない。`eng/verify-window.py --caption` は CI の必須 check ではない。
- ミニマップ（#1449）: 実機の GPU での描き直しの道は試験が通っていない（読みだけ）。ミニマップのクリックとドラッグは後続。
- 再生の上限（#1351）: 行が伸びる中身（`ix<Esc>`）は上限の内でも長くかかる（#1451）。`map` の右辺に `@a` を並べると数が 0 に戻る。
- Vim の追従（#1363 #1300）: `@` の再生の中で NORMAL の移動の後に来る INSERT は歩かない（#1433）。`:set so=N` の後の決め直しの差（#1432）。
- VISUAL（#1417 #1436）: 3 行以上をつなぐ `J` の中の行のマーク（#793）・VISUAL の `S`（surround #1001 まで何もしない）・VISUAL の `p` `P` の後の桁（#1418）。
- 巨大な 1 行のテキストオブジェクト（#1424）: 16 MiB・空白なしの `iw` `aw` は線形だが 1 文字ずつ後ろへ歩く（#1441）。

## 公開の手順

1. main の detached 作業木で梱包: `pwsh -NoProfile -File eng/package-release.ps1 -Beta 10 -OutputDirectory D:/NeNeNib/releases/v0.1.0-beta.10 -Verification docs/quality/beta10-release-2026-11-11.md`（作業木 `D:/NeNeNib/worktrees/beta10`・HEAD は origin/main と一致・未追跡 0・出力先のフォルダは道具が作る）。
2. 展開した exe の smoke（隔離 profile・`D:/NeNeNib/evidence/beta10-release/release-smoke.py`）。速さは根拠 (a) のまとめ枝 19 の木の 1 回を再利用する（梱包の exe では測らない）。
3. 同じ commit に annotated tag `v0.1.0-beta.10` と GitHub pre-release（zip と SHA256SUMS・本文は `D:/NeNeNib/evidence/beta10-release/release-notes.md`）。`publish.ps1` を設計席が実行する（`$commit` と本文の配布元の `@COMMIT@` を公開元の SHA に埋めてから・打つ前に構文だけ先に確かめる）。
4. `gh release download` で再取得し、tag の commit・bytes・digest を照合（`verify-publication.py`）。
