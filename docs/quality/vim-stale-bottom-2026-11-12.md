# `zb` `z-` の後の古い下端（#1483・2026-11-12）

ADR 0146 の #1483 の追補の実測の全文。Vim 9.1.0004（`C:\Program Files\Vim\vim91\vim.exe`・`--not-a-term`・`set nowrap`）と、`origin/main` `03983654` の Debug の再生器 `nib_vim_replay` を比べた。

- 本文は `1`〜`30` の番号だけの 30 行（F だけ 8 行）。窓は高さ 12。各行の「先頭・行」は鍵の前の窓の先頭とキャレットの行（桁は 1）。`so` は `set scrolloff=`。
- **1 本の `:normal!`** は oracle（`eng/vim-oracle.py` の `run_vim`）と fuzz の形で、鍵の列を 1 回の `:normal!` で流す。
- **鍵ごとに描く** は、鍵の列を 1 命令ずつの `:normal!` に分け、間に `redraw!` を挟んだ形（対話の Vim が鍵ごとに描くのに当たる）。
- **Nib** は 1 本の `:normal!` の期待値を入れた再生器の答え（違った欄だけ再生器の値・ほかは期待値と同じ）。
- 値は「行 / 先頭」。`≠束` は 1 本の `:normal!` と違う、`≠対話` は鍵ごとに描く Vim と違う。
- 測れなかった 13 件（`so` が大きいときに初めの窓が余白を満たさず oracle の置き方が拒んだ形）は「拒否」と書いた。
