## 置き方

| 要素 | 値 |
|---|---|
| 右に並べる（案 A・広い窓の既定） | 面の幅 min(1000 DIP, 窓の幅 − 32 DIP)・上 96 DIP（今と同じ）。入力 52 DIP・当たりの欄 400 DIP × 行 40 DIP × 最大 8・その右がプレビュー欄（高さは行の欄と同じ）・下 34 DIP |
| 下に開く（案 B・細い窓と手で選ぶ形） | 面の幅 640 DIP（今と同じ）。当たり最大 5 行・その下にプレビュー欄（見出し 28 DIP ＋ 残りの高さ） |
| なし | 今の面のまま |
| 自動 | 右が入れば右（プレビュー欄の幅 360 DIP 以上 = 窓の幅 792 DIP 以上）・入らなければ下（当たり 3 行 ＋ プレビュー 6 行が入る）・入らなければなし |
| 手の切り替え | 面が開いている間の Ctrl+Shift+P・見出しの右端の印。順は 右 → 下 → なし → 右。選んだ形は設定に覚える。手で右を選んでも、入らない窓ではその場だけ下 |
| 欄の境 | 当たりの欄とプレビュー欄の間に 1 DIP の `panel_border`（右）・プレビュー欄の上に 1 DIP の `panel_border`（下） |

## プレビュー欄

| 要素 | 値 |
|---|---|
| 地 | `background`（本文の色） |
| 見出し | 高さ 28 DIP・左右 14 DIP・下に 1 DIP の `panel_border`。名前は `text` の semibold・場所（フォルダ）と「412 行目」と言語は `muted`・11.5 DIP |
| 本文 | 本文と同じ族の字体・12.5 DIP・行の高さ 19 DIP・上下 6 DIP。行番号は幅 40 DIP の右寄せ ＋ 14 DIP の空き・`gutter` |
| 当たりの行 | `current_line` の面・行番号は `text`。当たりの文字は `search` の面 ＋ `accent` の 1 DIP の枠（D17） |
| 窓 | 全文検索の当たりは、その行の前 7 行から。ファイルとタブは先頭から。行は折り返さず、はみ出しは切る |
| 届くまで | 見出しだけ新しい候補のもの・本文は空（前の中身を残さない） |

## 待ちの間の演出（解読）

| 要素 | 値 |
|---|---|
| 出る所 | 見えている行のうち、まだ当たりが届いていない行だけ。届いた行・プレビュー欄・入力欄には出さない |
| 出る時 | 探し始めてから 200 ms を超えて、まだ探している間だけ。速く終わる検索では 1 回も出ない |
| 乱れた文字 | 半角カタカナ・数字・記号（`ｱｲｳｴｵｶｷｸｹｺｻｼｽｾｿﾀﾁﾂﾃﾄﾅﾆﾇﾈﾉ0123456789#$%&=+<>/`）。色は `gutter`・不透明度 55%。40 ms ごとに入れ替わる |
| 解ける | 当たりが届いた行は左から本物の文字になる。境の 1 字だけ `accent`。1 行 200 ms 以内。**届いた瞬間から選べて開ける** |
| 走査の線 | 無し（施主が外した） |
| 止める | Windows の「アニメーション効果」がオフ・設定 `finder_effect=off`。そのときは入力欄の右の文だけ |

速さの数字（40 ms・200 ms）は、キャンバスで施主が見た版（1 行 約 0.4 秒）よりさらに短くしてある。実機で見て決め直す。

## 置き場（実装で足すもの・ADR 0189）

配置は core の `palette_layout`（置き方の値を受ける）、乱れた文字は core の `finder_noise`、窓は application の `PreviewSnippet` と `PreviewPort`、描画は ui の `PreviewPanePainter`。
