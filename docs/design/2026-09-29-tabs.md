## 3. 寸法（DIP）

| 部位 | 値 |
| --- | --- |
| タブの幅 | 空きをタブの本数で割った値を 120〜200 に収める。あふれたら 120 に固定 |
| タブの高さ・上の余白・タブ間・帯の左余白 | 32・8・2・8（2026-09-15 のまま） |
| タブの内側の余白 | 左 14。× があるときは右 6、無いときは右 14 |
| 入りきらない題名 | 文字単位で切って末尾に「…」（題名の領域は左の余白から × の左端まで。× が無ければ右の余白まで） |
| × の領域 | 24 × 24・角丸 4・記号 10。タブの右端から 6 |
| 「∨」と「＋」 | 各 32 × 32・記号 10（2026-09-15 の「＋」のまま。画は 12 で描いたが、タブ 1 本のときの見た目を変えない）・マウスを載せたときの面の角丸 4（× と同じ） |
| 掴む余白（「＋」と窓の操作の間） | 40 以上 |
| 窓の操作 | 46 × 3（2026-09-15 のまま） |
| ホイール 1 刻みの送り量 | タブ 1 本ぶん（122 = 幅 120 ＋ 間 2） |
| 窓の最小の大きさ | 幅 360 × 高さ 200（タブが 1 本であふれない幅。360〜420 では 1 本のタブが 140〜200 に縮む） |

## 4. 色

| 状態 | 面 | 文字 |
| --- | --- | --- |
| アクティブなタブ | `tab_active` ＋ 下線 2（`accent`） | `text` |
| 非アクティブなタブ | なし（帯の `title_bar` のまま） | `muted` |
| マウスを載せた非アクティブなタブ | `tab_hover`（新しいトークン・ダークは #27071D。画は #2A0B20 で描いた） | `text` |
| × ・「∨」・「＋」にマウスを載せたとき | `toggle` | 変えない |
| 未保存の印 | 題名の先頭の「● 」（今のまま） | タブの文字の色 |

`tab_hover` は `title_bar` と `tab_active` の各成分の平均（切り捨て）。組み込みの 9 テーマは値を持ち、ユーザーテーマは省略できる（省略時は `tab_active`）。

## 5. 操作

| 操作 | 結果 |
| --- | --- |
| タブをクリック | そのタブへ切り替える（押したとき） |
| 押した要素と離した要素が違う | 何も起きない（× と「＋」と中ボタンは離したときに動き、押したときと同じ要素の上で離したときだけ効く） |
| × をクリック・タブを中ボタンでクリック・Ctrl+F4 | そのタブを閉じる（未保存なら「保存しますか」） |
| Ctrl+W | 通常モードでは閉じる。Vim モードでは何もしない |
| 「＋」をクリック・Ctrl+T | アクティブの右に空の「無題」を足して切り替える（入力行が開いている間の Ctrl+T は検索の移動のまま） |
| Ctrl+Tab / Ctrl+Shift+Tab | 最近使った順で次 / 前のタブ（Ctrl を押している間は順を固定して歩き、離したときに確定・端は折り返す・D23・ADR 0058） |
| `gt` `gT`・`:tabnext` `:tabprevious` | 帯の位置の順で次 / 前のタブ（ADR 0057） |
| 帯の上でホイール | 帯を横へ送る（あふれているときだけ） |
| 「∨」をクリック | 開いているタブの一覧（Ctrl+P の面） |
| ファイルを開く | 同じファイルが開いていればそのタブへ。アクティブが何も書いていない「無題」ならそこに。それ以外は新しいタブ |
| 最後の 1 つのタブを閉じる | 窓を閉じる（D22） |
| 窓を閉じる | 未保存のタブを帯の左から順に確かめる。キャンセルで止まる |

Vim のレジスタと「通常 | Vim」の切り替えは窓全体で 1 つ。あるタブで yank して別のタブで貼れる。
