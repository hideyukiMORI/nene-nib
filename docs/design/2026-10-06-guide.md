## 2. 空の文書の案内（D42・画 B）

| 項目 | 見た目 |
| --- | --- |
| 出すとき | 何も書いていない無題の文書（本文が空・履歴が空）がアクティブなとき。打ち始める・ファイルを開く・別のタブへ移ると消える |
| 置き場 | 本文の領域の中ほど。横は中央、縦は本文の領域の上から 3 分の 1 あたり。1 行目のキャレットと現在行の面には重ならない |
| 中身 | 3 行。左の列に鍵（右寄せ）、右の列に説明。`Ctrl+P` ファイルとタブの一覧 / `Ctrl+O` ファイルを開く / `F1` ヘルプ |
| 鍵 | 等幅 12.5 DIP・`text`。角丸 5 の枠 1 DIP（`panel_border`）と面（`panel`）。左右の余白 9・上下 2 |
| 説明 | UI の字体 13.5 DIP・`muted` |
| 行の間 | 12 DIP。鍵と説明の間 20 DIP |
| 下の 1 行 | 「打ち始めると消えます」。UI の字体 11.5 DIP・`muted`。3 行の下 20 DIP |

色は今あるトークンだけで足りる（`text` `muted` `panel` `panel_border`）。新しいトークンは足さない。

## 3. ステータスバーの案内（D42・画 A）

| 項目 | 見た目 |
| --- | --- |
| 出すとき | 入力行（`:` `/` `?`）・1 行の知らせ・録画の表示が無く、幅が足りるとき |
| 置き場 | 右の 3 項目（行と桁・文字コード・改行）のすぐ左。項目との間 28 DIP |
| 中身 | 「Ctrl+P 一覧」「F1 ヘルプ」の 2 つ。間 16 DIP |
| 字 | ステータスバーの字（12 DIP）。鍵は `text`、説明は `muted`。枠は付けない |
| 幅が足りないとき | 案内が先に消える。モード・右の項目は今のまま |

左（トグルとモード）は「いまの状態」、右は「文書の事実」。案内はどちらでもないので、右の項目の手前に置き、狭くなったら最初に引っ込む。

## 4. 設定（D42）

- `:set noguide` で 2 つとも消え、`:set guide` で戻る。Ctrl+P の `:` からも選べる。
- 既定は出す。設定は保存され、次の起動でも同じ。
- 名前は `guide`（Vim に同じ名前の設定は無い）。

## 5. 操作の一覧（D43・画 1）

| 項目 | 見た目 |
| --- | --- |
| 開き方 | F1（通常モードでも Vim のどのモードでも）。Ctrl+P の面で行頭に `?` を打っても同じ |
| 面 | Ctrl+P の面そのもの。入力行・行・脚の形と色は今のまま |
| 行 | 左に操作の名前（13.5 DIP・太め・`text`）、続けて短い説明（12 DIP・`muted`）、右端に鍵 |
| 鍵 | 等幅 12 DIP・`text`。角丸 5 の枠 1 DIP（`panel_border`）と面（本文の地の色）。空の文書の案内の鍵と同じ形 |
| 脚 | 今の面と同じ「↑↓ 選択　Enter 決定　Esc 閉じる」と件数 |
| 絞り込み | 名前・読み・鍵で絞る（「ほぞん」→ 保存・「ctrl+s」→ 保存）。説明は照合しない |

最初に載せる操作: ファイルを開く・保存・名前を付けて保存・新しいタブ・タブを閉じる・前に使ったタブへ・ファイルとタブの一覧・ブックマークに付ける / 外す・元に戻す・やり直す・文字を大きく / 小さく / 戻す・通常 / Vim の切り替え。

## 6. 実装との対応

| 画 | 実装 |

2026-10-07 実装時の照合: `HintB` とcanvasの注釈「空の文書では B、ふだんは A」に合わせ、本文に案内を出すときはステータスには重ねない。低い窓などで本文の案内が収まらなければ、幅が足りるときだけステータスへ回す。本文の横中央は行番号の欄も含む領域の中央。狭幅・低高さの寸法と表示の排他は ADR 0079 が定める。採用画の変更は無い。
