## 表（案 B）

```
ベンチ                   1.0.0      1.1.0    判定        ← 見出しの行は太字
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━    ← panel_border の 2 DIP
起動（最初の frame）    41.9 ms    44.6 ms   合格
───────────────────────────────────────────────────    ← panel_border の 1 DIP（行の間）
1 打鍵（空の文書）     0.641 ms   0.593 ms   合格
```

- 列の幅は中身から決める（その列のいちばん広い升 ＋ 左右の余白 14 DIP ずつ）。升の上下の余白は 7 DIP。升の中では折り返さない。
- 列の揃え（`:---` 左・`:---:` 中央・`---:` 右・指定なしは左）を効かせる。
- 表が枠より広いときは、右を枠で切る（囲みのコードと同じ・横の送りは後続）。
- 文字の色は本文と同じ（`foreground`）。升の中の強調・行内コード・リンク・打ち消し線は本文と同じ見た目。
- 罫の色は `panel_border`。色のトークンは足さない。外枠と縦の罫は引かない。

## alert（`> [!NOTE]` ほか 5 種）

```
┃ NOTE                         ← 種類の名前（太字・種類の色・訳さない）
┃ 設定は settings.v5 に書きます。 ← 本文は foreground
```

- 引用と同じ位置に左の線（3 DIP・種類の色）。1 行目に種類の名前を太字で出し、本文は `foreground`（ふつうの引用の `comment` 色ではない）。
- 種類と色（構文の色の役割を使い回す）: `NOTE` = `function`・`TIP` = `string`・`IMPORTANT` = `number`・`WARNING` = `warning`・`CAUTION` = `error`。
- 絵文字とアイコンは使わない（字体に依らない）。名前は GitHub の綴りのまま（大文字・訳さない）。
- 認めるのは GitHub と同じ形: 引用の最初の行が `[!NOTE]` だけ（大小は区別しない・前後の空白は可）。それ以外は今までどおりのふつうの引用。
