## 1. 設定画面の「機能」の節（既存の案の下に足す）

```
┌ 設定 ───────────────────────────────────────────────────────┐
│ 表示言語 ／ 外観 ／ 編集 …（既存の案の節）                    │
│                                                             │
│ 機能                                                        │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ いまの設定での 1 打鍵の見込み: 0.64 ms ＋ 小 × 1（約 0.65） │ │  ← 要約（見込み・基準は採用値と明示）
│ │ 速さに影響する機能はオンになっていません                 │ │
│ │                 [速さ優先] [おすすめ ●] [全部オン]        │ │  ← 3 つの組
│ └─────────────────────────────────────────────────────────┘ │
│ ●━  括弧の相手の強調               なし                      │  ← スイッチ・名前・1 行の説明・段
│     キャレットの下の括弧の相手を枠で示す                      │
│ ●━  変更のある行の印               なし                      │
│ ●━  INSERT の補完                  ● 小                      │
│ ━●  autopairs                      ● 小                      │
│ ━●  ミニマップ                     ●● 中                     │
│ ━●  言語サーバー（LSP）            ●●● 大・裏                 │  ← 裏で CPU を使う機能は「裏」の印
│                                                             │
│ 閉じると保存されます。段は機械で測った数字から決めています。 │
│                                        [元に戻す] [閉じる]   │
└─────────────────────────────────────────────────────────────┘
```

- **段の印**: なし＝文字だけ・小＝`muted` の ● 1 つ・中＝`accent` の ● 2 つ・大＝`error` の ● 3 つ。裏で CPU・メモリ・子プロセスを使う機能は「大・裏」。段の決め方は ADR 0170 の決定 2（1 打鍵の増分 ＜1% / 1〜5% / 5〜20% / 20% 超・機械で測った数字から）。
- **要約**: 基準値（`eng/perf-reference.json` の採用値 0.64 ms）に表の増分を足した「見込み」。その機械の実測ではないと 1 行で明示する。
- **組**: 速さ優先（段が「なし」だけオン）・おすすめ（小までオン・既定）・全部オン。選んだ後に個別のスイッチで直せる。
- 色のトークンは足していない（`error` は構文の色の `SyntaxPalette.error` を流用・ADR 0161 の波線と同じ）。

判断してもらう点: (a) 段の印を ● の数で表すのでよいか（文字だけ・色だけの別案あり）(b) 要約の文の長さ（1 行に収めるため「約 0.65 ms」を括弧に）(c) 「裏」の印の文言。

## 2. 起動画面（無題の本文の面）

```
│  1  NeNe Nib                                                  │  ← muted・本文の字の 1.5 倍
│                                                              │
│     最近使ったファイル                                        │  ← 節の見出し（muted・小さい字）
│   ▸ D:\NeNeNib\docs\reports\2026-10-27.md                     │  ← 選んだ行（current_line）
│     C:\Users\info\WORKS\NeNeNib\CLAUDE.md                     │
│     …                                                        │
│     ブックマーク                                              │
│     C:\Users\info\WORKS\NeNeNib\SPECIFICATION.md              │
│     はじめる                                                  │
│     新しいファイル          そのまま打ち始める                 │
│     ファイルを開く          [Ctrl]+[O]                        │
│     フォルダを開く          ルートを選んでエクスプローラーを出す │
│     鍵                                                        │
│     [Ctrl]+[P] 何でも探す       [F1] 操作の一覧               │
│     [Ctrl]+[Shift]+[E] エクスプローラー   [Ctrl]+[,] 設定     │
```

- 行番号の列と本文の字体はそのまま（本文の面に「描いている」ことが分かるように・行番号 1 が見える）。節の見出しと鍵の枠は UI の字体（Segoe UI）、パスは本文の字体。
- 履歴が無い起動（`?scene=empty`）は「まだ履歴がありません。ファイルを開くか、そのまま打ち始めてください」の 1 行と「はじめる」「鍵」だけ。
- 消え方は ADR 0172 の決定 1（文字を打つ・文書を開く・タブを足す）。

判断してもらう点: (a) 題「NeNe Nib」を出すか（出さない方が静か）(b) パスをフルで出すかファイル名＋フォルダの 2 段にするか（今はフル・末尾を「…」）(c) 鍵の節を 2 列にするか 1 列にするか。
