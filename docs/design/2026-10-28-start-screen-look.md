## 2026-11-11 に改めた点（#1455・設計席の講評・試用で直す）

段 2 の実装の絵を見て、次のとおり改めた（ADR 0172 の追補 20〜22）。上の図と表はこちらで読み替える。

| 要素 | 改めた値 |
|---|---|
| 最近使ったファイル・ブックマークの行 | フルパスをやめ、名前（`text`）＋ 12 DIP 空けて場所（フォルダのパス・`muted`）。場所が入り切らなければ頭側を「…」。名前は切らない（名前だけで入り切らないときだけ末尾を「…」） |
| 行の字 | UI の字体（エクスプローラーの面と同じ族と大きさ）。本文の等幅は使わない |
| 「はじめる」の補足 | ラベルのすぐ後ろに `muted`。右端は「ファイルを開く」の鍵の枠だけ |
| 節の見出し「鍵」 | 「ショートカット」 |
| ショートカットの節 | 鍵の枠を行の左端の軸（ほかの行のラベルと同じ x）に揃え、説明をその右に |
| 「はじめる」の行の鍵（#1480・追補 27） | 操作の表に鍵がある行（「新しいファイル」Ctrl+T・「ファイルを開く」Ctrl+O）は右端に鍵の枠。名前と補足は枠の手前まで。「フォルダを開く」は鍵が決まるまで補足だけ |
| 縦の位置（#1480・追補 26） | ブロック全体を本文の面の上下の中央に（上の余白は最小 36 DIP・面が足りなければ上寄せのまま） |

変えない所: 題・選んだ行の ▸ と `current_line` の地・幅 480 DIP・節の間隔。
