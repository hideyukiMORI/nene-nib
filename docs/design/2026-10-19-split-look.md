# split（分割ウィンドウ）の見た目 — 採用案（2026-10-19）

> Status: 設計席の推し（hide 不在の自走の日。試用のときに hide が選び直せるよう案 A/B/C を残す）。設計の記録は ADR 0148。
> 色は `core::Palette` のトークンだけ（ADR 0008 決定 8）。新しいトークンは足さない。寸法は DIP。

## 1. 何を決めるか

最大 2 枠（左右か上下の等分・ADR 0148 決定 1）で、使う人が一目で分かる必要があるのは 3 つ: **どこで分かれているか**・**どちらが操作中か**・**もう一方のキャレットはどこか**。ステータスバーとタブの帯は 1 つのまま（決定 13）。

## 2. 既存の部品との関係

| 既存 | 共有するもの | 足りないもの |
| --- | --- | --- |
| 本文の矩形 `body_layout`（gutter 56・左余白 8・上余白 12・行高 1.6 字） | 枠ごとに同じ配置を使う（`pane_layouts`） | 枠の境界 |
| キャレット（通常 2 DIP バー `accent`・Vim NORMAL はブロック `accent` に `on_accent` の字） | 操作中の枠はそのまま | 非操作枠の印 |
| 現在行 `current_line` | 操作中の枠はそのまま | 非操作枠で塗るか |
| Ctrl+P の面の縁 `panel_border`（1 DIP） | 境界の色 | — |

## 3. 案

### 境界

| 案 | 見た目 | 良い点 | 悪い点 |
| --- | --- | --- | --- |
| **A（推し）** | `panel_border` の 1 DIP の線 1 本。両側に余白を足さない（本文の左余白 8 と gutter が既にある）。左右の等分の余りの 1 物理画素は線に足す | 最も静か。125 テーマで `panel_border` は既に面の縁として調整済み | 上下に分けたとき、下の枠の上余白 12 と線が近く見えることがある |
| B | 4 DIP の帯を `gutter_background` で塗り、中央に `panel_border` の 1 DIP | 境界が掴める場所に見える（将来のドラッグ） | ドラッグは採らない（ADR 0148 の限界）。帯の分だけ本文が狭い |
| C | 線を引かず、非操作枠の背景を `panel` にする | 操作中の枠が一目で分かる | 本文の字の対比がテーマごとに変わる（`panel` は面の色で、本文の背景として調整していない） |

### 操作中の枠の印

| 案 | 見た目 | 良い点 | 悪い点 |
| --- | --- | --- | --- |
| **A（推し）** | 印を足さない。操作中の枠だけがキャレットを `accent` で描き、`current_line` を塗る。非操作枠は下の「非操作枠のキャレット」の印だけ | Vim と VS Code と同じ流儀。何も増えない | 両枠が空の文書のときは差が小さい（キャレットの色の差だけ） |
| B | 操作中の枠の境界側の端に `accent` の 2 DIP の線（左右なら枠の上端の全幅・上下なら枠の左端の全高） | 遠目でも分かる | タブの下線（`accent` の 2 DIP）と似て、帯の意味と混ざる |
| C | 操作中の枠の gutter を `gutter_background`、非操作枠の gutter を `background` にする | 控えめに分かる | gutter の背景はテーマで `background` と同じ値のものがあり、効かないテーマが出る |

### 非操作枠のキャレット

| 案 | 見た目 | 良い点 | 悪い点 |
| --- | --- | --- | --- |
| **A（推し）** | 通常モード: 2 DIP のバーを `muted`。Vim: 1 文字分の **中空のブロック**（1 DIP の枠線・`muted`・中は塗らず字はそのまま `text`） | 「ここにキャレットがある」が分かり、操作中と混ざらない。Vim の `guicursor` の非操作窓の流儀に近い | 中空のブロックは細い字体で見えにくいことがある |
| B | 描かない（VS Code の流儀） | 最も静か | 同じ文書を 2 枠で見るときに「もう一方はどこか」が分からず、F6 で移った瞬間に位置が分からない |
| C | 操作中と同じ `accent` で描く | 実装が最小 | どちらが操作中か分からない |

### 非操作枠の現在行

| 案 | 見た目 |
| --- | --- |
| **A（推し）** | 塗らない（操作中の枠だけ `current_line`） |
| B | 塗る（両枠） |

### ステータスバーとタブの帯

1 つのまま。表示は操作中の枠の文書（決定 13）。非操作枠の文書名は枠の中に描かない（限界）。hide が試用で「どのファイルか分からない」と言えば、次の案: 非操作枠の 1 行目の上に `muted` の小さな文書名（右寄せ・行高の半分）。

## 4. 推しの組（A・A・A・A）の画の説明

左右に分けた例（ダーク・茄子色）: 本文の帯がタイトルバーの下からステータスバーの上まで。中央に `panel_border`（#5A2A4C）の 1 DIP の縦線。左の枠は操作中で、行番号の gutter・`current_line` の面・`accent` の 2 DIP バー（Vim なら橙のブロック）。右の枠は同じ配置で、`current_line` は無く、キャレットの位置に `muted` の細いバー（Vim なら `muted` の中空の枠）。ステータスバーは今のまま 1 つ。上下に分けた例は線が横になるだけで、下の枠の上余白 12 はそのまま。
