## 1. 構成

```text
┌──────────────────────────────────────────────────────────────┐
│ [README.md ×][TextBuffer.hpp ×][メモ.txt ×] ＋        ─ □ ×  │ タイトルバー 40 DIP・Mica
├──────────────────────────────────────────────────────────────┤
│   1  // …                                                     │ 本文・等幅・行番号 56 DIP
│   2  namespace nenenib::core                                  │ 行高 24 DIP・現在行は薄い面
│   …                                                            │
├──────────────────────────────────────────────────────────────┤
│ [通常|Vim] NORMAL                 行 9, 桁 1  UTF-8  CRLF  C++ │ ステータスバー 28 DIP
└──────────────────────────────────────────────────────────────┘
```

- 枠なし。OS の枠は消すが、Aero Snap・影・最小化と最大化のアニメーションは保つ（`WM_NCCALCSIZE`）
- タイトルバーはタブの帯。タブは Windows Terminal 型で左寄せ、右端に最小化・最大化・閉じる（各 46 DIP 幅）
- 本文は等幅。実装は Cascadia Code、無ければ Consolas（キャンバスは JetBrains Mono で描いた）
- UI の文字は Segoe UI Variable Text（無ければ Segoe UI）
- ステータスバー左のトグルは「通常 | Vim」で、選択側がアクセント色の面。隣に現在モード（`通常` / `NORMAL` / `INSERT` / `VISUAL` …）
- Ctrl+P は本文の上に 640 DIP 幅の面。上に検索欄と絞り込みの記号（`★` ブックマーク・`◷` 履歴・`/` フォルダ）、行は種別のアイコン・名前・場所・補足。選択行はアクセントの薄い面。下に鍵の案内

## 4. 実装との対応

| 画 | 実装（Issue #5） |
| --- | --- |
| タイトルバーのタブ 3 本 | 1 本（表示中の名前「無題」）と「＋」。複数タブは Ctrl+P とタブの縦切りで |
| 本文 13 行のコード | 1 行（Issue #3 の表示文字列）。編集は次の縦切り |
| ステータスバー右の「C++」「空白 4」 | 「行 1, 桁 1」「UTF-8」「CRLF」だけ。言語と空白は編集の縦切りで |
| Ctrl+P | 描かない（Ctrl+P の縦切りで） |
| モードの文字の「字間広め」 | 太字（700）だけ。DirectWrite の字間は `IDWriteTextLayout1` 側にあり、毎フレーム layout を作ることになるので見送り |
| キャレットの位置 | 桁 1（本文の 1 文字目の手前）。画は 4 空白の後ろだが、ステータスの「行 1, 桁 1」に合わせた |
