# NeNe Nib の Markdown プレビューの見た目 — 採用案（2026-10-21）

> Status: 採用（施主 hide が 2026-10-21 に **案 B（構文の色）** を選択・施主決定 D62）。実装の判断は段 3 の ADR（#763 の renderer）。
> 候補 3 案（A 本文と同じ色・B 構文の色・C 読み物風）は設計席が文で起こし、板（`.dc.html`）は作っていない。見た目の確かめは段 3 の撮影（offscreen の PNG と `verify-window.py --capture`）で行う。
> 色は `core::Palette`（UI のトークン）と `core::SyntaxPalette`（本文の 16 役割・125 テーマで埋まっている・ADR 0017 / 0117）の**今ある値だけ**。新しいトークンは足さない（ADR 0008 決定 8・ADR 0117 決定 2）。寸法の土台は [採用案 2026-09-15](2026-09-15-look.md)（本文 13.5 pt＝18 DIP・行高 29 DIP・面は `panel` / `panel_border`・角丸 5）。プレビューの枠は split の other の枠（ADR 0148・仕切りは `panel_border` 1 DIP）。

## 1. 決まったこと

| 決定 | 内容 |
| --- | --- |
| D62 | Markdown プレビューの見た目は案 B: 見出しは `keyword`、コードは `string`（面は `panel`）、リンクは `function` に下線、引用は `comment` と左の線、箇条書きの記号は `operators`、水平線は `comment`。テーマを変えるとプレビューの色もテーマの構文色に変わる。見出しの倍率は h1 1.6・h2 1.35・h3 1.15・h4〜h6 は本文と同じで太字（施主決定 2026-10-21） |

採らなかった案: A（本文と同じ色・見出しとコードの区別が弱い）・C（読み物風・GitHub の README 型・`accent` のリンク。設計席の推しだったが hide は B を選んだ。構文の色が 125 テーマで既に決まっていて、プレビューでそれを見せるほうが Nib らしい）。

## 2. 共通の形

| 項目 | 見た目 |
| --- | --- |
| 枠 | split の other の枠。地は `SyntaxPalette.background`（本文と同じ地）。左右の余白 16 DIP・上の余白 12 DIP。行番号・現在行の面・キャレットは無い |
| 字体 | 本文の字体（`guifont`）。コードだけ等幅（格子の字体と同じ・D58） |
| 段落 | 本文の pt（設定に追従）・行高は本文と同じ比（×1.6）。段落の間は行高の半分 |
| 見出し | h1 = 本文 × 1.6（太字）・h2 × 1.35（太字）・h3 × 1.15（太字）・h4〜h6 = 本文と同じ（太字）。上の間は行高 1 つ、下は半分 |
| 太字・斜体 | `SetFontWeight(BOLD)` / `SetFontStyle(ITALIC)` を range で（字体に斜体が無ければ OS の疑似斜体） |
| 箇条書き | 字下げ 24 DIP × 深さ。記号 `•`（深さ 2 は `◦`・3 以上は `▪`）と番号 `1.` は `operators`。記号と文字の間 8 DIP |
| 画像 | `[画像: alt]` を `comment` の斜体で |
| HTML ブロック | 生の文字を等幅・`comment` で（限界） |
| 折り返し | 枠の幅で折る（本文の `wrap` に関わらず）。コードブロックは折らず横に送る |
| スクロール | 本文の `first_visible` の行に対応するブロックが枠の上に来る（片方向の同期）。ホイールで独立に送れ、本文を動かすとまた追従する |
| 更新 | 打つのを止めて 200 ms で差し替え（M-4）。差し替わるまで前の絵のまま。16 MiB を超える文書は「プレビューは 16 MiB までです」の 1 行だけ（M-3） |

## 3. 案 B の色（`SyntaxPalette` の役割）

| 要素 | 色 | 形 |
| --- | --- | --- |
| 本文の段落 | `foreground` | — |
| 見出し h1〜h6 | `keyword` | 太字・倍率は上 |
| 行内コード | `string` | 等幅・`Palette.panel` の面（角丸 3・左右 4 DIP） |
| コードブロック | `string` | 等幅・`Palette.panel` の面（角丸 5・余白 12 DIP）・折らない |
| リンクの文字 | `function` | 下線（`SetUnderline`）。開かない（M-5）。URL は出さない |
| 引用 | `comment` | 左に `comment` 2 DIP の線・字下げ 12 DIP |
| 箇条書きの記号・番号 | `operators` | — |
| 水平線 | `comment` | 1 DIP・上下の間は行高 1 つ |
| 強調（太字・斜体） | 周りの色のまま | 太さ・斜体だけ |
| 画像の代わりの文字・HTML ブロック | `comment` | 斜体 / 等幅 |

テーマを変えると（`:colorscheme`）プレビューの色はそのテーマの構文色に変わる。ダーク / ライトは `SyntaxPalette.background` と `foreground` に従う。

## 4. 実装との対応（段 3）

| 項目 | 実装 |
| --- | --- |
| 1 ブロック 1 layout | `PreviewTextLayouts`（ui/win32・鍵はブロックの文字列＋spans＋幅＋DPI＋字体＋pt・見えているブロックだけ・前 frame と同じ鍵は再利用）。`BodyTextLayouts` / `BodyTextPainter` には入れない（ADR 0114） |

| 確かめ | offscreen（WIC の bitmap）に描いて PNG に落とす試験の道具（tests の exe・製品の旗は足さない）と、段 4 の後の `verify-window.py --capture` |

## 5. 段 3 で決めた細部（2026-10-21 追記・#784）

採用案に書いていなかった所を、段 3 の撮影（`nib_preview_capture` の PNG）で設計席が見て決めた。

| 項目 | 見た目 |
| --- | --- |
| 続く項目の間 | 0（項目の間は空けない。リストの後は段落と同じく行高の半分） |
| 行内コードの面 | 行の当たり矩形の上下を行高の 1 割ずつ空ける（行高は本文の 1.6 倍で、面が隣の行に付かない） |
| HTML ブロック | 折らない（コードブロックと同じく横に送り、枠で切る） |
| 水平線の上下 | 行高 1 つずつ |
| 画像の代わりの文字 | 「[画像: alt]」の全体を `comment` の斜体 |

限界: 番号つきの記号は文字の左端から 8 DIP 空けて右に揃え、左の余白（16 DIP）に入る。本文 13.5 pt で 2 桁（`10.`）は枠の中に収まるが、3 桁以上や大きな字では枠の左端で切れうる（字下げは番号の幅で広げない）。
