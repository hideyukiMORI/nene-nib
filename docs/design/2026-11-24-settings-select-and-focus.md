# 設定: 一覧から選ぶ欄と焦点の行（/design・2026-11-24）

**状態: 設計席の採用案（hide の実機の確かめ待ち）。** 出どころは hide の決め「配色の部分をセレクトボックスのようなインターフェースにしたい」（#1926・2026-11-23）と「候補の一覧のフォーカスの色が他とほとんど変わらない・どのテーマでも」（#1929・2026-11-21）。見本は `D:/NeNeNib/evidence/design-20261124/settings-select.html`（絵は同じ所の `settings-select.png`）。/design（design-system の extend）の型で書く。

## 問題

- 選ぶ欄（`choice`）は選ぶ箱の見た目（地と下向きの印）なのに、クリックは次の値へ送るだけで戻れない。配色は 125 個あり、行き過ぎると 1 周するしかない。
- 焦点の行は `current_line` の面だけで見せている。`panel` は地を字へ 6% 寄せた色、`current_line` は 7% 寄せた色で、差は約 1%（既定の茄子色で 1.04:1）。色の差では見分けられない。挿入の補完の一覧の選んだ行も同じトークンで、同じ弱さを持つ。

## 決めた形

### 焦点（#1929）: 色の差ではなく `text` の 1 DIP の枠

- 設定の全部の行（設定の行・言語サーバーの行・畳みの行）の焦点は「`current_line` の面 ＋ `text` の色の 1 DIP の枠」。言語サーバーの節（#1945）で決めた形を全部の行へ広げる。
- `text` と `panel` のコントラストは本文の字と同じ水準（全テーマで 4.5:1 以上を契約 `verify_theme_contrast` が縛っている地と字の組から、`panel` が地を字へ 6% 寄せた分だけ下がる）。非テキストの UI の目安 3:1（WCAG 1.4.11）を全 125 テーマで満たすことを契約で縛る。
- `accent` は枠に使わない（地に近いテーマがある・#1945 のレビュー M1）。
- 挿入の補完の一覧の選んだ行（`CompletionPainter`）も同じ形（`current_line` の面 ＋ `text` の 1 DIP の枠）にそろえる。Ctrl+P の一覧と右クリックのメニュー（`selection` の面）は、指摘が出ていないので変えない。

### 一覧から選ぶ欄（#1926）

- 対象は `choice` の全部の行（配色・表示言語・字体など。選択肢が 2 つでも同じ。見た目が選ぶ箱なので、同じ見た目は同じ振る舞いにする）。段の上下（stepper）とスイッチは変えない。
- **開く**: 値の箱のクリック・焦点の行で Enter / Space（探す欄が空のとき）/ Alt+↓ / F4（Windows のコンボボックスの標準）。← → は今までどおり開かずに 1 つずつ送る（鍵だけで素早く試す道を残す）。
- **一覧の形**: 値の箱の下に、右端を箱にそろえて出す。入らなければ上。幅は「箱の幅」と「いちばん長い選択肢 ＋ 印の欄」の大きい方（パネルの幅まで）。見える行は最大 10 行で、それより多ければ送る（右端に細い送りの棒・`panel_border`）。下地は `background`・枠は `panel_border` の 1 DIP・角は右クリックのメニューと同じ丸み。行の高さは右クリックのメニューと同じ。
- **行**: 左に印の欄。今の値の行に ✓（`text` の色。色ではなく形で伝える）。選ぼうとしている行（鍵の ↑ ↓ かマウスを載せた行）は `selection` の面 ＋ `text` の 1 DIP の枠。開いた直後は今の値の行が選ぼうとしている行で、見える範囲の中ほどに来るように送る。開いている間、値の箱の枠は `text`。
- **鍵**: ↑ ↓（端で止まる・回らない）・Home / End・PgUp / PgDn・Enter か Space で決める・Esc か Alt+↑ / F4 で決めずに閉じる（パネルは閉じない）・Tab は決めて閉じ、焦点は同じ行のまま。字を打つと頭文字で跳ぶ（続けて打った字を前の方から照らす。1 秒空くか一覧を閉じると打った字を忘れる。大小は区別しない）。
- **マウス**: マウスを載せた行が選ぼうとしている行になる。行を押して同じ行で離すと決める。一覧の外を押すと決めずに閉じる（その押しはほかの物を動かさない）。右クリックも決めずに閉じる。ホイールは一覧を送る。閉じた箱の上のホイールは何もしない。
- **決める**: 今までの `ChangeSetting` と同じ「即時に反映・閉じると保存」（ADR 0170 決定 5・6）。「元に戻す」も同じ道で効く。
- **決める前に見せる（プレビュー）は入れない**: 選ぼうとしている行を動かしただけでは配色や字体を変えない。← → で 1 つずつ試す道は今のまま在る。プレビューは #1731（D93）の段で決める。
- 幅 700 DIP 未満（全幅のパネル）でも同じ形。

### 使うトークン（足さない）

`background`（一覧の下地）・`panel_border`（枠・送りの棒）・`text`（字・✓・焦点の枠）・`selection`（選ぼうとしている行の面）・`current_line`（焦点の行の面）・`muted`（箱の下向きの印）。

## アクセシビリティ

- 焦点と選ぼうとしている行は、色だけでなく枠（形）で伝える。今の値は ✓（形）で伝える。
- 鍵だけで開く・選ぶ・決める・やめるの全部ができる。Esc は内側（一覧）から先に閉じる。
- 3:1 の契約は全テーマを回して機械で縛る。
