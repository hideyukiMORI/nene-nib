## 生成と確かめの手順

```powershell
# 生成（一時の作業場所は D の下）
python -X utf8 eng/render-app-icon.py --chrome "C:/Program Files/Google/Chrome/Application/chrome.exe" --work D:/NeNeNib/temp/app-icon
# 描き直した画素と commit 済みの画素が同じか（Chrome が要る）
python -X utf8 eng/render-app-icon.py --chrome "C:/Program Files/Google/Chrome/Application/chrome.exe" --work D:/NeNeNib/temp/app-icon-check --check
# Chrome なし: 集合・大きさ・ICO の目次・SHA-256（CI の test-conformance.py が回す）
python -X utf8 eng/render-app-icon.py --verify
# exe の resource の icon group 101 が ICO の frame と同じか
python -X utf8 eng/render-app-icon.py --verify-exe build/NeNeNib.exe
```

## 大きさごとの絵

- 16 / 20 / 24 / 32 / 48 / 64 / 256 の ICO の frame は、design の 3 周目の `round3/render/A-best-<大きさ>.png` と **画素が 1 つも違わない**（#1580 の実装で数えた・40 は design に描いていない）。したがって `round3/notes.md` の「16 / 20 / 24 px で残る画素」の A-best の行がそのまま製品の絵に当てはまる。

| px | 孔 50% / 75% | 割れ目 50% / 75% | 線 50% / 75% | 先端と線の間（行） |
|---|---|---|---|---|
| 16 | 4 / 2 | 2 / 0 | 12 / 0 | 1 |
| 20 | 6 / 4 | 6 / 0 | 16 / 8 | 2 |
| 24 | 10 / 6 | 10 / 0 | 30 / 10 | 2 |

- 16 px は孔が 2 × 2 の暗い点として残り、割れ目は半分の濃さの 1 列、線は 2 行の橙、先端と線の間は 1 行空く。
- 絵は生成物そのもの（`src/app/msix/` の PNG と ICO の frame）。ICO の frame を PNG に戻した確かめの絵は作業木の `out/1580-impl/`（commit しない）。

## 窓とタスクバー

- exe の resource の icon group は `NENENIB_ICON_RESOURCE`（101・`src/ui/win32/AppIconResource.hpp`）。
- 窓の class は `hIcon` だけを `LR_SHARED` で引き、小さいアイコンは OS が同じ resource から選ぶ。タイトルバーは自前の描画で、帯にアイコンは描かない。覆いの子窓 `CoverWindow` はアイコンを持たない。
