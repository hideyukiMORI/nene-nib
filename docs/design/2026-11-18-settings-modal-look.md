## 形（実装で凍結する値は PR の表に書く）

```
┌ タイトルバー（タブ）──────────────────────────────────────────────┐
│ 本文（暗幕なし・切り替えが即時に効く）  │ 設定  [Ctrl+,]          ✕ │
│                                        │ [🔍 設定を探す（例: wrap）] │
│                                        │ (表示)(文字)(編集)(面)(機能)(言語サーバー) │
│                                        │─────────────────────────── │
│                                        │ 表示                        │
│                                        │ 表示言語        language [Windows に合わせる ▾] │
│                                        │ 配色            colorscheme [ubuntu-aubergine ▾] │
│                                        │ 操作の案内      guide    (●━) │
│                                        │ 文字 …  編集 …  面 …          │
│                                        │ 機能（2026-10-28 の採用案）    │
│                                        │ 言語サーバー（コマンドは読むだけ）│
│                                        │─────────────────────────── │
│                                        │ 閉じると保存されます。 [元に戻す][閉じる] │
└ ステータスバー ─────────────────────────────────────────────────┘
```

- 面: `panel` の地・左の境は `panel_border` の 1 px と影。角は丸めない（窓の端に付く）。
- 見出し 17 px 相当・節の見出しは `muted` の小さな字・行の名前は 13 px の太字・説明は `muted` の 11.5 px・`:set` の名前は等幅で `gutter` の色。
- スイッチは 40 × 22 DIP（オンは `accent`・オフは `toggle`）。選ぶ欄と段の上下は幅 172 DIP（地は `background`・枠は `panel_border`）。
- 節の札は押すとその節へ送る（札の焦点は `accent` の枠）。探す欄に打つと、当たらない行と空の節を隠す。何も当たらなければ「当たる設定はありません」の 1 行。
- 幅 700 DIP 未満の窓では引き出しを全幅にし、`:set` の名前を隠す。
- 色のトークンは足さない（`error` は ADR 0170 のとおり構文の色を流用）。
- 振る舞い（開く・閉じると保存・元に戻す・即時の反映）は ADR 0170 の決定 5・6 と 2026-11-18 の追補。
