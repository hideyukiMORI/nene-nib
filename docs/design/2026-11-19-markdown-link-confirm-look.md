## 共通の扱い（3 案とも・ADR 0151 の 2026-11-19 の追補）

- `http` / `https` → 既定のブラウザ。`mailto:` → 既定のメール。
- テキストのファイル（相対 / 絶対のパス）→ Nib の新しいタブ（開く道は `open_document` の 1 本）。
- `#見出し` → プレビューの中で跳ぶ（確かめない・段 L3）。
- それ以外（`javascript:`・`file:`・`ms-*`・UNC・テキストでない拡張子の `.exe` など）→ 開かない。札は「開けません」と写す口だけ。
- 札には表示の文字ではなく本当の宛先を出し、ホストを太字にする（見た目と宛先が違うリンクを見分ける）。

## 案 B の札

```
┌ このリンクを開きますか ─────────────────┐
│ https://www.vim.org/docs.php        ← 等幅・ホストだけ太字
│ 既定のブラウザで開きます                 ← comment 色
│ Enter 開く · Esc やめる · Ctrl+C 写す   [やめる] [開く]
└─────────────────────────────────────┘
```

- 面は `panel`、縁は `panel_border`、「開く」は `function` の面。札の幅は 400 DIP まで、長い宛先は折り返す。
- 札はクリックしたリンクの下（入らなければ上）。札の外のクリック・送り・打鍵（Enter / Esc / Ctrl+C 以外）で閉じる。
- 鍵: Enter 開く・Esc やめる・Ctrl+C 宛先を写す（実機のクリップボードを触る試験は替え玉だけ）。
