# 安装与首次启动

NeNe Nib 是一款适用于 Windows 11 的文本编辑器。平时使用“标准”模式，可以像记事本一样输入文字。按 `Ctrl+Shift+Space` 会切换到“Vim”模式，可以用 Vim 的操作方式编辑。本章介绍从安装到保存第一个文档的步骤，以及两种模式的切换方法。

> 如果不小心进入了“Vim”模式，输入的文字没有出现在文档中，请按 `Ctrl+Shift+Space` 返回“标准”模式。

## 系统要求

- 适用于 Windows 11（22H2 或更高版本）的 x64 版本。
- 不支持 Windows 10。
- 不需要额外的运行时（为运行应用而另外安装的组件）。只需一个可执行文件即可运行。

## 安装

有两种安装方法。两者包含的可执行文件相同。如果不确定，请选择 Microsoft Store。Microsoft Store 版会自动更新到新版本。

### 从 Microsoft Store 安装

1. 打开 [Microsoft Store 中的 NeNe Nib 页面](https://apps.microsoft.com/detail/9nclgdtfq529)。
2. 按照页面上的说明进行安装。
3. 从“开始”菜单启动 NeNe Nib。

新版本会通过 Store 自动更新。

<!-- 画面：Microsoft Store 中 NeNe Nib 页面的截图（稍后补充） -->

### 使用 GitHub 上的 ZIP

1. 从 [GitHub 的 Release 页面](https://github.com/hideyukiMORI/nene-nib/releases/tag/v1.2.0)下载 `NeNeNib-1.2.0-windows-x64.zip`。
2. 解压到任意文件夹。
3. 启动 `NeNeNib.exe`。

- ZIP 中包含 `NeNeNib.exe`、`README.txt`、`LICENSE`、`THIRD_PARTY_NOTICES.txt` 这 4 个文件。
- 没有安装程序，也不会自动更新。要使用新版本，请从 GitHub 的 Release 页面重新下载新版本的 ZIP 并替换原有文件。
- exe 没有签名（用于确认发布者身份的电子标记）。
- 可以对照同一页面上的 `SHA256SUMS`（每个文件的校验值列表），确认文件是否损坏。

ZIP 版可以将 NeNe Nib 添加到文件资源管理器的右键菜单和“打开方式”中。请从 `F1` 命令列表中选择“添加到 Windows 右键菜单”。要取消，请选择“从 Windows 右键菜单中移除”。不需要管理员权限。Store 版的命令列表中不会出现添加和移除这两项。

## 首次启动

第一次启动时，空的“无标题”标签页中会显示启动画面。

<!-- 画面：启动画面的截图（稍后补充） -->

启动画面从上到下显示以下内容。

| 区域 | 内容 |
|---|---|
| 最近使用的文件 | 最多列出 10 个最近关闭的文件。一开始显示“还没有历史记录。请打开文件，或直接开始输入”。 |
| 书签 | 如果有已添加书签的文件，最多列出 10 个。 |
| 开始 | “新建文件”（`Ctrl+T`）、“打开文件”（`Ctrl+O`）、“打开文件夹”（`Ctrl+Shift+R`）这 3 项。 |
| 快捷键 | “文件和标签页列表”（`Ctrl+P`）、“帮助”（`F1`）、“显示或隐藏资源管理器”（`Ctrl+Shift+E`）的按键。 |

标题旁显示版本号，下方显示版权信息和 GitHub 地址。

- 用 `↑`、`↓` 选择项目，按 `Enter` 或单击项目即可执行该项目。
- 输入任意文字或打开文档后，启动画面就会消失。可以直接开始输入。

从第二次启动开始，上次打开的标签页（仅限已保存的文件）会连同排列顺序、光标（表示输入文字位置的竖线）的位置和滚动位置一起恢复。如果上次的文件已不存在，会显示一行消息并关闭该标签页。

## 输入、打开和保存

| 任务 | 按键 | 结果 |
|---|---|---|
| 新建文档 | `Ctrl+T` 或 `Ctrl+N` | 打开一个空的“无标题”标签页。 |
| 打开文件 | `Ctrl+O` | 打开“打开”对话框，然后打开所选的文件。 |
| 保存 | `Ctrl+S` | 保存当前文件。如果文档还没有名称，会打开“另存为”对话框。 |
| 另存为 | `Ctrl+Shift+S` | 即使已有名称，每次也都会打开“另存为”对话框。 |
| 关闭标签页 | `Ctrl+W` 或 `Ctrl+F4` | 关闭当前标签页。 |

- 也可以将文件从文件资源管理器拖放到窗口中打开。同时拖放多个文件时，每个文件会在各自的标签页中打开。如果文件已经打开，会切换到该标签页。
- 有未保存更改的标签页，标签名前会显示“● ”。
- 在有未保存更改的情况下关闭标签页或窗口时，会询问“更改尚未保存。是否保存？”。请从“保存(S)”“不保存(N)”“取消”中选择。
- 按 `Esc` 不会关闭 NeNe Nib 窗口。“标准”模式下的 `Esc` 只会取消选择。
- 未保存的更改每 30 秒会备份到另一个位置。如果应用异常退出，下次启动时会询问一次“上次有未保存的编辑。是否恢复？”。

保存时使用的编码和换行符，可以单击状态栏右侧的编码（如 `UTF-8`）和换行符（`CRLF` 或 `LF`）进行选择。`CRLF` 是 Windows 的标准换行符，`LF` 是 macOS 和 Linux 的标准换行符。打开的文件会按照打开时的编码和换行符保存。

## 切换“标准”模式和“Vim”模式

NeNe Nib 有两种模式。

- “标准”模式使用与记事本相同的按键进行编辑。启动时总是处于“标准”模式。
- “Vim”模式使用 Vim 的操作方式进行编辑。Vim 有几种状态：用按键移动光标或执行命令的 NORMAL、输入文字的 INSERT，以及选择范围的 VISUAL。

按 `Ctrl+Shift+Space`，无论处于哪种模式，都会切换到另一种模式。也可以单击状态栏左侧的“标准 | Vim”进行切换。

<!-- 画面：状态栏左侧“标准 | Vim”切换开关和模式名称的截图（稍后补充） -->

当前处于哪种模式，可以看状态栏左侧。

- 在“标准 | Vim”切换开关中，当前模式的一侧会带有颜色。
- 其右侧显示当前模式的名称。“标准”模式时显示 `标准`，“Vim”模式时显示 `NORMAL`、`INSERT`、`VISUAL` 等。

如果输入的文字没有进入正文，请查看状态栏，确认是否处于“Vim”模式的 NORMAL。按 `Ctrl+Shift+Space` 即可返回“标准”模式。

- 切换模式后，正文、撤销历史记录和光标位置都会保持不变。
- 切换到“Vim”模式后，从 NORMAL 开始。
- 输入法正在组字（尚未上屏）时，`Ctrl+Shift+Space` 无效。请先上屏或取消组字，然后再按。

在两种模式中，有些按键的作用不同。例如，“Vim”模式下的 `Ctrl+O` 是返回上一个位置的 Vim 按键，因此在“Vim”模式下打开文件的按键是 `Ctrl+Shift+O`。“Vim”模式下没有分配按键的操作，可以从下面介绍的 `F1` 命令列表中使用。

## `F1` 命令列表

即使不记得按键，也可以用 `F1` 查找并执行操作。

| 任务 | 操作 | 结果 |
|---|---|---|
| 打开命令列表 | 按 `F1` | 打开一个列出操作名称、简短说明和按键的列表。 |
| 筛选列表 | 输入文字 | 只保留名称匹配的操作。界面语言为日语时，还可以用读音的平假名（如“ほぞん”）查找。 |
| 执行操作 | 用 `↑`、`↓` 选择后按 `Enter` | 立即执行所选的操作。 |
| 关闭列表 | 按 `Esc` | 关闭列表。 |

<!-- 画面：F1 命令列表的截图（稍后补充） -->

- 列表中列出当前模式下可用的操作。打印、“选择编码”、“选择换行符”等没有分配按键的操作，也可以从这里执行。
- 刚打开列表时，输入法处于关闭状态。需要用输入法输入时，请先打开输入法。
- 按 `Ctrl+P` 后输入 `?`，也会显示同一个列表。

## 界面语言

界面文字可以选择日语、英语或简体中文。默认跟随 Windows 的显示语言。要更改时，请从 `F1` 命令列表中选择“选择显示语言”。选择后会立即切换，下次启动时也保持不变。

Vim 的模式名称（如 `NORMAL`）、Vim 的消息和主题名称，在任何语言下都显示为英语。

## 设置

按 `Ctrl+,` 打开右侧的“设置”窗格，即可更改设置。关闭时会保存。详细内容请参阅“设置”一章。

NeNe Nib 不收集个人信息，应用本身不会连接网络。

## 深入了解：设置和记录的存放位置

设置、上次的标签页、最近关闭的文件、书签和自动备份都存放在 `%LOCALAPPDATA%\NeNeNib` 中。`%LOCALAPPDATA%` 是 Windows 中为每个用户存放应用数据的文件夹（通常是 `C:\Users\用户名\AppData\Local`）。在文件资源管理器的地址栏中输入 `%LOCALAPPDATA%\NeNeNib` 即可打开。

| 文件 | 内容 |
|---|---|
| `settings.v6` | 设置 |
| `session.v2` | 上次打开的标签页及其位置 |
| `history.v1` | 最近关闭的文件（最多 100 个） |
| `bookmarks.v1` | 书签（最多 1,024 个） |

删除此文件夹后，NeNe Nib 会恢复到首次启动时的状态。对于 Microsoft Store 版，Windows 有时会将此文件夹放在应用专用的存储位置，这种情况下卸载应用时，该文件夹也会一并删除。如果已经存在 ZIP 版的文件夹，Store 版有时也会直接使用该文件夹。
