# Markdown 与预览

编写 Markdown（用 `#`、`**` 等符号表示标题和粗体的文档格式）文档时，可以在预览中确认最终效果。本章介绍预览的打开方法、预览中可以显示的写法，以及向 Markdown 文档中粘贴内容的方法。

> 要关闭预览，请按几次 `Ctrl+Shift+M`。每按一次，会按“右侧（下方）窗格”→“整个编辑区”→“关闭”的顺序切换。

## 打开预览

| 任务 | 操作 | 结果 |
|---|---|---|
| 与正文并排查看 | `Ctrl+Shift+M` | 预览显示在另一个窗格（右侧或下方）中。左侧（显示在下方时为上方）保留正文，因此可以一边编写一边确认。 |
| 在整个编辑区查看 | 并排查看时再按一次 `Ctrl+Shift+M`，或从 `F1` 命令列表中选择“Markdown 预览（全区域）” | 预览占满整个编辑区。标签栏和状态栏仍然保留。 |
| 返回切换前的显示 | `Esc` | 退出整个编辑区的预览，返回切换为整个编辑区之前的显示（见表格下方的列表项）。 |
| 关闭预览 | 在整个编辑区查看时再按一次 `Ctrl+Shift+M` | 关闭预览，只显示正文。不会返回并排显示。 |

- 从并排查看切换为整个编辑区时，按 `Esc` 会返回与正文并排的预览。用 `F1` 命令列表或 `:preview full` 直接切换为整个编辑区时，按 `Esc` 会关闭预览，只显示正文。

<!-- 画面：左侧为正文、右侧为预览并排显示的截图（稍后补充） -->

- 修改正文后，稍过片刻预览也会更新。
- 滚动正文时，预览也会跟随到相同的位置。
- 无法用 `F6` 或单击移到预览窗格。会显示“无法进入预览窗格”。
- 在整个编辑区的预览中，可以通过拖动或按住 `Shift` 并按方向键选择文字，并用 `Ctrl+C` 复制。不能编辑。输入文字时会显示“预览时无法编辑。按 Esc 返回”。
- 在“Vim”模式下，也可以用 `:preview side`（并排查看）、`:preview full`（整个编辑区）、`:preview off`（关闭）切换。
- 无法让预览在下次启动时保持打开。启动时预览总是关闭的。

## 预览中可以显示的内容

预览按照 CommonMark（详细规定 Markdown 写法的通用规范）读取文档。除了标题、段落、粗体、斜体、项目符号列表、编号列表、引用、代码、链接和图片之外，还可以显示以下内容。

| 写法 | 示例 | 在预览中的显示效果 |
|---|---|---|
| 表格 | `\| 名称 \| 值 \|` 行，以及 `\|---\|---\|` 分隔行 | 显示为只有横线的表格，标题行为粗体（列的对齐方式见表格下方）。 |
| 提示（GitHub 的 alert） | 以 `> [!NOTE]` 开头的引用 | 左侧画一条彩色线，第一行以粗体显示类型名称。类型有 `NOTE`、`TIP`、`IMPORTANT`、`WARNING`、`CAUTION` 这 5 种，名称保持英语。 |
| 任务列表 | `- [ ] 未完成`、`- [x] 已完成` | 显示为复选框（见下面的“切换复选框”）。 |
| 删除线 | `~~删除的文字~~` | 在文字上画线。 |
| 直接写出的 URL | `https://example.com` | 显示为链接。 |
| 字符引用（用 `&` 和 `;` 括起名称来表示一个字符的 HTML 写法） | `&copy;` 等 | HTML 的所有命名字符引用都会显示为对应的字符（`&copy;` 显示为 ©）。 |
| front matter（位于文档开头、用于写文档标题和日期等的区域） | 从文档开头的 `---` 行到下一个 `---` 行 | 不作为正文的标题或段落读取，而是显示为单色的一块。 |
| 围栏代码（用 `` ``` `` 行包围前后的代码） | 在 `` ``` `` 后写上语言名称的代码 | 使用与正文相同的语法着色。 |

在表格的分隔行中写 `:---` 表示左对齐，写 `:---:` 表示居中，写 `---:` 表示右对齐。

### 围栏代码的颜色

根据 `` ``` `` 后的第一个词决定着色所用的语言。可以使用语言名称（如 `python`）、扩展名（如 `py`、`ts`）或别名（如 `c++`）。未知的语言以及没有写语言的代码，保持单色。

### 图片

电脑中的图片文件会嵌在正文中显示。

- 支持的格式为 PNG、JPEG、GIF（只显示第一帧）和 BMP。
- 比窗格大的图片会缩小到窗格的宽度。不会放大较小的图片。
- 图片的位置用相对于文档所在文件夹的相对路径，或从驱动器开始的路径来写。
- 不会获取互联网上的图片（以 `http`、`https` 开头的图片）。与无法读取的图片一样，显示为 `[图片：说明文字]`。

### 宽表格

比窗格宽的表格，下方会出现一条细滚动条。用以下任一方法，可以只横向滚动该表格。

- 拖动滚动条
- 单击滚动条的轨道
- 在表格上按住 `Shift` 并滚动鼠标滚轮
- 在表格上使用水平滚轮（或触摸板的水平滑动操作）

## 在预览中操作

### 切换复选框

单击预览中的复选框，正文中的 `[ ]` 和 `[x]` 会互相切换。并排查看和在整个编辑区查看时都可以操作。按一次 `Ctrl+Z` 即可撤销。

在整个编辑区查看时，在正文光标所在的任务行上按 `Space` 也可以切换。如果该行没有任务，会显示“此行没有任务”。

### 打开链接

单击预览中的链接，不会立即打开，而是在链接正下方显示一个小确认框。框中显示真实的目标，其中服务器名称部分为粗体。

<!-- 画面：链接下方显示的确认框截图（稍后补充） -->

| 按键 | 结果 |
|---|---|
| `Enter` | 打开链接。 |
| `Esc` | 不打开，关闭确认框。 |
| `Ctrl+C` | 将目标复制到剪贴板。 |

| 目标 | 打开方式 |
|---|---|
| 以 `http`、`https` 开头 | 在默认浏览器中打开。 |
| 以 `mailto:` 开头 | 在默认邮件应用中写新邮件。 |
| 文本文件 | 在 NeNe Nib 的新标签页中打开。 |
| 程序或类型未知的目标 | 不打开。会显示“无法打开此链接”，请复制后自行确认。 |

单击 `#标题` 形式的链接（指向同一文档中标题的链接）时，不显示确认框，正文的光标会移到该标题所在的行。标题名称的生成规则与 GitHub 相同。找不到时会显示“此文档中没有该标题”。在“Vim”模式下，可以用 `''` 返回移动之前的位置。

## 将 HTML 作为 Markdown 粘贴

将从浏览器或文字处理软件复制的文字用 `Ctrl+V` 粘贴到 Markdown 文档中时，会把标题、粗体、链接和项目符号列表转换为 Markdown 符号后粘贴。只想粘贴文本时，请使用 `Ctrl+Shift+V`。详细内容请参阅“[标准编辑](02-basic-editing.md)”一章中的“粘贴网页中的文字”。

## 语法着色

Markdown 文档正文和程序文件的着色，在“[主题与外观](07-themes.md)”一章中介绍。预览中围栏代码的颜色，不会因正文的 `:syntax off` 而消失。

## 尚不支持的功能

- 无法查找预览中的文字。
- 指向其他文档中标题的链接（`other.md#sec` 形式）只会打开该文档，不会移到该标题。

## 深入了解：预览的详细规则

| 项目 | 规则 |
|---|---|
| 可预览的大小 | 最大 16 MiB 的文档。超过时会显示“预览的上限为 16 MiB”形式的消息。 |
| 解析组件 | 用 md4c 0.5.2 读取，显示由 NeNe Nib 自行绘制。 |
| 围栏代码的颜色 | 较长的代码按每 64 行分段着色。 |
| 指向标题的链接 | 比较标题名称时，只有半角拉丁字母不区分大小写。对于全角拉丁字母、希腊字母等的大写字母，请在链接中写成与标题相同的大写。 |
| 长段落 | 非常长的段落，第一次显示时需要一点时间。从第二次开始，滚动时也不会卡顿。 |

- 标题中含有全角拉丁字母、希腊字母等的大写字母时，如果在链接中将这些字母写成小写，就找不到该标题。
