# 设置

NeNe Nib 的设置可以通过两种方法更改。一种是按 `Ctrl+,` 打开右侧的“设置”窗格，可以一边查看项目一边用鼠标或键盘更改。另一种是 `:set` 等命令，还可以更改“设置”中没有的项目。本章说明这两种方法的用法，以及主要设置的列表。

> “设置”中没有的项目（如不区分大小写的查找）需要用 `:set` 命令更改。在“标准”模式下，按 `Ctrl+P` 后输入 `:`，也可以使用命令。

## 使用“设置”

| 任务 | 操作 | 结果 |
|---|---|---|
| 打开“设置” | `Ctrl+,`（或在 `F1` 命令列表中选择“设置”） | 在窗口右侧打开“设置”。正文不会被遮住。 |
| 选择项目 | `↑`、`↓`（或 `Tab`） | 所选项目周围显示框。 |
| 打开或关闭 | 按 `Space`，或单击开关 | 立即切换。 |
| 逐个更改值 | `←`、`→` | 配色、字号等的值切换为前一个或后一个值。 |
| 从值的列表中选择 | 单击值，或按 `Enter`、`Space`、`Alt+↓`、`F4` | 打开列表。用 `↑`、`↓` 选择后按 `Enter`，即设为该值。 |
| 转到某一节 | `Ctrl+1` 到 `Ctrl+6` | 转到“显示”“文字”“编辑”“面板”“功能”“语言服务器”各节。 |
| 查找项目 | 在顶部的“搜索设置”中输入文字 | 只保留名称、说明或 `:set` 名称相符的项目。 |
| 恢复为打开时的设置 | 按“还原” | 恢复为打开“设置”时的状态。 |
| 关闭 | `Esc`、`Ctrl+,`、“关闭”、✕，或单击“设置”以外的位置 | 关闭并保存设置。 |

- 更改的设置会立即反映在界面上。保存是在关闭时进行的。
- 单击正文、输入文字或切换标签页时，“设置”也会关闭并保存。在正文上滚动鼠标滚轮，以及按住 `Ctrl` 滚动滚轮时，不会关闭。
- 查找项目期间，`Space` 会作为查找文字中的空格输入。
- 值的列表最多显示 10 行，当前值带有 ✓。按 `Esc`、`Alt+↑`、`F4` 只关闭列表。按 `Tab` 会确定所选的值并关闭列表。输入值的首字符，会跳到以该字符开头的值。

### 节和项目

| 节 | 项目 |
|---|---|
| 显示 | 配色、显示语言、操作提示、缩进参考线及其颜色和宽度 |
| 文字 | 字体（字体名称。仅显示）、字号 |
| 编辑 | 自动换行、自动缩进、光标动画、光标动画时间、输入火花 |
| 面板 | 资源管理器（显示在窗口左侧、以树形显示文件的栏。与 Windows 的文件资源管理器不同）、`Ctrl+P` 的预览（“查找面板的预览”）、窗格调整幅度、“Vim 的 Ctrl-w 幅度” |
| 功能 | 匹配括号高亮（始终开启）、缩略图、语言服务器（LSP） |
| 语言服务器 | 各语言的语言服务器（在“语言服务器”一章中说明） |

### 对速度的影响

“功能”一节的上方显示“当前设置下每次按键的估计耗时”。该值是指从按一次键到显示在界面上所需时间的估计值。它是在开发者电脑上测得的基准时间上，加上已开启功能所需的时间。功能的各行用 ● 的数量表示对速度影响的大小。● 的数量也是根据在开发者电脑上测得的数字决定的，并非在你的电脑上测得的时间。

可以用下方的 3 个按钮一次性切换多个功能。

| 按钮 | 结果 |
|---|---|
| 速度优先 | 只开启不影响速度的功能。 |
| 推荐 | 只开启对速度影响小的功能。默认为此状态。 |
| 全部开启 | 开启所有功能。 |

## 使用 `:set` 命令

输入命令的位置因模式而异。

| 模式 | 输入方法 |
|---|---|
| “Vim”模式 | 在 NORMAL 下按 `:`，窗口底部会显示 `:`。接着输入 `set ignorecase` 这样的内容并按 `Enter`。 |
| “标准”模式 | 按 `Ctrl+P` 后输入 `:`，会显示命令列表。接着输入 `set ignorecase` 这样的内容，列表会缩小范围，然后按 `Enter`。 |

`Ctrl+P` 的 `:` 列表在“Vim”模式下也可以使用。即使没有记住所有命令，只要输入 `:set`，就会列出可用的命令。`:set scrolloff=3` 这样带值的命令，也可以直接输入并按 `Enter` 使用。

- 在“Vim”模式的 `:` 行中，可以用 `Tab`、`Shift+Tab` 补全命令和主题名称。按 `Esc` 取消输入。
- 像 `:set ignorecase?` 这样在末尾加 `?`，会显示当前值。
- 像 `:set ignorecase&` 这样在末尾加 `&`，会恢复为默认值。
- 可以像 `:set ic scs` 这样，在一行中并列写 2 个以上的设置。
- 许多设置也可以使用 `ic`（`ignorecase`）这样与 Vim 相同的简写名称。
- `:set` 命令立即生效。需要保存的设置会当场保存。

## 不区分大小写查找

默认情况下，查找时区分大小写。要不区分大小写查找，请打开 `ignorecase`。此设置在“设置”界面和 `F1` 命令列表中都没有，需要用命令更改。

### 在“标准”模式下更改

1. 按 `Ctrl+P`。
2. 输入 `:set ignorecase`。列表中会保留“set ignorecase”。
3. 按 `Enter`。

这样，`Ctrl+F`、`F3`、`Shift+F3` 以及 `Ctrl+H` 替换中查找的文字就不再区分大小写。要恢复时，按同样的步骤选择 `:set noignorecase`。

### 在“Vim”模式下更改

在 NORMAL 下输入 `:set ignorecase`（简写为 `:set ic`）并按 `Enter`。`/`、`?`、`n`、`N` 的查找就不再区分大小写。要恢复时输入 `:set noignorecase`（`:set noic`）。

### 仅在输入大写字母时区分（smartcase）

在 `ignorecase` 的基础上再打开 `smartcase`（简写为 `scs`），则只有当查找文字中含有大写字母时才区分大小写。例如，`nib` 与 `Nib` 和 `NIB` 都匹配，而 `Nib` 只与 `Nib` 匹配。`smartcase` 只在 `ignorecase` 打开时才起作用。

| 查找的文字 | 仅 `ignorecase` | `ignorecase` 和 `smartcase` |
|---|---|---|
| `nib` | 与 `nib`、`Nib`、`NIB` 匹配 | 与 `nib`、`Nib`、`NIB` 匹配 |
| `Nib` | 与 `nib`、`Nib`、`NIB` 匹配 | 只与 `Nib` 匹配 |

两者都会保存，下次启动时仍然有效。`Ctrl+Shift+F` 的项目搜索不受此设置影响，始终不区分大小写查找输入的文字。

## 主要设置列表

在“‘设置’中的项目”列中有名称的设置，也可以在“设置”界面中更改。

### 查找

| 任务 | 命令 | “设置”中的项目 | 默认值 |
|---|---|---|---|
| 不区分大小写查找 | `:set ignorecase`（`ic`） | 无 | 关闭 |
| 仅在输入大写字母时区分 | `:set smartcase`（`scs`） | 无 | 关闭 |
| 在“Vim”模式的查找中，为所有找到的位置着色 | `:set hlsearch`（`hls`）、`:set nohlsearch` | 无 | 开启 |
| 在“Vim”模式的查找中，输入过程中就显示找到的位置 | `:set incsearch`（`is`）、`:set noincsearch` | 无 | 开启 |
| 在“Vim”模式的查找中，查找到文档末尾后返回开头继续查找 | `:set wrapscan`（`ws`）、`:set nowrapscan` | 无 | 开启 |

### 显示

| 任务 | 命令 | “设置”中的项目 | 默认值 |
|---|---|---|---|
| 长行自动换行 | `:set wrap`、`:set nowrap` | 自动换行 | 开启 |
| 以距光标所在行的行数显示行号 | `:set relativenumber`（`rnu`） | 无 | 关闭 |
| 在光标上下始终保留 N 行可见 | `:set scrolloff=3`（`so=3`） | 无 | 0 |
| 在空文档和状态栏中显示操作提示 | `:set guide`、`:set noguide` | 操作提示 | 开启 |
| 更改界面语言 | `:set language=ja`、`en`、`zh-hans`、`system` | 显示语言 | 跟随 Windows |
| 更改主题 | `:colorscheme 名称` | 配色 | 跟随 Windows |
| 更改字号 | `:set fontsize=18` | 字号 | 13.5 pt |
| 更改字体 | `:set guifont=名称:h字号` | 无（“字体”仅显示） | Cascadia Code |
| 在左侧显示资源管理器 | `:set explorer`、`:set noexplorer` | 资源管理器 | 关闭 |

### 编辑与功能

| 任务 | 命令 | “设置”中的项目 | 默认值 |
|---|---|---|---|
| 在“Vim”模式下换行时，沿用上一行的缩进 | `:set autoindent`（`ai`） | 自动缩进 | 关闭 |
| 使用语言服务器 | `:set lsp`、`:set nolsp` | 语言服务器（LSP） | 关闭 |
| 在“Vim”模式的复制和粘贴中使用 Windows 剪贴板 | `:set clipboard=unnamed` | 无 | 关闭 |

这里列出的设置会保存，下次启动时仍然有效。但以下 4 个设置不会保存，下次启动时会恢复为默认值。

- `hlsearch`
- `incsearch`
- `wrapscan`
- `clipboard`

- `scrolloff` 是 0 到 999 的数字，在“标准”模式和“Vim”模式下都起作用。
- `autoindent` 在“Vim”模式的 INSERT 中换行时，以及 `o`、`O`、`cc`、`S` 时起作用。
- 主题、字号、字体、自动换行、行号和特效的设置，在“主题与外观”一章中说明。
- 显示语言也可以在 `F1` 命令列表中通过“选择显示语言”更改。输入 `:set language?`，会显示当前设置和实际使用的语言。
- 不能使用 `:set number` 和 `:set nonumber`。行号始终显示。

## 设置的保存

- 在“设置”中更改的设置，会在关闭“设置”时保存。
- 用 `:set` 或 `:colorscheme` 更改的设置，会当场保存。
- 无法保存时，会显示一行消息。如果在关闭“设置”时未能保存，会在关闭窗口时再次保存。
- 设置保存在 `%LOCALAPPDATA%\NeNeNib` 中的 `settings.v6` 中。其位置在“安装与首次启动”一章的末尾说明。

## 深入了解：设置文件与旧版本

- 没有 `settings.v6` 时，会依次读取旧版本的设置文件：1.1.0 的 `settings.v5`、1.0.0 的 `settings.v4`。读取的旧文件不会改写，第一次更改设置时会创建 `settings.v6`。
- 创建 `settings.v6` 后，如果在 1.1.0 中更改设置，该更改会写入 `settings.v5`，因此不会反映到 1.2.0 中。反之亦然。
- 设置文件的大小上限为 16 KiB。
- 如果设置文件已损坏，会显示消息并以原设置启动，在修正并重新启动之前不会保存设置。
- 用“Vim”模式的 `:map` 创建的按键映射，也保存在 `settings.v6` 中。
