# 语言服务器

语言服务器是针对各种编程语言提供的独立应用。它会读取你正在编写的源代码，指出错误、提供补全（正在输入的名称的后续候选），并显示定义的位置等信息。NeNe Nib 连接语言服务器后，会在正文中显示这些信息。NeNe Nib 不包含语言服务器，请另行安装所用语言的语言服务器。本章以 clangd（C 和 C++ 的语言服务器）为例，说明连接和使用的方法。

> 语言服务器默认处于关闭状态。仅安装语言服务器不会显示任何内容。请在“设置”中打开语言服务器，并选择所用语言的服务器。

## 连接语言服务器

最简单的方法是通过按 `Ctrl+,` 打开右侧的“设置”窗格进行连接。

1. 安装所用语言的语言服务器。C 和 C++ 使用 clangd。
2. 在 NeNe Nib 中按 `Ctrl+,` 打开“设置”。
3. 在“功能”一节中打开“语言服务器（LSP）”。
4. “语言服务器”一节中按语言列出各行。找到已安装的语言服务器后会显示“已找到”，请按右侧的“使用”。
5. 关闭“设置”。关闭时会保存设置。
6. 打开该语言的文件后，语言服务器就会启动。

<!-- 画面：“设置”的“语言服务器”一节和“使用”按钮的截图（稍后补充） -->

“语言服务器”一节的各行会显示以下状态。

| 状态 | 含义 |
|---|---|
| 正在查找… | 正在电脑中查找。 |
| 已找到 | 已安装。按“使用”后，此语言将使用该语言服务器。 |
| 未找到 | 没有找到。第 2 行会显示安装命令。对于 Lua 和 Markdown，显示的不是命令，而是“安装后重新打开设置即可显示在这里”这样的提示。 |
| 已设置 | 已确定此语言使用的语言服务器。按“移除”即可停止使用。 |
| 正在启动 | 语言服务器正在启动。 |
| ● 正在运行 | 语言服务器正在运行。 |
| 已停止 | 连续多次启动失败，因此已停止。可用 `:set lsp` 重新启动。 |

- 一开始列出 5 种语言的行。按“查看其他 N 种语言”即可显示其他语言。
- C 和 C++ 合为一行。按“使用”后，两者使用同一个 clangd。
- 如果安装了语言服务器后仍显示“未找到”，请重新打开“设置”。如果更改了 PATH（Windows 查找应用的文件夹列表），请重新启动 NeNe Nib。
- 也可以用 `:set lsp` 和 `:set nolsp` 打开或关闭语言服务器。`:set` 命令在“设置”一章中说明。
- 语言服务器不适用于没有名称的“无标题”文档。请先保存一次。

状态栏右侧显示当前文档的语言。语言服务器启动期间，其进度也会显示在状态栏中。

## 查看错误和警告（诊断）

语言服务器发现错误或警告时，会在正文中的相应位置加上波浪线。这称为诊断。

- 状态栏右侧以 `E2 W1` 的形式显示错误和警告的数量。`E` 是错误数，`W` 是警告数。
- 将光标放在波浪线上时，状态栏左侧会显示该诊断的内容。

<!-- 画面：波浪线和状态栏中 E、W 数量的截图（稍后补充） -->

| 任务 | “标准”模式 | “Vim”模式 | 结果 |
|---|---|---|---|
| 转到下一个诊断 | `F8` | `F8` 或 `]d` | 移到下一个错误或警告。 |
| 转到上一个诊断 | `Shift+F8` | `Shift+F8` 或 `[d` | 移到上一个错误或警告。 |
| 查看诊断的全部内容 | 在 `F1` 命令列表中选择“显示诊断” | `gl` | 在小提示框中显示光标处诊断的内容。 |
| 查看诊断列表 | 在 `F1` 命令列表中选择“诊断列表” | 在 `F1` 命令列表中选择“诊断列表” | 已打开标签页的诊断列在 `Ctrl+P` 列表中。 |

按 `Ctrl+P` 后输入 `^`，也会显示诊断列表。

## 补全

可以从候选列表中选择正在输入的名称的后续部分并插入。候选中，语言服务器的候选排在前面，已打开文档中的单词排在后面。语言服务器关闭时，只列出文档中的单词。

### “标准”模式

| 任务 | 按键 | 结果 |
|---|---|---|
| 打开候选列表 | `Ctrl+Space`（或 `Ctrl+I`） | 列出与光标前正在输入的名称相符的候选。 |
| 选择候选 | `↑`、`↓` | 所选候选会突出显示。此时正文尚未改变。 |
| 插入所选候选 | `Enter` 或 `Tab` | 用所选候选替换正在输入的名称。 |
| 关闭列表 | `Esc` | 不插入任何内容并关闭列表。 |

- 在列表打开时继续输入文字，候选会随之缩小范围。
- 语言服务器运行时，输入 `.` 等特定字符后，列表会自动打开。
- 在自动打开的列表中，按 `Tab` 会插入所选候选或最上面的候选。按 `Enter` 只会插入用 `↑`、`↓` 选择的候选。如果没有选择就按 `Enter`，则为普通换行。也可以单击候选来插入。
- 如果输入法设置为使用 `Ctrl+Space`，请使用 `Ctrl+I`。

### “Vim”模式

在 INSERT 中使用以下按键。

| 任务 | 按键 | 结果 |
|---|---|---|
| 打开候选列表并插入下一个候选 | `Ctrl+N` | 打开列表，并依次插入候选。 |
| 插入上一个候选 | `Ctrl+P` | 按相反顺序插入候选。 |
| 确定当前候选 | `Ctrl+Y` | 关闭列表。 |
| 取消 | `Ctrl+E` | 恢复为正在输入的名称，并关闭列表。 |

- 在 INSERT 中，输入语言服务器的特定字符后，列表也会自动打开。列表打开期间，可以用 `↑`、`↓`、`PgUp`、`PgDn` 选择候选。
- 列表打开期间，`Ctrl+P` 是选择候选的按键，不会打开文件和标签页列表。

## 查看名称的信息、转到定义

| 任务 | “标准”模式 | “Vim”模式 | 结果 |
|---|---|---|---|
| 查看名称的信息 | 在 `F1` 命令列表中选择“显示信息” | `K` | 在小提示框中显示光标处名称的类型和说明。 |
| 转到定义 | `F12` | `F12` 或 `gd` | 跳转到光标处名称的定义位置。如果在其他文件中，则打开该文件。 |
| 查看参数信息 | 在 `F1` 命令列表中选择“显示参数信息” | 在 `F1` 命令列表中选择“显示参数信息” | 在光标所在行的上方显示函数调用的参数。 |

- 再次按键、单击或滚动后，信息提示框就会消失。
- 如果定义有 2 处以上，则跳转到第一处，并以“定义 1 / 3”的形式提示。
- 在函数名后输入 `(` 或 `,` 时，会自动显示参数信息。正在输入的参数会突出显示。

## 查找使用位置（引用）

| 任务 | “标准”模式 | “Vim”模式 | 结果 |
|---|---|---|---|
| 查看使用该名称的位置列表 | `Shift+F12` | `Shift+F12` 或 `grr` | 使用光标处名称的位置列在 `Ctrl+P` 列表中。 |

在列表中选择一项并按 `Enter`，即可跳转到该位置。列表最多显示 1,000 项。按 `Ctrl+P` 后输入 `&`，会再次显示上次查找的引用列表。

## 查看函数和类型的列表（符号列表）

| 任务 | “标准”模式 | “Vim”模式 | 结果 |
|---|---|---|---|
| 查看当前文档中函数和类型的列表 | 在 `F1` 命令列表中选择“符号列表” | `gO` | 当前文档中的函数、类型等列在 `Ctrl+P` 列表中。 |

在列表中选择一项并按 `Enter`，即可跳转到该位置。列表最多显示 1,000 项。按 `Ctrl+P` 后输入 `%`，也会显示符号列表。

## 重命名

可以一次性更改函数或变量的名称，包括所有使用该名称的位置。

| 任务 | “标准”模式 | “Vim”模式 | 结果 |
|---|---|---|---|
| 重命名 | `F2` | `F2` 或 `grn` | 窗口底部显示“新名称：”。输入新名称并按 `Enter`，名称随即更改。 |

- 其他文件中使用该名称的位置也会一并更改。尚未打开的文件会在新标签页中打开，更改保持未保存状态。请查看标签页名称前的“● ”，确认后再保存。
- 只要有一处无法更改，就不会更改任何位置，并显示一行消息。
- 在“Vim”模式下，INSERT 期间不会重命名。请按 `Esc` 返回 NORMAL 后再按键。
- 要撤销时，请在每个更改过的标签页中按 `Ctrl+Z`（“Vim”模式下按 `u`）。

## 整理格式（格式化）

可以请语言服务器整理缩进和空白等格式。此功能没有分配按键，请在 `F1` 命令列表中选择。

| 任务 | 操作 | 结果 |
|---|---|---|
| 整理整个文档 | 在 `F1` 命令列表中选择“格式化文档” | 整理整个文档的格式。 |
| 整理所选范围 | 在 `F1` 命令列表中选择“格式化选定内容” | 整理所选范围的格式。如果没有选择任何内容，则整理光标所在行。 |

格式化的结果按一次 `Ctrl+Z`（“Vim”模式下按 `u`）即可撤销。在“Vim”模式的 INSERT 期间不会进行格式化。

## 语言服务器不工作时

- 对于语言服务器不支持的功能，会显示“此语言服务器不提供引用”这样的一行消息。不同的语言服务器支持的功能不同。
- 在 `F1` 命令列表中选择“打开语言服务器日志”，即可在“无标题”标签页中查看语言服务器输出的消息。在“Vim”模式下也可以用 `:LspLog` 打开。
- 如果语言服务器连续多次启动失败，就会停止。请排除原因后，用 `:set lsp` 重新启动。

## 深入了解：在设置文件中编写

“设置”中的“使用”会在设置文件 `settings.v6`（请参阅“安装与首次启动”一章的末尾）中写入以下几行。也可以手动编写。

```
lsp=on
lsp.cpp.command=C:\llvm\bin\clangd.exe
```

- `lsp=on` 是打开语言服务器的行。
- 在 `lsp.语言.command=` 后面写启动语言服务器的命令。语言名称为 `c`、`cpp`、`python`、`rust`、`go`、`typescript`、`javascript`、`cs` 等。C 和 C++ 使用同一个 clangd 时，请写 `lsp.c.command=` 和 `lsp.cpp.command=` 两行。
- 可执行文件请写成以驱动器号开头的完整路径。文件夹名称中有空格时，请用 `"` 括起来。可以在后面用空格分隔写入参数。
- 不能使用 `.cmd` 或 `.bat`。对于用 npm 安装的语言服务器，请依次写出 `node.exe` 和脚本的路径。
- 手动编写时，请先关闭 NeNe Nib。如果在 NeNe Nib 打开期间改写，NeNe Nib 会显示“设置文件已被其他进程更改”，并且不会覆盖该文件。
- 如果写法有误，会显示“设置文件的格式不正确”，在改正之前将无法保存设置。

“设置”的“语言服务器”一节列出的是以下语言的语言服务器：C / C++、Python、TypeScript / JavaScript、Rust、Go、C#、Lua、Shell、JSON、CSS、HTML、YAML、Dockerfile、PHP、Markdown。经过验证的是 clangd、rust-analyzer、gopls 和 pyright。

每种语言各运行一个语言服务器，切换标签页时不会停止。使用同一命令运行的 C 和 C++、TypeScript 和 JavaScript，在同一项目中共用一个语言服务器。项目的范围是从文档所在的文件夹向上查找 `.git`、`Cargo.toml` 等标记文件来确定的。

重命名有以下限制。

- 不会进行涉及超过 32 个文件的更改，也不会进行创建、重命名或删除文件的更改。
- 在未打开的文件中，不是无 BOM 的 UTF-8 的文件和超过 4 MiB 的文件不会更改。
- 语言服务器尚未读取的文件中的名称不会更改。如果在语言服务器刚启动后就进行重命名，请通过“已更改 3 个文件中的 12 处”这样的消息确认更改的文件数。
- 如果更改涉及的标签页中有未保存的更改，并且该标签页的内容尚未传给语言服务器，则整个重命名都不会进行。例如，在语言服务器启动之前就已打开的标签页、由其他语言服务器负责的标签页，以及从未显示过的标签页。请保存该标签页后再试一次。
