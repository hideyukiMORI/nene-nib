# Vim 编辑

按 `Ctrl+Shift+Space`，NeNe Nib 会切换到“Vim”模式，可以使用与 Vim 相同的按键进行编辑。本章前半部分介绍从未用过 Vim 的人首先要掌握的操作。后半部分面向熟悉 Vim 的人，用表格汇总 NeNe Nib 中可用的按键和命令。

> 刚切换到“Vim”模式时处于 NORMAL，输入的文字不会进入正文。按 `i` 进入 INSERT 后即可输入文字。要返回“标准”模式，请再按一次 `Ctrl+Shift+Space`。

## Vim 入门

### 模式的概念

在 Vim 中，同一个按键的作用会因当前状态而不同。Vim 把这种状态称为“模式”。为了与 NeNe Nib 的“标准”模式和“Vim”模式区分开，本章按照界面上的写法，写作 NORMAL、INSERT、VISUAL。

不同状态下，状态栏的显示和光标的形状会改变。

| 状态 | 用途 | 状态栏的显示 | 光标的形状 |
|---|---|---|---|
| NORMAL | 用按键移动，或执行删除、复制等命令。输入的文字不会进入正文。 | `NORMAL` | 覆盖字符的方块 |
| INSERT | 输入的文字会进入正文。可以像记事本一样输入。 | `INSERT` | 竖线 |
| VISUAL | 选择范围。可以对所选范围执行命令。 | `VISUAL`、`VISUAL LINE`、`VISUAL BLOCK` | — |

当前状态显示在状态栏左侧“标准 | Vim”的右边。不确定时，请先看这里。

- 切换到“Vim”模式后，总是从 NORMAL 开始。
- 无论处于哪种状态，按 `Esc` 都会返回 NORMAL。
- 输入法在 NORMAL 中会自动关闭，进入 INSERT 后恢复开启。

### 开始输入与返回 NORMAL

在 NORMAL 中按下面的键会进入 INSERT，即可输入文字。输入完成后，按 `Esc` 返回 NORMAL。

| 任务 | 按键 | 结果 |
|---|---|---|
| 从光标前开始输入 | `i` | 在光标所在字符之前进入 INSERT。 |
| 从光标后开始输入 | `a` | 在光标所在字符之后进入 INSERT。 |
| 在下方新建一行并输入 | `o` | 在当前行下方新建一个空行，并在该行进入 INSERT。 |
| 在上方新建一行并输入 | `O` | 在当前行上方新建一个空行，并在该行进入 INSERT。 |
| 从行首或行尾开始输入 | `I`、`A` | 在行中第一个字符之前或行尾进入 INSERT。 |
| 返回 NORMAL | `Esc` | 停止输入，返回 NORMAL。 |

### 移动

在 NORMAL 中，用字母键移动光标。也可以使用方向键、`Home`、`End`、`PgUp`、`PgDn`。

| 任务 | 按键 | 结果 |
|---|---|---|
| 向左、下、上、右移动一格 | `h`、`j`、`k`、`l` | 向左移动一个字符、向下移动一行、向上移动一行、向右移动一个字符。 |
| 移到下一个或上一个单词 | `w`、`b` | 移到下一个单词的开头或上一个单词的开头。 |
| 移到行首或行尾 | `0`、`$` | 移到行中第一个或最后一个字符。 |
| 移到文档的第一行或最后一行 | `gg`、`G` | 移到文档的第一行或最后一行。 |
| 移到指定行 | 输入 `:120` 后按 `Enter` | 移到第 120 行。 |

在按键前输入数字，会重复相应的次数。例如，`5j` 会向下移动 5 行。

### 删除、复制、粘贴和撤销

| 任务 | 按键 | 结果 |
|---|---|---|
| 删除一个字符 | `x` | 删除光标所在的字符。 |
| 删除一行 | `dd` | 删除当前行。删除的行可以用于粘贴。 |
| 复制一行 | `yy` | 复制当前行。 |
| 粘贴 | `p`、`P` | 将复制或删除的文字粘贴到光标之后（整行时为下方）或之前（整行时为上方）。 |
| 撤销 | `u` | 撤销上一次编辑。 |
| 重做 | `Ctrl+R` | 重新执行已撤销的编辑。 |
| 重复同一编辑 | `.` | 在光标处再执行一次上一次的编辑。 |

在“Vim”模式下，右键菜单中的“复制”和“粘贴”也使用 Windows 剪贴板，因此可以与其他应用互相复制粘贴（内部执行的是 `"+y`、`"+p` 等 Vim 按键）。

用 `dd` 删除或用 `yy` 复制的文字，会存入只在 NeNe Nib 内部使用的位置（Vim 中称为寄存器），不会进入 Windows 剪贴板。

### 选择范围

| 任务 | 按键 | 结果 |
|---|---|---|
| 选择字符范围 | 按 `v` 后移动 | 进入 VISUAL，按移动的距离进行选择。 |
| 按行选择 | 按 `V` 后移动 | 进入 VISUAL LINE，按整行选择。 |
| 删除或复制所选范围 | `d`、`y` | 删除或复制所选范围，并返回 NORMAL。 |
| 停止选择 | `Esc` | 取消选择并返回 NORMAL。 |

双击选择单词或三击选择行时，会进入 VISUAL。

### 保存与关闭

在 NORMAL 中输入 `:`，窗口底部会出现输入命令的行。输入命令后按 `Enter` 即可执行。

| 任务 | 输入的命令 | 结果 |
|---|---|---|
| 保存 | `:w` | 保存当前文件。也可以用 `Ctrl+S` 保存。 |
| 保存并关闭标签页 | `:wq` | 保存后关闭当前标签页。 |
| 关闭标签页 | `:q` | 关闭当前标签页。有未保存的更改时不会关闭。 |
| 不保存就关闭标签页 | `:q!` | 放弃更改并关闭当前标签页。 |
| 取消命令 | `Esc` | 关闭输入命令的行。 |

### 返回“标准”模式

按 `Esc` 不会返回“标准”模式。按 `Esc` 只会返回到 NORMAL。要返回“标准”模式，无论处于哪种状态，请按 `Ctrl+Shift+Space`，或单击状态栏左侧的“标准 | Vim”。正文、撤销历史记录和光标位置都会保持不变。

### 与“标准”模式按键不同的操作

“Vim”模式优先使用 Vim 的按键，因此有些按键的作用与“标准”模式不同。

| 任务 | “标准”模式 | “Vim”模式 |
|---|---|---|
| 保存 | `Ctrl+S` | `Ctrl+S`（相同）或 `:w` |
| 撤销、重做 | `Ctrl+Z`、`Ctrl+Y` | `u`、`Ctrl+R` |
| 打开文件 | `Ctrl+O` | `Ctrl+Shift+O`（`Ctrl+O` 是返回上一个位置的 Vim 按键） |
| 关闭标签页 | `Ctrl+W` | `Ctrl+F4` 或 `:q`（`Ctrl+W` 是 Vim 拆分窗格的按键） |
| 新建标签页 | `Ctrl+T`、`Ctrl+N` | `Ctrl+T`（`Ctrl+N` 是 Vim 的按键） |
| 书签 | `Ctrl+D` | `Ctrl+Shift+D` |
| 查找、替换、转到行 | `Ctrl+F`、`Ctrl+H`、`Ctrl+G` | `/`、`:s`、`:120` 等（`Ctrl+F`、`Ctrl+H`、`Ctrl+G` 保持 Vim 中的作用） |

没有分配按键的操作，在两种模式下都可以从 `F1` 命令列表中使用。

## Vim 用户参考

以下内容面向用过 Vim 的人。不熟悉 Vim 的人，只看前半部分就足以使用。

NeNe Nib 的 Vim 操作不是嵌入 Vim 实现的，而是从零开始编写的。我们准备了 6,892 项测试（另有 402 项自动换行显示时的测试），与在真正的 Vim 9.1 中按相同按键得到的结果进行对比，确认结果一致。

| 文档与屏幕 | `gg` `G` `{N}%` `H` `M` `L` |
| 配对的括号 | `%` |

### 操作符与文本对象

操作符（如 `d`，对后面接着的移动或范围起作用的命令）可以与移动或文本对象（如 `iw`，表示单词、括号内等整体的写法）组合使用。次数与 Vim 一样相乘（`2d3w` 为 6 个单词）。

| 类别 | 按键 |
|---|---|
| 操作符 | `d` `c` `y` `>` `<` `g~` `gu` `gU` |
| 整行与到行尾 | `dd` `cc` `yy` `D` `C` `Y` |
| 单个字符的编辑 | `x` `X` `r` `s` `S` `~` |
| 合并行 | `J` `gJ` |
| 粘贴 | `p` `P` |
| 增加或减少数字 | `Ctrl+A` `Ctrl+X`，VISUAL 中的 `g Ctrl+A` |
| 文本对象 | `iw` `aw` `iW` `aW`，引号（如 `i"` `a"`），括号（如 `i(` `a{`，也可以使用 `b` `B`），`ip` `ap` `is` `as` `it` `at` |
| 进入 INSERT | `i` `a` `I` `A` `gI` `o` `O`（可以加次数），`gi` |
| INSERT 中 | `Ctrl+W` `Ctrl+U` `Ctrl+R {寄存器}`，`Ctrl+O`（执行一个 NORMAL 命令） |
| 重复与撤销 | `.`（VISUAL 中也可用），`u`，`Ctrl+R` |

### VISUAL 与矩形选择

矩形选择（跨行选择相同列范围的方块区域）用 `Ctrl+V` 进行。

| 类别 | 按键 |
|---|---|
| 开始选择 | `v` `V` `Ctrl+V`，恢复上一次选择 `gv`，切换选择的端点 `o` `O` |
| 对所选内容的命令 | `d` `x` `y` `c` `r` `J` `gJ` `X` `D` `Y` `C` `R` `s` `>` `<` `~` `u` `U` |
| 用粘贴替换所选内容 | `p` `P`（`P` 不更改寄存器） |
| 矩形选择中的命令 | `$` `I` `A` `c` `C` `d` `x` `y` `r` `>` `<` `~` `u` `U`，矩形的 `p` `P`，`.` |

用矩形的 `p` `P` 粘贴时，如果粘贴的列落在全角字符的中间，不会拆开该字符，而是用空格填充前面的部分。

### 寄存器与宏

| 类别 | 按键 |
|---|---|
| 无名寄存器 | 不指定寄存器时使用 |
| 命名寄存器 | `"a`～`"z`，追加用 `"A`～`"Z` |
| 编号寄存器 | `"0`～`"9` |

### 查找与替换

| 类别 | 按键、命令 |
|---|---|
| 查找 | `/` `?` `n` `N` `*` `#`，输入过程中的 `Ctrl+G` `Ctrl+T`，`:noh` |
| 选择上次查找的匹配项 | `gn` `gN`（用 `cgn` 和 `.` 逐个更改） |
| 大小写 | `:set ignorecase`、`:set smartcase` |
| 替换 | `:[范围]s/查找/替换/[标志] [次数]` |
| 重复替换 | `:&` `:&&` `:~`，NORMAL 中的 `&` `g&` |
| 删除或复制行 | `:[范围]d` `:[范围]y` |
| 匹配或不匹配模式的行 | `:g/查找/d` `:v/查找/d` `:g/查找/s//替换/` |

- `hlsearch`（为匹配项着色）和 `incsearch`（输入过程中即开始查找）默认为开启。
- 在 `:` 行和查找行中，可以用 `↑`、`↓` 调出之前输入的命令或文字。
- 替换的范围可以使用 `%` `N,M` `.` `$` `'<,'>` `'a,'b` `.,.+N`，标志可以使用 `g` `i` `I` `n` `e` `&` `c`。分隔符除了 `/` 之外，任何非字母的字符都可以使用。
- 替换内容中可以使用 `&` `\0`～`\9`（`\(` `\)` 的分组）、`~` `\r` `\u` `\U` `\l` `\L` `\e`。
- 一次替换命令，按一次 `u` 即可撤销。
- 模式写法的支持范围，汇总在本章末尾的“深入了解”中。

### easymotion

在 NORMAL 和 VISUAL 中按 `\\`（按两次 `\`），再按下面的键，屏幕上可见的目标位置左上角会显示小标签。输入标签上的字符，即可移到该位置。按 `Esc` 取消。

| 接着按的键 | 显示标签的位置 |
|---|---|
| `w`、`b` | 光标之后、之前的单词开头 |
| `e` | 光标之后的单词末尾 |
| `j`、`k` | 光标下方、上方各行中第一个非空白字符 |
| `l` | 所有可见单词的开头 |

### 尚不支持的功能

当前版本还不支持以下操作。

- 大写标记（`'A`～`'Z`）和 `:marks`
- `:sort`，以及使用 `d` 和 `s` 以外命令的 `:g` `:v`
- 只读寄存器（`".` `":` `"/` `"%`）
- NORMAL 中的 `R`，以及 VISUAL 中的 `S`
- 在“Vim”模式下用鼠标拖动进入 VISUAL
- commentary 和 surround
- `:w` 等命令的文件名中 `%` 和 `*` 的展开

## 深入了解：与 Vim 的细微差别

### 模式的写法

查找和 `:s` 使用相同的模式（表示要查找内容的写法）规则。在 `magic` 写法中，可以使用以下内容。

- `.` `*` `^` `$`，以及字符集合 `[...]`
- 作用于单个字符或分组的次数 `\+` `\=` `\?` `\{n}` `\{n,}` `\{,m}` `\{n,m}`，以及最短匹配 `\{-n,m}`
- 选择 `\|`，分组 `\(` `\)` 和 `\%(` `\)`
- 重新设置匹配起点和终点的 `\zs` `\ze`

以下写法暂时还不能使用。

- 用 `\v` `\V` `\M` 切换写法
- 跨行的模式（如 `\n` `\_s` `\_.`）
- 模式中的反向引用（如 `\(a\)\1`）

如果展开模式后的结果非常大（例如单个字符的重复超过 1,024 次），会显示与 Vim 的 E363 相同的消息，并且不进行查找。

### 替换的确认

加上 `c` 标志后，每个匹配项都会询问：`y`（替换）、`n`（跳过）、`a`（替换其余全部）、`q`（停止）、`l`（替换这一处后停止）。在 `:g` 中的 `:s` 加上 `c` 标志时，目前会显示拒绝的消息而不执行。没有在输入过程中预先显示替换结果的功能。

### 无法更改值的设置

NeNe Nib 的缩进始终是制表符，宽度为 8。`:set` 接受与当前相同的值（`noet` `sw=8` `ts=8` `magic`），但拒绝不同的值（如 `et` `sw=4` `nomagic`）。`:set number` 和 `:set all&` 也会拒绝。在宏或 `.` 的重复中遇到遭到拒绝的行时，重复会在该处中止。

### 其他

- `:set clipboard=unnamed` 在关闭窗口之前有效，不会保存到设置文件中。
- 宏或 `.` 的重复所发送的按键，每次执行最多 100,000 个。超过时会丢弃其余按键，并显示一行消息。
- 对于以换行符结尾的文件，不会认为最后一个换行符之后还有一个空行（与 Vim 的 `eol` 计数方式相同）。`G` 和 `:$` 会移到最后一个换行符所在的行。保存时的内容不会改变。
- 在 INSERT 中按 `Ctrl+O` 等待 NORMAL 命令期间，状态栏会显示 `(insert)`。
- 无论界面语言是什么，Vim 的消息都以英语显示。
