# 文件与项目

在 NeNe Nib 中，每个打开的文件都会成为标题栏中的一个标签页。本章介绍标签页的用法、用 `Ctrl+P` 查找并打开文件的方法、打开文件夹以处理整个项目（存放一组文件的文件夹）的方法，以及将正文拆分为两个窗格的方法。

> 如果不知道该打开哪里的文件，请先按 `Ctrl+P`。已打开的标签页、书签、最近关闭的文件以及与当前文件在同一文件夹中的文件，会汇总显示在一个列表中。

## 标签页

标签页横向排列在窗口最上方的标题栏中。

| 任务 | 操作 | 结果 |
|---|---|---|
| 打开新标签页 | `Ctrl+T`（“标准”模式下也可以用 `Ctrl+N`），或单击标签栏中的 `+` | 打开一个空的“无标题”标签页。 |
| 切换标签页 | 单击标签页 | 切换到该标签页的文档。 |
| 按最近使用的顺序切换 | `Ctrl+Tab`（反向为 `Ctrl+Shift+Tab`） | 按住 `Ctrl` 的同时每按一次 `Tab`，就按最近使用的顺序前进到下一个标签页。松开 `Ctrl` 时所在的标签页即为选定的标签页。 |
| 关闭标签页 | `Ctrl+F4`（“标准”模式下也可以用 `Ctrl+W`）、单击标签页上的 ×，或在标签页上按下鼠标滚轮（中键单击） | 关闭该标签页。 |
| 从标签页列表中选择 | 标签栏放不下所有标签页时出现的 `∨` | 显示已打开的标签页列表。 |
| 查看文件的位置 | 将鼠标停在标签页上 | 稍等片刻，标签页下方会以小字显示文件的完整路径（从驱动器开始的完整位置）。较长的路径会把中间部分缩略为“…”。 |

### 标签页的右键菜单

右键单击标签页（包括其上的 ×），会显示以下菜单。“标准”模式和“Vim”模式下相同。

| 项目 | 结果 |
|---|---|
| 在文件资源管理器中显示 | 在 Windows 文件资源管理器中打开该文件所在的文件夹，并选中该文件。 |
| 复制路径 | 将文件的完整路径复制到剪贴板。 |
| 复制文件名 | 将文件名复制到剪贴板。 |
| 保存 | 保存该标签页的文档。 |
| 另存为 | 以其他文件名保存该标签页的文档。 |
| 关闭标签页 | 关闭该标签页。 |
| 关闭其他标签页 | 保留该标签页，关闭其他标签页。 |
| 关闭右侧的标签页 | 关闭该标签页右侧的标签页。 |

- 在“无标题”标签页中，由于没有路径，“在文件资源管理器中显示”“复制路径”“复制文件名”会显示为灰色，无法选择。
- 一次关闭多个标签页时，会对每个未保存的标签页询问是否保存。选择“取消”会在该处停止。
- 此菜单无法用键盘打开（`Shift+F10` 和菜单键打开的是正文的右键菜单）。“在文件资源管理器中显示”“复制路径”“复制文件名”“关闭其他标签页”“关闭右侧的标签页”也可以从 `F1` 命令列表中对当前标签页执行。

### 下次启动时的标签页

不指定文件启动时，上次打开的标签页（仅限已保存的文件）会连同排列顺序、当时显示的标签页、光标和滚动位置一起恢复。详细内容请参阅“安装与首次启动”一章。

## 用 `Ctrl+P` 查找文件和标签页

按 `Ctrl+P` 会打开“文件和标签页列表”。输入框为空，以下内容会列在同一个列表中。

- 已打开的标签页
- 书签
- 历史记录（最近关闭的文件）
- 与当前文件在同一文件夹中的文件

<!-- 画面：Ctrl+P 列表和右侧预览栏的截图（稍后补充） -->

输入文件名的一部分，会用模糊搜索（只要依次包含输入的字符，即使不连续也能找到的查找方式）筛选候选项。按文件名找不到时，还会按文件夹名称查找。

| 任务 | 按键 | 结果 |
|---|---|---|
| 选择候选项 | `↑`、`↓` | 移动所选的候选项。 |
| 打开 | `Enter` | 打开所选的文件。如果是已打开的标签页，会切换到该标签页。 |
| 关闭 | `Esc` | 关闭列表。 |
| 更改预览栏的位置 | 在列表打开时按 `Ctrl+Shift+P` | 预览栏按“右侧”→“下方”→“不显示”的顺序切换。 |

- 所选候选项的内容会显示在列表右侧的预览栏中。窗口宽度不够时，显示在列表下方。选择的位置在下次启动时保持不变。
- 对于已打开的标签页，显示包括尚未保存部分在内的内容。对于未打开的文件，最多读取 16 MiB 并显示。位于 OneDrive 等云端、尚未下载到此电脑的文件，不会为了预览而下载。
- 刚打开列表时，输入法处于关闭状态。需要用输入法输入时，请先打开输入法。

### 用开头的符号筛选

在输入框开头输入一个符号，可以只筛选该类别。

| 开头的符号 | 显示的内容 |
|---|---|
| `#` | 已打开的标签页 |
| `*` | 书签 |
| `@` | 历史记录（最近关闭的文件） |
| `/` | 与当前文件在同一文件夹中的文件 |
| `!` | 项目全文搜索（见下面的“在整个项目中查找”） |
| `:` | 设置命令（在“设置”一章中介绍） |
| `?` | 命令列表（与 `F1` 相同） |

`^`、`&`、`%` 是语言服务器的列表，在“语言服务器”一章中介绍。

## 最近关闭的文件与书签

### 历史记录

关闭标签页后，该文件会保留在历史记录中，最多 100 个。除了显示在 `Ctrl+P` 列表中，还可以用 `@` 只显示历史记录。启动画面的“最近使用的文件”中也最多显示 10 个。

如果历史记录中的文件已不存在，会显示一行消息，并将其从历史记录中移除。

### 书签

为经常打开的文件添加书签后，在 `Ctrl+P` 列表中输入 `*` 即可马上调出。

| 任务 | 按键 | 结果 |
|---|---|---|
| 为当前文件添加或移除书签 | “标准”模式为 `Ctrl+D`，“Vim”模式为 `Ctrl+Shift+D` | 显示“已添加书签”或“已移除书签”。 |
| 为列表中的文件添加或移除书签 | 在 `Ctrl+P` 列表中选择候选项后按相同的键 | 不打开所选文件，直接添加或移除书签。 |

- 只能为已保存的文件添加书签。在“无标题”标签页中会显示“请选择已保存的文件”。
- 最多可以添加 1,024 个书签。
- 即使移动或删除了已添加书签的文件，书签也会保留。不再需要时，请在 `Ctrl+P` 列表中用 `*` 筛选后选中它，然后按相同的键移除。
- 启动画面的“书签”中也最多显示 10 个。
- “Vim”模式下的 `Ctrl+D` 仍是与 Vim 相同的向下滚动半屏。

## 打开文件夹（项目的根文件夹）

在 NeNe Nib 中打开项目时，先选择一个文件夹作为“根文件夹”（资源管理器和全文搜索中最顶层的文件夹）。资源管理器是显示在屏幕左侧、以树形显示文件的面板，与 Windows 的文件资源管理器不是一回事。

| 任务 | 操作 | 结果 |
|---|---|---|
| 打开文件夹 | `Ctrl+Shift+R`、启动画面中的“打开文件夹”，或从 `F1` 命令列表中选择“选择根文件夹” | 打开选择文件夹的对话框。所选文件夹成为根文件夹，左侧显示资源管理器。 |
| 将当前文件所在的文件夹设为根文件夹 | `:set root=.` | 当前文档所在的文件夹成为根文件夹。 |
| 按路径指定文件夹 | 在 `:set root=` 后接文件夹的路径 | 该文件夹成为根文件夹。 |

- `:set` 命令也可以在按 `Ctrl+P` 后，在 `:` 之后输入使用。
- 所选的根文件夹会保存到设置中，下次启动时保持不变。
- 选择文件夹的对话框中，已安装的 WSL（在 Windows 上运行 Linux 的机制）发行版也会作为 `\\wsl.localhost\<名称>` 位置显示。

## 资源管理器

资源管理器是在正文左侧以树形显示根文件夹下的文件夹和文件的面板。默认不显示。

<!-- 画面：左侧资源管理器和斜体预览标签页的截图（稍后补充） -->

| 任务 | 操作 | 结果 |
|---|---|---|
| 显示或隐藏 | `Ctrl+Shift+E`（或 `:set explorer`、`:set noexplorer`） | 未显示时显示资源管理器并移到其中。已显示且焦点在资源管理器中时隐藏它。已显示且焦点在正文中时，只移到资源管理器。 |
| 打开文件 | 单击文件所在的行 | 打开文件。焦点仍留在资源管理器中，因此可以接着用 `↑`、`↓` 查看其他文件。 |
| 打开并移到正文 | 双击文件所在的行，或按 `Enter` | 打开文件并移到正文。 |
| 展开或折叠文件夹 | 单击文件夹所在的行 | 显示或收起文件夹的内容。 |
| 更改面板宽度 | 拖动面板与正文之间的分界线 | 宽度随之改变。双击分界线可恢复原来的宽度。拖动过程中按 `Esc`，会恢复到拖动前的宽度。更改后的宽度在下次启动时保持不变。 |

焦点在资源管理器中时，可以使用以下按键。两种模式下相同。

| 按键 | 结果 |
|---|---|
| `↓`、`↑`（或 `j`、`k`） | 移动所选的行。 |
| `→`（或 `l`） | 展开文件夹。 |
| `←`（或 `h`） | 折叠文件夹。在已折叠的文件夹或文件上按时，移到上一级文件夹。 |
| `Enter` | 如果是文件，打开并移到正文。如果是文件夹，则展开。 |
| `Esc` | 保持面板显示，移到正文。 |

### 单击打开的标签页（预览标签页）

在资源管理器中单击一次打开的标签页，标签名会显示为斜体。这是“预览标签页”，之后再单击其他文件时，不会新增标签页，而是在同一个标签页中替换内容。这样依次浏览文件时，标签页不会越来越多。

执行以下任一操作后，它会变为普通标签页并保留下来。

- 编辑正文
- 保存
- 在资源管理器中双击，或按 `Enter`
- 双击标签名

用 `Ctrl+P`、`Ctrl+O` 或拖放打开的标签页，一开始就是普通标签页。这与 Markdown 预览（下一章）是不同的功能。

### 资源管理器的外观

- 文件所在的行带有一个小圆点，颜色表示该文件的语言。
- 有未保存更改的文件带有彩色圆圈。
- 隐藏文件也会以浅色显示。

## 在整个项目中查找

可以在根文件夹下的所有文件中查找文字。

1. 按 `Ctrl+Shift+F`（两种模式下都可用。从 `F1` 命令列表中选择“在项目中搜索”也相同）。`Ctrl+P` 列表会以开头已填入 `!` 的状态打开。
2. 输入要查找的文字。每输入一次都会重新查找，找到的行会逐渐添加到列表中。查找过程中会显示“正在搜索…”以及已搜索完的文件数。
3. 用 `↑`、`↓` 选择后按 `Enter`，会打开该文件，并将光标移到找到的行和列。

<!-- 画面：用 Ctrl+Shift+F 查找过程中的列表截图（稍后补充） -->

- 查找范围是资源管理器根文件夹之下。未选择根文件夹时，查找当前文档所在的文件夹之下。两者都没有时，会显示“没有可搜索的位置。请选择根目录，或从已保存的文档中搜索”。
- 输入的文字按原样查找，不区分大小写。在开头加上 `/`，会作为与 Vim 查找写法相同的模式进行查找。
- 每一行只显示最先找到的一处。找到 1,000 处时停止。
- 无法查找不是正确 UTF-8 的行（如 Shift_JIS 文件中的行）。要在 Shift_JIS 文件中查找，请打开该文件并用 `Ctrl+F` 查找。在已打开文档中查找的功能，也适用于 Shift_JIS 文件。

## 拆分窗格

可以将正文拆分为两个窗格，并排查看同一文档中相隔较远的部分，或两个不同的文档。

| 任务 | 按键 | 结果 |
|---|---|---|
| 左右拆分 | `Ctrl+\` | 将正文拆分为左右两个窗格，两边显示同一文档。 |
| 上下拆分 | `Ctrl+Shift+\` | 将正文拆分为上下两个窗格，两边显示同一文档。 |
| 移到另一个窗格 | `F6`，或单击窗格 | 切换要操作的窗格。 |
| 关闭窗格 | `Ctrl+Shift+F4` | 关闭当前窗格，恢复为一个窗格。不会关闭文档。 |
| 更改窗格大小 | 拖动窗格之间的分界线 | 分界线随之移动。双击可恢复为相同大小。拖动过程中按 `Esc` 会恢复原状。 |

- 最多两个窗格。
- 切换标签页、新建标签页、打开文件和 `Ctrl+P`，都作用于当前操作的窗格。
- 也可以用 `F1` 命令列表中的“扩大窗格”“缩小窗格”“均分窗格”更改大小。每次移动的幅度可以在设置的“窗格调整幅度”（默认为 5）中更改。
- 窗格的拆分方式和大小保持到关闭窗口为止。下次启动时会恢复为一个窗格。

## 在“Vim”模式下

在“Vim”模式下，除了上面的按键之外，也可以用与 Vim 相同的命令完成相同的操作。详细内容请参阅“[Vim 编辑](03-vim.md)”一章。

| 任务 | Vim 命令 |
|---|---|
| 切换标签页 | `gt`、`gT`，`:tabnext`、`:tabprevious` |
| 打开或关闭标签页 | `:tabnew`、`:tabclose` |
| 以列表查看已打开的标签页 | `:tabs`，`:ls`、`:files`、`:buffers`，`:b`（如 `:b memo`，接着输入即可筛选） |
| 打开文件列表 | `:e`（与 `Ctrl+P` 相同的列表） |
| 在整个项目中查找 | 在 `:grep` 后接要查找的文字 |
| 拆分、切换或关闭窗格 | `Ctrl+W` `s`、`Ctrl+W` `v`、`Ctrl+W` `w`、`Ctrl+W` `c`、`Ctrl+W` `o`、`:only` 等 |
| 更改窗格大小 | `Ctrl+W` `>`、`Ctrl+W` `<`、`Ctrl+W` `+`、`Ctrl+W` `-`、`Ctrl+W` `=`，`:resize`、`:vertical resize` |

## 尚不支持的功能

- 暂时还不能通过拖动标签页来调整顺序。
- 窗口的位置和大小不会保留到下次启动。
- 在资源管理器中，不能重命名、删除文件或新建文件。
- 其他应用更改了文件夹的内容时，在重新展开该文件夹之前，资源管理器中不会反映这些更改。
- 任务栏的跳转列表（右键单击任务栏图标时显示的列表）中，暂时还不显示历史记录和书签。

## 深入了解：列表与查找的上限

| 项目 | 上限与规则 |
|---|---|
| `Ctrl+P` 列表中同一文件夹的文件 | 读取到 8,192 个时会显示一条消息，直到关闭列表为止（另请参阅下面的列表项）。 |
| `Ctrl+P` 列表的预览栏 | 未打开的文件最多读取 16 MiB。超过此大小的文件和非文本文件会显示“不预览”。 |
| 历史记录 | 最多 100 个。存放在 `%LOCALAPPDATA%\NeNeNib\history.v1` 中。 |
| 书签 | 最多 1,024 个。存放在 `%LOCALAPPDATA%\NeNeNib\bookmarks.v1` 中。 |
| 资源管理器 | 每个文件夹最多显示 2,000 项。无法读取的文件夹显示为“（无法读取）”。 |
| 项目全文搜索跳过的内容 | 隐藏文件夹，`.git`、`node_modules`、`build`、`out` 文件夹，目录联接和指向文件夹的符号链接（两者都是类似快捷方式、指向其他位置文件夹的机制），超过 16 MiB 的文件，前 8 KiB 中含有 NUL（值为 0 的字符）的文件 |
| 项目全文搜索的数量 | 每行 1 处，总共最多 1,000 处 |
| 窗格大小每次调整的幅度 | 设置中的“窗格调整幅度”，1 到 40（另请参阅下面的列表项）。 |

- `Ctrl+P` 列表中同一文件夹的文件，不会显示隐藏文件、系统文件以及已知不是文本的文件类型。没有扩展名的文件和扩展名未知的文件会显示。
- 读写书签失败时，会保留之前的列表，并显示一行消息。
- 窗格大小每次调整的幅度，也可以用 `:set paneresizestep=` 更改。
- “Vim”模式下的 `Ctrl+W` `>`、`<`、`+`、`-`，不加次数时，与 Vim 一样只移动一个字符（或一行）。设置 `:set paneresizestepvim` 后，会跟随“窗格调整幅度”。
