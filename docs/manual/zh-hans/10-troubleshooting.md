# 疑难解答

本章以“出现这种情况 → 这样处理”的形式，汇总刚开始使用 NeNe Nib 时常遇到的问题及其解决方法。其他章节已说明的内容只作简要介绍，并指引到相应章节。

> 遇到问题时，请先查看状态栏左侧。如果显示 `NORMAL` 或 `VISUAL`，说明处于“Vim”模式。按 `Ctrl+Shift+Space` 可以返回“标准”模式。

## 输入文字后没有反应

可能处于“Vim”模式的 NORMAL。在 NORMAL 下，按键不会输入文字，而是作为 Vim 命令执行。

- 按 `Ctrl+Shift+Space` 返回“标准”模式后，就可以像在记事本中一样编辑。
- 要在“Vim”模式下继续编辑，请按 `i` 进入 INSERT。按 `Esc` 返回 NORMAL。
- 输入法正在组字（尚未上屏）时，`Ctrl+Shift+Space` 无效。请先确认或取消输入，然后再按。
- 在“Vim”模式的 NORMAL 下，输入法会自动关闭。进入 INSERT 后恢复。

模式的辨别方法在“[安装与首次启动](01-install.md)”一章中说明，“Vim”模式的用法在“[Vim 编辑](03-vim.md)”一章中说明。

## 按 `Ctrl+O` 无法打开文件

“Vim”模式下的 `Ctrl+O` 是返回上一个位置的 Vim 按键。

- 在“Vim”模式下打开文件的按键是 `Ctrl+Shift+O`。
- 也可以在 `F1` 命令列表中选择“打开文件”。
- 返回“标准”模式后，按 `Ctrl+O` 会打开“打开”对话框。

## 没有打印的按键

NeNe Nib 的 `Ctrl+P` 不是打印，而是打开“文件和标签页列表”的按键。打印没有分配按键。

- 在 `F1` 命令列表中选择“打印”，即可选择打印机并打印。
- 在“Vim”模式下，也可以用 `:hardcopy` 打印。
- 可以打印的文档最大为 16 MiB。

## 找不到时的消息以英语显示

查找的消息与 Vim 相同，以英语显示。即使把界面语言设为英语以外的语言，也不会改变。主要消息的含义如下。

| 窗口底部显示的消息 | 含义 |
|---|---|
| `E486: Pattern not found: 查找的文字` | 在文档中没有找到查找的文字。 |
| `search hit BOTTOM, continuing at TOP` | 已查找到文档末尾，因此返回开头继续查找。 |
| `search hit TOP, continuing at BOTTOM` | 已查找到文档开头，因此返回末尾继续查找（向前查找时）。 |
| `E385: Search hit BOTTOM without match for: 查找的文字` | 查找到末尾也没有找到（设置为在末尾停止时）。 |

找不到时，请确认以下几点。

- 查找时区分大小写。不区分大小写的查找方法在“[设置](08-settings.md)”一章中说明。
- 输入的文字按原样作为普通文字查找。
- Shift_JIS 文件的内容无法用项目的全文搜索（`Ctrl+Shift+F`）查找。在已打开的文档中查找则可以找到。

查找的用法在“[标准编辑](02-basic-editing.md)”一章中说明。

## 想把设置恢复为初始状态

只恢复某一项设置时，请使用在该设置名称后加 `&` 的命令。例如，自动换行的设置可以这样恢复。

| 模式 | 操作 |
|---|---|
| “标准”模式 | 按 `Ctrl+P` 后输入 `:`，接着输入 `set wrap&` 并按 `Enter`。 |
| “Vim”模式 | 在 NORMAL 下输入 `:set wrap&` 并按 `Enter`。 |

该设置会恢复为默认值。也可以在 `Ctrl+,` 的“设置”中把项目改回原来的值。命令的输入方法在“[设置](08-settings.md)”一章中说明。没有一次性恢复所有设置的命令。

要把所有设置恢复为初始状态，请重命名设置文件。这样不会删除文件，以后还可以恢复。

1. 关闭所有 NeNe Nib 窗口。
2. 在文件资源管理器的地址栏中输入 `%LOCALAPPDATA%\NeNeNib` 并打开。
3. 重命名所有以 `settings.v` 开头的文件（`settings.v6`、`settings.v5` 等）。例如，将 `settings.v6` 改为 `settings.v6.bak`。
4. 启动 NeNe Nib。设置会变为默认值。

- 没有 `settings.v6` 时，NeNe Nib 会读取旧版本的设置文件（`settings.v5` 等）。因此，请重命名所有以 `settings.v` 开头的文件。
- 要恢复原来的设置，请先关闭 NeNe Nib，然后把文件名改回原样。
- 上次的标签页、最近关闭的文件和书签保存在其他文件中，因此会保留下来。
- 如果要连同这些内容一起恢复为首次启动时的状态，请重命名 `NeNeNib` 文件夹（例如改为 `NeNeNib.bak`），而不是文件。要恢复时，请先删除新创建的 `NeNeNib` 文件夹，再把名称改回 `NeNeNib`。
- 对于 Store 版，Windows 有时会把此文件夹放在应用专用的存储位置。如果已经有 ZIP 版的文件夹，Store 版有时也会使用该文件夹。详情在“[安装与首次启动](01-install.md)”一章的末尾说明。

如果启动时显示“设置文件的格式不正确。原设置文件保持不变。”这样的消息，说明设置文件已损坏。在此期间更改的设置不会保存。请按上面的步骤重命名设置文件，或修正设置文件后，重新启动 NeNe Nib。

## 异常退出了

NeNe Nib 每 30 秒会将未保存的更改备份到其他位置。异常退出后启动时，只会询问一次“上次有未保存的编辑。是否恢复？”。

| 回答 | 结果 |
|---|---|
| 是 | 将备份的文档恢复到标签页中。恢复的标签页处于未保存状态（标签页名称前带有“● ”），请按 `Ctrl+S` 保存。没有名称的文档会恢复为“无标题”标签页。 |
| 否 | 丢弃备份的文档。以后无法再恢复。 |

- 可以恢复的是到最后一次备份为止的更改。在强制退出或断电时，最后一次备份之后的更改（最多 30 秒）会丢失。
- NeNe Nib 因意外错误而退出时，会在退出前再备份一次。
- 超过 64 MiB 的文档不会备份。详情在“[大文件与字符编码](09-large-files-and-encodings.md)”一章中说明。
- 备份的文件放在 `%LOCALAPPDATA%\NeNeNib\autosave` 中。正常关闭后会删除。

## 出现乱码

NeNe Nib 会自动识别打开的文件的字符编码。打开时没有重新选择字符编码的操作。

- 支持的字符编码为 UTF-8、UTF-8（带 BOM）、Shift_JIS、UTF-16（带 BOM）。EUC-JP 文件会作为 Shift_JIS 打开，JIS（ISO-2022-JP）文件会作为 UTF-8 打开，因此会出现乱码。
- 不支持 GBK／GB18030。如需打开这类文件，请先用其他软件将其转换为 UTF-8。
- 显示“无法识别编码。”而无法打开时，也说明是不支持的字符编码的文件。

支持的字符编码和识别方法，在“[大文件与字符编码](09-large-files-and-encodings.md)”一章中说明。

## Store 版与 ZIP 版的区别

其中的可执行文件是相同的。区别如下。

| | Microsoft Store 版 | GitHub 的 ZIP 版 |
|---|---|---|
| 更新到新版本 | 通过 Store 自动更新。 | 不会自动更新。请从 Release 页面重新下载新的 ZIP。 |
| 添加到文件资源管理器的右键菜单 | 不支持。`F1` 命令列表中也不显示。 | 可以通过 `F1` 命令列表中的“添加到 Windows 右键菜单”添加。 |
| 设置和记录的存放位置 | Windows 有时会放在应用专用的存储位置。这种情况下，卸载后会删除。 | `%LOCALAPPDATA%\NeNeNib`。 |

ZIP 版的 exe 没有签名（用于确认发布者的电子标记）。

安装方法在“[安装与首次启动](01-install.md)”一章中说明。

## 报告问题

如果发现问题，或对用法有不明白的地方，请在 GitHub 的 [NeNe Nib Issue 页面](https://github.com/hideyukiMORI/nene-nib/issues)中提出。提出 Issue 需要 GitHub 账户。

如果写明以下内容，就能更快地查明原因。

- NeNe Nib 的版本（在 `F1` 命令列表中选择“关于 NeNe Nib”，版本会显示在状态栏中）
- 是 Store 版还是 ZIP 版
- Windows 的版本
- 是“标准”模式还是“Vim”模式
- 做了什么操作、出现了什么结果，以及本来期望的结果

NeNe Nib 没有自动发送问题信息的机制。应用本身不连接网络，因此只要不写在 Issue 中，开发者就不会知道。

Issue 页面任何人都可以查看。粘贴文档内容或屏幕截图时，请确认其中没有不想被他人看到的信息。

## 深入了解：无法打开或保存文件时的消息

| 消息 | 原因 |
|---|---|
| 找不到文件。 | 文件已被移动或删除。 |
| 没有打开该文件的权限。 | Windows 的权限不允许读取该文件。 |
| 无法打开超过 1 GB 的文件。 | 超过了可以打开的大小（1 GiB）。 |
| 无法打开超过 64 MiB 的 Shift_JIS / UTF-16 文件。 | 超过了 Shift_JIS 和 UTF-16 可以打开的大小。 |
| 无法识别编码。 | 是不支持的字符编码的文件。 |
| 不支持 UTF-32 文件。请另存为 UTF-8 或 UTF-16。 | 不支持 UTF-32。 |
| 内存不足，无法打开文件。 | 电脑的内存不足。请关闭其他应用后重新打开。 |
| 无法保存文件。原文件未更改。 | 由于保存位置不允许写入等原因，无法保存。原文件保持不变。 |
| 部分字符无法以此编码保存。是否以 UTF-8 保存？ | 有无法以所选字符编码写入的字符。选择“是”会以 UTF-8 保存。 |

使用手册的目录见“[NeNe Nib 使用手册](README.md)”。
