# 标准编辑

当状态栏左侧显示 `标准` 时，NeNe Nib 处于“标准”模式，可以使用与记事本相同的按键进行编辑。本章先介绍与记事本相同的地方，再介绍 NeNe Nib 特有的地方。“Vim”模式的操作在“Vim 编辑”一章中介绍。

> 如果输入的文字没有出现在文档中，可能处于“Vim”模式。按 `Ctrl+Shift+Space` 即可返回“标准”模式。

## 选择文字

| 任务 | 操作 | 结果 |
|---|---|---|
| 选择范围 | 按住 `Shift` 并按方向键 | 随光标移动选中文字。 |
| 用鼠标选择范围 | 拖动 | 选择拖动经过的范围。也可以从后往前拖动。拖动到正文区域之外时，正文会向该方向滚动。 |
| 扩展当前选择 | 按住 `Shift` 并单击 | 保留选择的起点，选择到单击的位置为止。 |
| 放置光标 | 单击 | 光标移到单击的位置。 |
| 选择单词 | 双击 | 选择单击处的单词。 |
| 选择行 | 三击 | 选择单击处的行。 |
| 全选 | `Ctrl+A` | 选择整个文档。 |
| 取消选择 | `Esc` | 取消选择。 |

## 复制、剪切、粘贴和撤销

| 任务 | 按键 | 结果 |
|---|---|---|
| 复制 | `Ctrl+C`（或 `Ctrl+Insert`） | 将所选文字复制到剪贴板。 |
| 剪切 | `Ctrl+X`（或 `Shift+Delete`） | 将所选文字移到剪贴板。 |
| 粘贴 | `Ctrl+V`（或 `Shift+Insert`） | 粘贴剪贴板中的内容。 |
| 粘贴为纯文本 | `Ctrl+Shift+V` | 只粘贴剪贴板中的文本。 |
| 撤销 | `Ctrl+Z` | 撤销上一次编辑。 |
| 重做 | `Ctrl+Y`（或 `Ctrl+Shift+Z`） | 重新执行已撤销的编辑。 |

`Ctrl+V` 和 `Ctrl+Shift+V` 的区别，将在下面的“粘贴网页中的文字”中说明。

## 右键菜单

在正文中右键单击，会显示“剪切”“复制”“粘贴”“删除”“全选”“查找”“替换”菜单。也可以按 `Shift+F10` 或键盘上的菜单键打开。

## 移动光标

| 任务 | 按键 | 结果 |
|---|---|---|
| 逐字移动 | `←`、`→` | 每次移动一个字符。 |
| 移到上一行或下一行 | `↑`、`↓` | 每次移动屏幕上的一行。 |
| 移到行首或行尾 | `Home`、`End` | 移到屏幕行的行首或行尾。 |
| 逐屏移动 | `PgUp`、`PgDn` | 每次翻动一屏，光标也移动相同的距离。 |
| 移到文档开头或末尾 | `Ctrl+Home`、`Ctrl+End` | 移到文档的开头或末尾。 |
| 按单词移动 | `Ctrl+←`、`Ctrl+→` | 在单词边界处停下。 |

长行默认按窗口宽度自动换行显示。自动换行只影响显示，不会在正文中插入换行符。`↑`、`↓`、`Home`、`End` 会把自动换行后屏幕上的一行当作一行来移动。

单词边界的判断方式与记事本相同。

- `Ctrl+→` 会越过单词及其后面的空白，停在下一个单词的开头。在行尾时，会在换行符前停一次。
- `Ctrl+←` 按相反方向移动。
- 对于日文，会在汉字、平假名、片假名等文字种类变化的地方停下。连续的汉字视为一个单词。
- `_` 视为符号，因此在 `foo_bar` 中会在 `_` 的前后停下。双击时，会将整个 `foo_bar` 作为一个单词选择。

### 文档边缘以及有选择时的行为

这些行为与 Windows 的标准一致：

- 光标在文档最后一行（自动换行时为其最后一个屏幕行）时按 `↓`，会移到文档末尾。
- 光标在文档第一行（自动换行时为其第一个屏幕行）时按 `↑`，会移到文档开头。
- 有选择范围时，不按 `Shift` 直接按 `←`，光标会移到选择的起点并取消选择。按 `→` 则移到选择的终点。
- 有选择范围时，`↑`、`Home`、`PgUp` 从选择的起点开始移动，`↓`、`End`、`PgDn` 从选择的终点开始移动。

## 删除

| 任务 | 按键 | 结果 |
|---|---|---|
| 删除光标前的字符 | `Backspace` | 删除前面的一个字符。 |
| 删除光标后的字符 | `Delete` | 删除后面的一个字符。 |
| 删除前一个单词 | `Ctrl+Backspace` | 删除到 `Ctrl+←` 停下的位置为止。 |
| 删除后一个单词 | `Ctrl+Delete` | 删除到 `Ctrl+→` 停下的位置为止。 |

- 有选择范围时，无论按哪个键，都会删除所选范围。
- 在行首按 `Ctrl+Backspace`，会删除与上一行之间的换行符。如果在缩进行的行首按，会将缩进、换行符以及上方的空行一并删除。按一次 `Ctrl+Z` 即可恢复。
- 在查找输入框和 `Ctrl+P` 列表中，暂时还不能按单词移动或删除。

## 粘贴网页中的文字

从浏览器或文字处理软件复制的文字，会同时以纯文本形式和包含标题、链接的 HTML 形式存入剪贴板。NeNe Nib 的 `Ctrl+V` 会根据当前打开的文档类型改变粘贴方式。

| 打开的文档 | 按 `Ctrl+V` 粘贴的内容 |
|---|---|
| Markdown（用 `#`、`**` 等符号表示标题和粗体的文档格式，如 `.md`） | 将 HTML 转换为 Markdown 后粘贴。标题变为 `#`，粗体变为 `**…**`，链接变为用 `[ ]` 括起文字、用 `( )` 括起目标的形式，项目符号列表变为 `- `。 |
| HTML、JavaScript、TypeScript | 连同标签一起粘贴 HTML。 |
| 其他文档 | 只粘贴文本。 |

- `Ctrl+Shift+V` 在任何文档中都只粘贴文本。不想把格式带入 Markdown 文档时使用。
- 无论在哪种文档中，如果想连同标签一起粘贴 HTML，请从 `F1` 命令列表中选择“粘贴 HTML 源代码”。此操作没有分配按键。
- 如果无法将 HTML 转换为 Markdown，则只粘贴文本。
- 无论使用哪种粘贴方式，按一次 `Ctrl+Z` 即可撤销粘贴。

## 查找、替换和转到行

| 任务 | 按键 | 结果 |
|---|---|---|
| 查找文字 | `Ctrl+F` | 窗口底部显示“查找：”。输入要查找的文字并按 `Enter`，会转到下一个匹配项。 |
| 查找下一个 | `F3` | 转到上次查找内容的下一个匹配项。 |
| 查找上一个 | `Shift+F3` | 转到上次查找内容的上一个匹配项。 |
| 替换 | `Ctrl+H` | 在“查找：”之后，接着询问要替换成的文字。 |
| 转到行 | `Ctrl+G` | 在“行：”中输入行号并按 `Enter`，会转到该行。 |
| 关闭输入框 | `Esc` | 关闭“查找：”等输入框。 |

<!-- 画面：“查找：”输入框和匹配项高亮颜色的截图（稍后补充） -->

### 查找

- 在输入过程中，就会在正文中标出匹配的位置。
- 匹配项会带有颜色，光标所在的匹配项用边框标出。
- 在“查找：”中按 `Enter`，不会关闭输入框，而是前进到下一个匹配项。完成后按 `Esc` 关闭。
- 输入的文字按原样查找。`.` 和 `*` 也按字符本身查找。
- 区分大小写。不区分大小写的查找方法在“设置”一章中介绍。
- 没有找到匹配项时，以及从文档末尾绕回开头继续查找时，窗口底部会以英语显示一行消息。

### 替换

1. 按 `Ctrl+H`。“查找：”中已填入上次查找的文字。
2. 确认要查找的文字后按 `Enter`。
3. 在“将（要查找的文字）替换为：”中输入要替换成的文字。
4. 按下面任意一个键。

| 按键 | 结果 |
|---|---|
| `Enter` | 替换当前一处，并转到下一个匹配项。继续按 `Enter`，可以逐个替换。 |
| `Ctrl+Enter` | 替换文档中的全部匹配项。按一次 `Ctrl+Z` 即可全部恢复。 |

替换后的文字也会按原样输入。

### 转到行

在“行：”中，用半角数字输入行号，或“行:列”的形式（如 `120:5`）。如果输入的行号大于文档的行数，会转到最后一行。

### 在“Vim”模式下

在“Vim”模式下，`Ctrl+F`、`Ctrl+H`、`Ctrl+G` 保持 Vim 中的作用。从 `F1` 命令列表中选择“查找”“替换”“转到行”，可以完成相同的操作。两种模式共用查找的文字，因此在“标准”模式下查找的文字，可以在“Vim”模式下用 `n` 继续查找。

## 其他与记事本相同的操作

| 任务 | 操作 | 结果 |
|---|---|---|
| 插入日期和时间 | `F5` | 在光标位置插入当前的日期和时间。 |
| 放大或缩小文字 | `Ctrl++`、`Ctrl+-`、按住 `Ctrl` 并滚动鼠标滚轮 | 在 8 到 40 pt 之间，以 0.5 pt 为单位更改正文的字号。 |
| 恢复文字大小 | `Ctrl+0` | 将正文文字恢复为默认大小。 |
| 打印 | 从 `F1` 命令列表中选择“打印” | 选择打印机并打印当前文档。 |

打印没有分配按键。记事本的 `Ctrl+P` 是打印，而 NeNe Nib 的 `Ctrl+P` 是打开“文件和标签页列表”的按键。

## 深入了解：带有重音符号或浊点的字符

有些字符是把重音符号或浊点作为另一个字符附加在后面写成的。例如，在“か”后面放一个组合用浊点，使其显示为“が”。用于为人名汉字等选择字形的异体字选择器，也同样附加在前一个字符的后面。

在“标准”模式下，这类字符按以下方式处理。

| 按键 | 结果 |
|---|---|
| `←`、`→` | 把原字符与后面附加的重音符号、浊点和第一个异体字选择器作为一个字符整体越过。 |
| `Delete` | 一次删除同一组字符。后面接着的异体字选择器也一起删除。 |
| `Backspace` | 逐个删除重音符号或浊点。对于“が”，只删除浊点，保留“か”。异体字选择器与其前面的字符一起删除。 |

通过组合显示为一个的表情符号（如家庭表情符号）、更改了肤色的表情符号和国旗，暂时还不会作为一个字符处理。
