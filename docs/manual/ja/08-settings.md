# 設定

NeNe Nib の設定は、2 つの方法で変えられます。1 つは `Ctrl+,` で右に開く「設定」で、項目を見ながらマウスやキーで変えられます。もう 1 つは `:set` などの命令で、「設定」に無い項目も変えられます。この章では、両方の使い方と主な設定の一覧を説明します。

> 「設定」に無い項目（大文字と小文字を区別しない検索など）は、`:set` の命令で変えます。「通常」モードでも、`Ctrl+P` を押してから `:` を打つと命令を使えます。

## 「設定」を使う

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| 「設定」を開く | `Ctrl+,`（または `F1` の一覧から「設定」） | ウィンドウの右に「設定」が開きます。本文は隠れません。 |
| 項目を選ぶ | `↑`・`↓`（または `Tab`） | 選んだ項目に枠が付きます。 |
| オンとオフを切り替える | `Space` を押すか、スイッチをクリック | すぐに切り替わります。 |
| 値を 1 つずつ変える | `←`・`→` | 配色や文字の大きさなどの値が、前後の値に変わります。 |
| 値の一覧から選ぶ | 値をクリックするか、`Enter`・`Space`・`Alt+↓`・`F4` | 一覧が開きます。`↑`・`↓` で選んで `Enter` を押すと、その値になります。 |
| 節へ移動する | `Ctrl+1`〜`Ctrl+6` | 「表示」「文字」「編集」「パネル」「機能」「言語サーバー」の節へ移動します。 |
| 項目を探す | 上の「設定を探す」に文字を打つ | 名前・説明・`:set` の名前に合う項目だけが残ります。 |
| 開いたときの設定に戻す | 「元に戻す」を押す | 「設定」を開いたときの状態に戻ります。 |
| 閉じる | `Esc`・`Ctrl+,`・「閉じる」・✕、または「設定」の外をクリック | 閉じて、設定を保存します。 |

- 変えた設定は、その場で画面に表れます。保存するのは閉じるときです。
- 本文をクリックしたり、文字を打ったり、タブを切り替えたりしても、「設定」は閉じて保存します。本文の上のホイールでのスクロールと `Ctrl` を押しながらのホイールでは閉じません。
- 項目を探している間の `Space` は、探す文字の空白になります。
- 値の一覧は 10 行まで見え、今の値に ✓ が付きます。`Esc`・`Alt+↑`・`F4` で一覧だけを閉じます。`Tab` は選んでいる値に決めて一覧を閉じます。値の頭の文字を打つと、その文字で始まる値へ移動します。

### 節と項目

| 節 | 項目 |
|---|---|
| 表示 | 配色・表示言語・操作の案内・インデントガイドとその色や幅 |
| 文字 | 字体（フォントの名前。表示だけ）・文字の大きさ |
| 編集 | 折り返し・自動の字下げ・キャレット（文字を入れる位置を示す縦線。カーソルとも言います）の動き・キャレットの動きの時間・打ったときの粒 |
| パネル | エクスプローラー（画面の左に出る、ファイルをツリーで表示する欄。Windows のエクスプローラーとは別のもの）・`Ctrl+P` のプレビュー・枠を広げる・狭める量・「Vim の Ctrl-w の量」 |
| 機能 | 括弧の相手の強調（いつもオン）・ミニマップ・言語サーバー（LSP） |
| 言語サーバー | 言語ごとの言語サーバー（「言語サーバー」の章で説明します） |

### 速さへの影響

「機能」の節の上には、「いまの設定での 1 打鍵の見込み」が出ます。1 打鍵の見込みは、キーを 1 回打ってから画面に表れるまでの時間の見込みです。開発者の PC で測った基準の時間に、オンにしている機能の分を足して示します。機能の行には、速さへの影響の大きさが ● の数で出ます。● の数も、開発者の PC で測った数字から決めています。お使いの PC で測った時間ではありません。

その下の 3 つのボタンで、機能をまとめて切り替えられます。

| ボタン | どうなるか |
|---|---|
| 速さ優先 | 速さに影響しない機能だけをオンにします。 |
| おすすめ | 影響の小さい機能までをオンにします。はじめはこの状態です。 |
| 全部オン | 機能を全部オンにします。 |

## `:set` の命令を使う

命令は、モードによって打つ場所が違います。

| モード | 打ち方 |
|---|---|
| 「Vim」モード | NORMAL で `:` を押すと、画面の下に `:` が出ます。続けて `set ignorecase` のように打って `Enter` を押します。 |
| 「通常」モード | `Ctrl+P` を押してから `:` を打つと、命令の一覧が出ます。続けて `set ignorecase` のように打つと一覧が絞られるので、`Enter` を押します。 |

`Ctrl+P` の `:` の一覧は「Vim」モードでも使えます。命令をすべて覚えていなくても、`:set` と打てば、使える命令が並びます。`:set scrolloff=3` のように値を付けた命令も、そのまま打って `Enter` で使えます。

- 「Vim」モードの `:` の行では、`Tab`・`Shift+Tab` で命令やテーマの名前を補えます。`Esc` で打つのをやめます。
- `:set ignorecase?` のように最後に `?` を付けると、今の値が出ます。
- `:set ignorecase&` のように最後に `&` を付けると、既定値に戻ります。
- `:set ic scs` のように、1 行に 2 つ以上の設定を並べられます。
- 多くの設定は、`ic`（`ignorecase`）のような Vim と同じ短い名前でも打てます。
- `:set` の命令はすぐに効きます。保存する設定は、その場で保存します。

## 大文字と小文字を区別しないで探す

はじめは、検索で大文字と小文字を区別します。区別しないで探すときは、`ignorecase` をオンにします。この設定は「設定」の画面にも `F1` の一覧にも無いので、命令で変えます。

### 「通常」モードで変える

1. `Ctrl+P` を押します。
2. `:set ignorecase` と打ちます。一覧に「set ignorecase」が残ります。
3. `Enter` を押します。

これで、`Ctrl+F`・`F3`・`Shift+F3` と、`Ctrl+H` の置換で探す文字が、大文字と小文字を区別しなくなります。元に戻すときは、同じ手順で `:set noignorecase` を選びます。

### 「Vim」モードで変える

NORMAL で `:set ignorecase`（短く `:set ic`）と打って `Enter` を押します。`/`・`?`・`n`・`N` の検索が、大文字と小文字を区別しなくなります。元に戻すときは `:set noignorecase`（`:set noic`）です。

### 大文字を打ったときだけ区別する（smartcase）

`ignorecase` に加えて `smartcase`（短く `scs`）もオンにすると、探す文字に大文字が 1 つでもあるときだけ区別します。たとえば `nib` は `Nib` にも `NIB` にも一致し、`Nib` は `Nib` にだけ一致します。`smartcase` は、`ignorecase` がオンのときだけ働きます。

| 探す文字 | `ignorecase` だけ | `ignorecase` と `smartcase` |
|---|---|---|
| `nib` | `nib`・`Nib`・`NIB` に一致する | `nib`・`Nib`・`NIB` に一致する |
| `Nib` | `nib`・`Nib`・`NIB` に一致する | `Nib` にだけ一致する |

どちらも保存され、次の起動でもそのままです。`Ctrl+Shift+F` のプロジェクトの検索は、この設定にかかわらず、打った文字をいつも大文字と小文字を区別しないで探します。

## 主な設定の一覧

「「設定」の項目」の列に名前がある設定は、「設定」の画面からも変えられます。

### 検索

| やりたいこと | 命令 | 「設定」の項目 | 既定値 |
|---|---|---|---|
| 大文字と小文字を区別しないで探す | `:set ignorecase`（`ic`） | なし | オフ |
| 大文字を打ったときだけ区別する | `:set smartcase`（`scs`） | なし | オフ |
| 「Vim」モードの検索で、見つかったところすべてに色を付ける | `:set hlsearch`（`hls`）・`:set nohlsearch` | なし | オン |
| 「Vim」モードの検索で、打っている間から見つかるところを示す | `:set incsearch`（`is`）・`:set noincsearch` | なし | オン |
| 「Vim」モードの検索で、文書の末尾まで探したら先頭へ戻って探し続ける | `:set wrapscan`（`ws`）・`:set nowrapscan` | なし | オン |

### 表示

| やりたいこと | 命令 | 「設定」の項目 | 既定値 |
|---|---|---|---|
| 長い行を折り返す | `:set wrap`・`:set nowrap` | 折り返し | オン |
| 行番号をキャレットの行からの行数で出す | `:set relativenumber`（`rnu`） | なし | オフ |
| キャレットの上下に、いつも N 行を見えるように残す | `:set scrolloff=3`（`so=3`） | なし | 0 |
| 空の文書とステータスバーに操作の案内を出す | `:set guide`・`:set noguide` | 操作の案内 | オン |
| 画面の言語を変える | `:set language=ja`・`en`・`zh-hans`・`system` | 表示言語 | Windows に合わせる |
| テーマを変える | `:colorscheme 名前` | 配色 | Windows に合わせる |
| 文字の大きさを変える | `:set fontsize=18` | 文字の大きさ | 13.5 pt |
| フォントを変える | `:set guifont=名前:h大きさ` | なし（「字体」は表示だけ） | Cascadia Code |
| 左にエクスプローラーを出す | `:set explorer`・`:set noexplorer` | エクスプローラー | オフ |

### 編集と機能

| やりたいこと | 命令 | 「設定」の項目 | 既定値 |
|---|---|---|---|
| 「Vim」モードで改行したとき、前の行の字下げをコピーする | `:set autoindent`（`ai`） | 自動の字下げ | オフ |
| 言語サーバーを使う | `:set lsp`・`:set nolsp` | 言語サーバー（LSP） | オフ |
| 「Vim」モードのコピーと貼り付けで Windows のクリップボードを使う | `:set clipboard=unnamed` | なし | オフ |

ここに挙げた設定は保存され、次の起動でもそのままです。ただし、次の 4 つは保存されません。次に起動すると既定値に戻ります。

- `hlsearch`
- `incsearch`
- `wrapscan`
- `clipboard`

- `scrolloff` は 0〜999 の数で、「通常」モードと「Vim」モードの両方で働きます。
- `autoindent` が働くのは、「Vim」モードの INSERT の改行と、`o`・`O`・`cc`・`S` です。
- テーマ・文字の大きさ・フォント・折り返し・行番号・演出の設定は、「テーマと見た目」の章で説明しています。
- 表示言語は、`F1` の一覧の「表示言語を選ぶ」からも変えられます。`:set language?` で、今の設定と、実際に使っている言語が出ます。
- `:set number` と `:set nonumber` は使えません。行番号はいつも出ています。

## 設定の保存

- 「設定」で変えた設定は、「設定」を閉じるときに保存します。
- `:set` や `:colorscheme` で変えた設定は、その場で保存します。
- 保存できなかったときは、1 行のメッセージが出ます。「設定」を閉じるときに保存できなかったときは、ウィンドウを閉じるときにもう一度保存します。
- 設定は `%LOCALAPPDATA%\NeNeNib` の `settings.v6` に保存します。場所は「インストールと初回起動」の章の終わりで説明しています。

## 詳しく知りたい人へ: 設定ファイルと古いバージョン

- `settings.v6` が無いときは、1.1.0 の `settings.v5`、1.0.0 の `settings.v4` の順に、古いバージョンの設定ファイルを読みます。読んだ古いファイルは書き換えず、最初に設定を変えたときに `settings.v6` を作ります。
- `settings.v6` ができた後に 1.1.0 で設定を変えると、その変更は `settings.v5` に入るので、1.2.0 には届きません。逆も同じです。
- 設定ファイルの大きさの上限は 16 KiB です。
- 設定ファイルが壊れていると、メッセージを出して元の設定のまま起動し、直して起動し直すまで設定を保存しません。
- 「Vim」モードの `:map` で作ったキーの割り当ても、`settings.v6` に保存します。
