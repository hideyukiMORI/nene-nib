# 困ったとき

この章では、NeNe Nib を使いはじめた人がよくつまずくところと、その直し方を「こうなった → こうする」の形でまとめます。ほかの章で説明していることは短く書き、その章へ案内します。

> 困ったときは、まずステータスバーの左を見てください。`NORMAL` や `VISUAL` と出ていれば「Vim」モードです。`Ctrl+Shift+Space` で「通常」モードに戻れます。

## 文字を打っても入らない

「Vim」モードの NORMAL になっているかもしれません。NORMAL では、打ったキーが文字ではなく Vim の命令として働きます。

- `Ctrl+Shift+Space` を押すと「通常」モードに戻り、メモ帳と同じように書けます。
- 「Vim」モードのまま書くときは、`i` を押して INSERT にします。`Esc` で NORMAL に戻ります。
- 日本語の変換中は、`Ctrl+Shift+Space` は効きません。変換を確定するか取り消してから押してください。
- 「Vim」モードの NORMAL では、日本語の入力が自動でオフになります。INSERT に入ると戻ります。

モードの見分け方は「[インストールと初回起動](01-install.md)」、「Vim」モードの使い方は「[Vim の操作](03-vim.md)」の章で説明しています。

## `Ctrl+O` でファイルが開かない

「Vim」モードの `Ctrl+O` は、前にいた位置へ戻る Vim のキーです。

- 「Vim」モードでファイルを開くキーは `Ctrl+Shift+O` です。
- `F1` の一覧から「ファイルを開く」を選んでも開けます。
- 「通常」モードに戻せば、`Ctrl+O` で［開く］ダイアログが開きます。

## 印刷のキーが無い

NeNe Nib の `Ctrl+P` は、印刷ではなく「ファイルとタブの一覧」を開くキーです。印刷にはキーが割り当てられていません。

- `F1` の一覧から「印刷」を選ぶと、プリンターを選んで印刷できます。
- 「Vim」モードでは、`:hardcopy` でも印刷できます。
- 印刷できるのは 16 MiB までの文書です。

## 検索で見つからないときのメッセージが英語で出る

検索のメッセージは、Vim と同じ英語の文で出ます。画面の言語を日本語にしていても変わりません。主なメッセージの意味は次のとおりです。

| 画面の下に出るメッセージ | 意味 |
|---|---|
| `E486: Pattern not found: 探した文字` | 探した文字が文書の中に見つかりませんでした。 |
| `search hit BOTTOM, continuing at TOP` | 文書の末尾まで探したので、先頭へ戻って探し続けました。 |
| `search hit TOP, continuing at BOTTOM` | 文書の先頭まで探したので、末尾へ戻って探し続けました（前を探したとき）。 |
| `E385: Search hit BOTTOM without match for: 探した文字` | 末尾まで探しても見つかりませんでした（末尾で止める設定のとき）。 |

見つからないときは、次の点を確かめてください。

- 大文字と小文字は区別して探します。区別しないで探す方法は「[設定](08-settings.md)」の章で説明します。
- 打った文字は、そのままの文字として探します。
- Shift_JIS のファイルの中身は、プロジェクトの全文検索（`Ctrl+Shift+F`）では探せません。開いた文書の中を探す検索なら探せます。

検索の使い方は「[通常の編集](02-basic-editing.md)」の章で説明しています。

## 設定を最初に戻したい

ひとつの設定だけを戻すときは、その設定の名前の後ろに `&` を付けた命令を使います。たとえば折り返しなら、次のようにします。

| モード | 操作 |
|---|---|
| 「通常」モード | `Ctrl+P` を押してから `:` を打ち、続けて `set wrap&` と打って `Enter` を押します。 |
| 「Vim」モード | NORMAL で `:set wrap&` と打って `Enter` を押します。 |

その設定が既定値に戻ります。`Ctrl+,` の「設定」で、項目を元の値に変え直してもかまいません。命令の打ち方は「[設定](08-settings.md)」の章で説明しています。全部の設定をまとめて戻す命令はありません。

全部の設定を最初に戻すときは、設定ファイルの名前を変えます。消さずに残しておくので、後から元に戻せます。

1. NeNe Nib のウィンドウを全部閉じます。
2. エクスプローラーのアドレスバーに `%LOCALAPPDATA%\NeNeNib` と打って開きます。
3. 名前が `settings.v` で始まるファイル（`settings.v6`・`settings.v5` など）の名前を、全部変えます。たとえば `settings.v6` を `settings.v6.bak` にします。
4. NeNe Nib を起動します。設定は既定値になります。

- `settings.v6` が無いと、NeNe Nib は古いバージョンの設定ファイル（`settings.v5` など）を読みます。そのため、`settings.v` で始まるファイルは全部の名前を変えてください。
- 元の設定に戻したいときは、NeNe Nib を閉じてから、名前を元に戻します。
- 前回のタブ・最近閉じたファイル・ブックマークは別のファイルに入っているので、そのまま残ります。
- これらも含めて初回起動のときの状態に戻すときは、ファイルではなく `NeNeNib` のフォルダの名前を変えます（`NeNeNib.bak` など）。元に戻すときは、新しくできた `NeNeNib` のフォルダを消してから、名前を `NeNeNib` に戻します。
- Store 版では、Windows がこのフォルダをアプリ専用の保存場所に置くことがあります。ZIP 版のフォルダがすでにあれば、Store 版でもそのフォルダを使うことがあります。詳しくは「[インストールと初回起動](01-install.md)」の章の終わりで説明しています。

起動したときに「設定ファイルの形式が正しくありません。元の設定は保持します。」のようなメッセージが出たときは、設定ファイルが壊れています。この間は設定を変えても保存されません。上の手順で設定ファイルの名前を変えるか、設定ファイルを直してから、NeNe Nib を起動し直してください。

## 異常終了した

NeNe Nib は、保存していない変更を 30 秒ごとに別の場所へ退避しています。異常終了した後で起動すると、「前回の未保存の編集が残っています。戻しますか。」と 1 回だけ聞かれます。

| 答え | どうなるか |
|---|---|
| はい | 退避していた文書を、タブに戻します。戻したタブは保存していない状態（タブ名の前に「● 」）なので、`Ctrl+S` で保存してください。名前の無い文書は「無題」のタブに戻ります。 |
| いいえ | 退避していた文書を捨てます。後から戻すことはできません。 |

- 戻せるのは、最後に退避したときまでの変更です。強制終了や電源断のときは、最後の退避の後の変更（最大 30 秒ぶん）は失われます。
- NeNe Nib が想定外のエラーで終わるときは、終わる直前にもう一度退避します。
- 64 MiB を超える文書は退避しません。詳しくは「[大きなファイルと文字コード](09-large-files-and-encodings.md)」の章で説明しています。
- 退避したファイルは、`%LOCALAPPDATA%\NeNeNib\autosave` に置きます。正常に閉じると消えます。

## 文字化けした

NeNe Nib は、開いたファイルの文字コードを自動で見分けます。開くときに文字コードを選び直す操作はありません。

- 扱えるのは UTF-8・UTF-8（BOM つき）・Shift_JIS・UTF-16（BOM つき）です。EUC-JP のファイルは Shift_JIS として、JIS（ISO-2022-JP）のファイルは UTF-8 として開くので、文字化けします。
- 「文字コードを判別できませんでした。」と出て開かないときも、扱えない文字コードのファイルです。

対応している文字コードと見分け方は、「[大きなファイルと文字コード](09-large-files-and-encodings.md)」の章で説明しています。

## Store 版と ZIP 版の違い

中の実行ファイルは同じです。違いは次のとおりです。

| | Microsoft Store 版 | GitHub の ZIP 版 |
|---|---|---|
| 新しいバージョンへの更新 | Store から自動で更新されます。 | 自動では更新されません。Release のページから新しい ZIP を取り直します。 |
| エクスプローラーの右クリックへの登録 | できません。`F1` の一覧にも出ません。 | `F1` の一覧の「Windows の右クリックに登録する」でできます。 |
| 設定と記録の置き場所 | Windows がアプリ専用の保存場所に置くことがあります。その場合は、アンインストールすると消えます。 | `%LOCALAPPDATA%\NeNeNib` です。 |

ZIP 版の exe には署名（配った人を確かめるための電子的な印）がありません。

インストールの方法は「[インストールと初回起動](01-install.md)」の章で説明しています。

## 不具合を知らせる

不具合を見つけたときや、使い方で分からないことがあるときは、GitHub の [NeNe Nib の Issue のページ](https://github.com/hideyukiMORI/nene-nib/issues)に書いてください。書くには GitHub のアカウントが要ります。

次のことが書いてあると、原因を早く調べられます。

- NeNe Nib のバージョン（`F1` の一覧から「バージョン情報」を選ぶと、ステータスバーに出ます）
- Store 版か ZIP 版か
- Windows のバージョン
- 「通常」モードか「Vim」モードか
- 何をしたら、どうなったか。本当はどうなってほしかったか

NeNe Nib には、不具合の情報を自動で送る仕組みはありません。アプリ自身はネットワークに接続しないので、Issue に書かない限り、開発者には届きません。

Issue のページは、誰でも読めます。文書の中身や画面の写真を貼るときは、人に見られて困る情報が写っていないか確かめてください。

## 詳しく知りたい人へ: ファイルを開けない・保存できないときのメッセージ

| メッセージ | 理由 |
|---|---|
| ファイルが見つかりませんでした。 | ファイルが移動されたか、消されています。 |
| ファイルを開く権限がありません。 | Windows の権限で、読むことが許されていません。 |
| 1 GB を超えるファイルは開けません。 | 開ける大きさ（1 GiB）を超えています。 |
| 64 MiB を超える Shift_JIS / UTF-16 は開けません。 | Shift_JIS と UTF-16 で開ける大きさを超えています。 |
| 文字コードを判別できませんでした。 | 扱えない文字コードのファイルです。 |
| UTF-32 のファイルは扱えません。UTF-8 か UTF-16 で保存し直してください。 | UTF-32 には対応していません。 |
| メモリが足りず、ファイルを開けませんでした。 | PC のメモリが足りません。ほかのアプリを閉じてから開き直してください。 |
| ファイルを保存できませんでした。元のファイルは変わっていません。 | 書き込みが許されていない場所などの理由で、保存できませんでした。元のファイルはそのまま残ります。 |
| この文字コードでは保存できない文字があります。UTF-8 で保存しますか。 | 選んだ文字コードで書けない文字があります。「はい」で UTF-8 で保存します。 |

手引きの目次は「[NeNe Nib の手引き](README.md)」にあります。
