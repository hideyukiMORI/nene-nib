# Markdown とプレビュー

Markdown（`#` や `**` などの記号で見出しや太字を書く文書の形式）の文書を書きながら、仕上がりをプレビューで確かめられます。この章では、プレビューの出し方、プレビューで表示できる書き方、Markdown の文書への貼り付けを説明します。

> プレビューを閉じたいときは、`Ctrl+Shift+M` を何回か押してください。押すたびに「右（下）の枠」→「全面」→「閉じる」の順に切り替わります。

## プレビューを出す

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| 本文と並べて見る | `Ctrl+Shift+M` | もう 1 つの枠（右、または下）にプレビューが出ます。左（下に出したときは上）には本文が残るので、書きながら確かめられます。 |
| 全面で見る | 並べて見ている間にもう一度 `Ctrl+Shift+M`、または `F1` の一覧から「Markdown プレビュー（全面）」 | 本文の場所の全部にプレビューを出します。タブの帯とステータスバーは残ります。 |
| 全面の前の表示に戻る | `Esc` | 全面のプレビューをやめて、全面にする前の表示に戻ります（表の下の箇条書き）。 |
| プレビューを閉じる | 全面で見ている間にもう一度 `Ctrl+Shift+M` | プレビューが閉じて、本文だけになります。並べた表示には戻りません。 |

- 並べて見ていたところから全面にしたときは、`Esc` で本文と並べたプレビューに戻ります。`F1` の一覧や `:preview full` でいきなり全面にしたときは、`Esc` でプレビューが閉じて本文だけになります。

<!-- 画面: 左に本文、右にプレビューを並べた写真（あとで入れる） -->

- 本文を書き換えると、少し後にプレビューも書き換わります。
- 本文をスクロールすると、プレビューも同じところへついてきます。
- プレビューの枠へは `F6` やクリックで移れません。「プレビューの枠には入れません」と出ます。
- 全面のプレビューでは、文字をドラッグや `Shift`＋矢印キーで選んで、`Ctrl+C` でコピーできます。編集はできません。文字を打つと「プレビュー中は編集できません。Esc で戻る」と出ます。
- 「Vim」モードでは、`:preview side`（並べて見る）・`:preview full`（全面）・`:preview off`（閉じる）でも切り替えられます。
- プレビューを次の起動で開いたままにすることはできません。起動したときは、いつも閉じています。

## プレビューで表示できるもの

プレビューは、CommonMark（Markdown の書き方を細かく決めた共通の仕様）に沿って文書を読みます。見出し・段落・太字・斜体・箇条書き・番号付きの箇条書き・引用・コード・リンク・画像のほか、次のものを表示できます。

| 書き方 | 例 | プレビューでの見え方 |
|---|---|---|
| 表 | `\| 名前 \| 値 \|` の行と、`\|---\|---\|` の区切りの行 | 横の罫線だけの表になり、見出しの行は太字になります（列のそろえ方は表の下の箇条書き）。 |
| 注意書き（GitHub の alert） | `> [!NOTE]` で始まる引用 | 左に色の付いた線を引き、1 行目に種類の名前を太字で出します。種類は `NOTE`・`TIP`・`IMPORTANT`・`WARNING`・`CAUTION` の 5 つで、名前は英語のままです。 |
| タスクリスト | `- [ ] まだ`・`- [x] 済み` | チェックボックスになります（下の「チェックボックスを切り替える」）。 |
| 取り消し線 | `~~消した文字~~` | 文字に線を引きます。 |
| URL をそのまま書いたもの | `https://example.com` | リンクになります。 |
| 文字参照（`&` と `;` で囲んだ名前で 1 文字を表す HTML の書き方） | `&copy;` など | HTML の名前付きの文字参照は、すべて対応する文字（`&copy;` なら ©）になります。 |
| front matter（文書の題名や日付などを書いておく、文書の先頭の欄） | 文書の先頭の `---` の行から次の `---` の行まで | 本文の見出しや段落としては読まず、1 色のまとまりとして表示します。 |
| 囲みのコード（`` ``` `` の行で前後を囲んだコード） | `` ``` `` の後ろに言語の名前を書いたコード | 本文と同じ構文の色分けで色を付けます。 |

表の区切りの行に `:---` と書くと左、`:---:` と書くと中央、`---:` と書くと右に、その列をそろえます。

### 囲みのコードの色

`` ``` `` の後ろの最初の言葉で、色を付ける言語を決めます。言語の名前（`python` など）、拡張子（`py`・`ts` など）、別の呼び名（`c++` など）が使えます。知らない言語と、言語を書いていないコードは、1 色のままです。

### 画像

PC の中にある画像のファイルは、文章の流れの中に表示します。

- 対応している形式は PNG・JPEG・GIF（最初の 1 コマだけ）・BMP です。
- 枠より大きい画像は、枠の幅に合わせて縮めます。小さい画像を大きくすることはありません。
- 画像の場所は、文書のフォルダからの相対パスか、ドライブから始まるパスで書きます。
- インターネット上の画像（`http`・`https` で始まるもの）は取りに行きません。読めない画像と一緒に、`[画像: 説明の文字]` と表示します。

### 広い表

枠より幅の広い表には、表の下に細いバーが出ます。次のどれかで、その表だけを横に送れます。

- バーをドラッグする
- バーの溝をクリックする
- 表の上で `Shift` を押しながらホイールを回す
- 表の上で横のホイール（またはタッチパッドの横の操作）を使う

## プレビューで操作する

### チェックボックスを切り替える

プレビューのチェックボックスをクリックすると、本文の `[ ]` と `[x]` が切り替わります。並べて見ているときも、全面で見ているときもできます。`Ctrl+Z` の 1 回で戻せます。

全面で見ているときは、本文のキャレットがあるタスクの行で `Space` を押しても切り替わります。その行にタスクが無いときは「この行にタスクはありません」と出ます。

### リンクを開く

プレビューのリンクをクリックすると、すぐには開かず、リンクのすぐ下に小さな確認の欄が出ます。欄には本当の行き先が出て、サーバーの名前の部分が太字になります。

<!-- 画面: リンクの下に出る確認の欄の写真（あとで入れる） -->

| 押すキー | どうなるか |
|---|---|
| `Enter` | リンクを開きます。 |
| `Esc` | 開かずに閉じます。 |
| `Ctrl+C` | 行き先をクリップボードへコピーします。 |

| 行き先 | 開き方 |
|---|---|
| `http`・`https` で始まるもの | 既定のブラウザで開きます。 |
| `mailto:` で始まるもの | 既定のメールのアプリで、新しいメールを書きます。 |
| テキストのファイル | NeNe Nib の新しいタブで開きます。 |
| プログラムや、種類の分からない行き先 | 開きません。「このリンクは開けません」と出るので、コピーして自分で確かめてください。 |

`#見出し` の形のリンク（同じ文書の中の見出しへのリンク）をクリックすると、確認の欄は出さず、本文のキャレットがその見出しの行へ移動します。見出しの名前の決め方は GitHub と同じです。見つからないときは「この文書にその見出しはありません」と出ます。「Vim」モードでは、`''` で移動する前の位置に戻れます。

## HTML を Markdown として貼り付ける

ブラウザやワープロからコピーした文章を Markdown の文書に `Ctrl+V` で貼ると、見出し・太字・リンク・箇条書きを Markdown の記号に直して貼ります。文字だけを貼りたいときは `Ctrl+Shift+V` を使います。詳しくは「[通常の編集](02-basic-editing.md)」の章の「ウェブページの文章を貼り付ける」を見てください。

## 構文の色分け

Markdown の文書の本文や、プログラムのファイルの色分けは、「[テーマと見た目](07-themes.md)」の章で説明します。プレビューの囲みのコードの色は、本文の `:syntax off` では消えません。

## まだできないこと

- プレビューの中の文字は検索できません。
- 別の文書の見出しへのリンク（`other.md#sec` の形）は、その文書を開くだけで、見出しへは移動しません。

## 詳しく知りたい人へ: プレビューの細かい決まり

| 項目 | 決まり |
|---|---|
| プレビューできる大きさ | 16 MiB までの文書です。それより大きいと「プレビューは 16 MiB までです」の形のメッセージが出ます。 |
| 解析の部品 | md4c 0.5.2 で読み、表示は NeNe Nib が自分で描きます。 |
| 囲みのコードの色 | 長いコードは 64 行ずつに分けて色を付けます。 |
| 見出しへのリンク | 見出しの名前を比べるとき、大文字と小文字を同じに扱うのは半角の英字だけです。全角の英字やギリシャ文字などの大文字は、見出しと同じ大文字でリンクに書いてください。 |
| 長い段落 | とても長い段落は、はじめて表示するときに少し時間がかかります。2 回目からは、スクロールしても止まりません。 |

- 見出しに全角の英字やギリシャ文字などの大文字があるとき、リンクでその文字を小文字で書くと、その見出しは見つかりません。
