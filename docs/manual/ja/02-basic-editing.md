# 通常の編集

ステータスバーの左が `通常` のとき、Nib はメモ帳と同じキーで書けます。この章では、メモ帳と同じところを先に、Nib ならではのところを後に説明します。Vim の操作は「Vim の操作」の章で説明します。

## 文字を選ぶ

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| 範囲を選ぶ | Shift を押しながら矢印のキー | キャレットの動いた分だけ選びます。 |
| マウスで範囲を選ぶ | ドラッグ | ドラッグした範囲を選びます。後ろから前へもドラッグできます。本文の外までドラッグすると、本文がその向きへスクロールします。 |
| 今の選択を広げる | Shift を押しながらクリック | 選択の始まりを残したまま、クリックした所まで選びます。 |
| キャレットを置く | クリック | クリックした所にキャレットが移ります。 |
| 語を選ぶ | ダブルクリック | クリックした語を選びます。 |
| 行を選ぶ | トリプルクリック | クリックした行を選びます。 |
| 全体を選ぶ | Ctrl+A | 文書の全体を選びます。 |
| 選択をやめる | Esc | 選択を外します。 |

## コピー・切り取り・貼り付け・元に戻す

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| コピーする | Ctrl+C（または Ctrl+Insert） | 選んだ文字をクリップボードへ写します。 |
| 切り取る | Ctrl+X（または Shift+Delete） | 選んだ文字をクリップボードへ移します。 |
| 貼り付ける | Ctrl+V（または Shift+Insert） | クリップボードの中身を貼ります。 |
| 文字だけを貼り付ける | Ctrl+Shift+V | クリップボードの文字だけを貼ります。 |
| 元に戻す | Ctrl+Z | 直前の編集を取り消します。 |
| やり直す | Ctrl+Y（または Ctrl+Shift+Z） | 取り消した編集をもう一度行います。 |

Ctrl+V と Ctrl+Shift+V の違いは、下の「ウェブページの文章を貼り付ける」で説明します。

## キャレットを動かす

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 1 文字ずつ動く | ← → | 1 文字ずつ動きます。 |
| 上下の行へ動く | ↑ ↓ | 画面の 1 行ずつ動きます。 |
| 行の頭と終わりへ動く | Home・End | 画面の行の頭と終わりへ動きます。 |
| 1 画面ずつ動く | PgUp・PgDn | 画面を 1 画面ずつ送り、キャレットも同じだけ動きます。 |
| 文書の頭と終わりへ動く | Ctrl+Home・Ctrl+End | 文書の頭と終わりへ動きます。 |
| 語ごとに動く | Ctrl+← → | 語の境目で止まります。 |

長い行は、はじめから画面の幅で折り返して表示します。折り返しは表示だけで、本文に改行は入りません。↑ ↓・Home・End は、折り返した画面の行を 1 行として動きます。

語の境目は、メモ帳と同じ決め方です。

- Ctrl+→ は、語とその後ろの空白を越えて、次の語の頭で止まります。行の終わりでは、改行の前で 1 回止まります。
- Ctrl+← は、その逆向きに動きます。
- 日本語は、漢字・ひらがな・カタカナのように文字の種類が変わる所で止まります。漢字が続く間は 1 語として扱います。
- `_` は記号として扱うので、`foo_bar` では `_` の前後で止まります。ダブルクリックでは `foo_bar` の全体を 1 語として選びます。

### メモ帳と同じ、端の行と選択の動き

Windows の標準に合わせて、次のように動きます。

- 最後の画面の行で ↓ を押すと、文書の終わりへ動きます。
- 最初の画面の行で ↑ を押すと、文書の頭へ動きます。
- 範囲を選んでいるときに Shift なしで ← を押すと、選択の始まりにキャレットが移って選択が外れます。→ なら選択の終わりへ移ります。
- 範囲を選んでいるときの ↑・Home・PgUp は選択の始まりから、↓・End・PgDn は選択の終わりから動きます。

## 消す

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| キャレットの前の文字を消す | Backspace | 前の 1 文字を消します。 |
| キャレットの後ろの文字を消す | Delete | 後ろの 1 文字を消します。 |
| 前の語を消す | Ctrl+Backspace | Ctrl+← で止まる所までを消します。 |
| 後ろの語を消す | Ctrl+Delete | Ctrl+→ で止まる所までを消します。 |

- 範囲を選んでいるときは、どのキーでも選んだ範囲を消します。
- 行の頭で Ctrl+Backspace を押すと、前の行との間の改行を消します。字下げした行の頭からなら、字下げと改行と、その上の空の行までをまとめて消します。Ctrl+Z の 1 回で戻ります。
- 検索の入力欄と Ctrl+P の一覧では、まだ語ごとに動いたり消したりできません。

## アクセントや濁点のついた文字

アクセントや濁点を、別の文字として後ろに付けて書いた文字があります。たとえば「か」の後ろに結合用の濁点を置いて「が」と見せる書き方です。人名の漢字などで字形を選ぶ異体字セレクタも、同じように前の文字の後ろに付きます。

Nib の通常のモードでは、こうした文字を次のように扱います。

| 押すキー | どうなるか |
|---|---|
| ← → | 元の文字と、後ろに付いたアクセント・濁点・最初の異体字セレクタを、まとめて 1 文字として越えます。 |
| Delete | 同じまとまりを 1 回で消します。続く異体字セレクタも一緒に消します。 |
| Backspace | アクセントや濁点を 1 つずつ外します。「が」なら濁点だけを消して「か」を残します。異体字セレクタは、その前の文字と一緒に消します。 |

つないで 1 つに見せる絵文字（家族の絵文字など）・肌の色を変えた絵文字・国旗は、まだ 1 文字として扱いません。

## ウェブページの文章を貼り付ける

ブラウザやワープロからコピーした文章には、文字だけのものと、見出しやリンクを含んだ HTML のものが、一緒にクリップボードに入っています。Nib の Ctrl+V は、開いている文書の種類によって貼り方を変えます。

| 開いている文書 | Ctrl+V で貼られるもの |
|---|---|
| Markdown（`.md` など） | HTML を Markdown に直して貼ります。見出しは `#`、太字は `**…**`、リンクは文字を `[ ]`、行き先を `( )` で囲んだ形、箇条書きは `- ` になります。 |
| HTML・JavaScript・TypeScript | HTML をタグごと貼ります。 |
| そのほかの文書 | 文字だけを貼ります。 |

- Ctrl+Shift+V は、どの文書でも文字だけを貼ります。Markdown の文書に見た目を持ち込みたくないときに使います。
- どの文書でも HTML をタグごと貼りたいときは、F1 の一覧から「HTML のまま貼り付け」を選びます。この操作にキーはありません。
- HTML を Markdown に直せなかったときは、文字だけを貼ります。
- 貼り付けは、どの貼り方でも Ctrl+Z の 1 回で戻せます。

## 検索・置換・行へ移動

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 文字を探す | Ctrl+F | 画面の下に「検索: 」と出ます。探す文字を打って Enter を押すと、次に見つかった所へ移ります。 |
| 次を探す | F3 | 最後に探した文字の、次に見つかった所へ移ります。 |
| 前を探す | Shift+F3 | 最後に探した文字の、前に見つかった所へ移ります。 |
| 置き換える | Ctrl+H | 「検索: 」に続けて、置き換える文字を聞きます。 |
| 行へ移動する | Ctrl+G | 「行: 」に行の番号を打って Enter を押すと、その行へ移ります。 |
| 入力欄を閉じる | Esc | 「検索: 」などの入力欄を閉じます。 |

### 探す

- 打っている間から、見つかる所を本文の中で見せます。
- 見つかった所には色が付き、キャレットのある所は枠で示します。
- 「検索: 」の Enter は、入力欄を閉じずに次の所へ進みます。終わったら Esc で閉じます。
- 打った文字は、そのままの文字として探します。`.` や `*` も、その文字そのものを探します。
- 大文字と小文字は区別します。
- 見つからないときと、文書の終わりから頭へ戻って探し続けたときは、画面の下に英語の 1 行で知らせます。

### 置き換える

1. Ctrl+H を押します。「検索: 」に前回探した文字が入っています。
2. 探す文字を確かめて Enter を押します。
3. 「置換後 (探す文字): 」に、置き換える文字を打ちます。
4. 次のどちらかを押します。

| 押すキー | どうなるか |
|---|---|
| Enter | 今の所を 1 つ置き換えて、次に見つかった所へ移ります。続けて Enter を押すと、1 つずつ置き換えていけます。 |
| Ctrl+Enter | 文書の中の全部を置き換えます。Ctrl+Z の 1 回で全部が戻ります。 |

置き換える文字も、そのままの文字として入ります。

### 行へ移動する

「行: 」には、行の番号か、「行:桁」の形（`120:5` など）を半角の数字で打ちます。文書より大きな番号を打つと、最後の行へ移ります。

### Vim のモードのとき

「Vim」では Ctrl+F・Ctrl+H・Ctrl+G は Vim の働きのままです。F1 の一覧から「検索」「置換」「行へ移動」を選ぶと、同じことができます。探した文字は 2 つのモードで共通で、「通常」で探した文字を「Vim」の `n` で続けて探せます。

## そのほかのメモ帳と同じ操作

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| 日付と時刻を入れる | F5 | 今の時刻と日付をキャレットの所に入れます。 |
| 文字を大きくする・小さくする | Ctrl + `+`・Ctrl + `-`・Ctrl を押しながらホイール | 本文の文字の大きさを 0.5 pt ずつ、8〜40 pt の間で変えます。 |
| 文字の大きさを戻す | Ctrl + `0` | 本文の文字を既定の大きさに戻します。 |
| 印刷する | F1 の一覧から「印刷」 | プリンターを選んで、今の文書を印刷します。 |
