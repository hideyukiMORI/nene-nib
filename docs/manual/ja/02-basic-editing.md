# 通常の編集

ステータスバーの左が `通常` のとき、NeNe Nib は「通常」モードで、メモ帳と同じキーで書けます。この章では、メモ帳と同じところを先に、NeNe Nib ならではのところを後に説明します。「Vim」モードの操作は「Vim の操作」の章で説明します。

> 文字を打っても入らないときは、「Vim」モードになっているかもしれません。`Ctrl+Shift+Space` を押すと「通常」モードに戻れます。

## 文字を選ぶ

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| 範囲を選ぶ | `Shift` を押しながら矢印キー | キャレット（文字を入れる位置を示す縦線）が移動した分だけ選びます。 |
| マウスで範囲を選ぶ | ドラッグ | ドラッグした範囲を選びます。後ろから前へもドラッグできます。本文の外までドラッグすると、本文がその向きへスクロールします。 |
| 今の選択を広げる | `Shift` を押しながらクリック | 選択の始まりを残したまま、クリックしたところまで選びます。 |
| キャレットを置く | クリック | クリックしたところにキャレットが移動します。 |
| 単語を選ぶ | ダブルクリック | クリックした単語を選びます。 |
| 行を選ぶ | トリプルクリック | クリックした行を選びます。 |
| 全体を選ぶ | `Ctrl+A` | 文書の全体を選びます。 |
| 選択を解除する | `Esc` | 選択を解除します。 |

## コピー・切り取り・貼り付け・元に戻す

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| コピーする | `Ctrl+C`（または `Ctrl+Insert`） | 選んだ文字をクリップボードへ写します。 |
| 切り取る | `Ctrl+X`（または `Shift+Delete`） | 選んだ文字をクリップボードへ移します。 |
| 貼り付ける | `Ctrl+V`（または `Shift+Insert`） | クリップボードの中身を貼ります。 |
| 文字だけを貼り付ける | `Ctrl+Shift+V` | クリップボードの文字だけを貼ります。 |
| 元に戻す | `Ctrl+Z` | 直前の編集を取り消します。 |
| やり直す | `Ctrl+Y`（または `Ctrl+Shift+Z`） | 取り消した編集をもう一度行います。 |

`Ctrl+V` と `Ctrl+Shift+V` の違いは、下の「ウェブページの文章を貼り付ける」で説明します。

## キャレットを移動する

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 1 文字ずつ移動する | `←`・`→` | 1 文字ずつ移動します。 |
| 上下の行へ移動する | `↑`・`↓` | 画面の 1 行ずつ移動します。 |
| 行頭・行末へ移動する | `Home`・`End` | 画面の行の行頭・行末へ移動します。 |
| 1 画面ずつ移動する | `PgUp`・`PgDn` | 画面を 1 画面ずつ送り、キャレットも同じだけ移動します。 |
| 文書の先頭・末尾へ移動する | `Ctrl+Home`・`Ctrl+End` | 文書の先頭・末尾へ移動します。 |
| 単語ごとに移動する | `Ctrl+←`・`Ctrl+→` | 単語の境目で止まります。 |

長い行は、はじめから画面の幅で折り返して表示します。折り返しは表示だけで、本文に改行は入りません。`↑`・`↓`・`Home`・`End` は、折り返した画面の 1 行を 1 行として移動します。

単語の境目は、メモ帳と同じ決め方です。

- `Ctrl+→` は、単語とその後ろの空白を越えて、次の単語の先頭で止まります。行末では、改行の前で 1 回止まります。
- `Ctrl+←` は、その逆向きに移動します。
- 日本語は、漢字・ひらがな・カタカナのように文字の種類が変わるところで止まります。漢字が続く間は 1 つの単語として扱います。
- `_` は記号として扱うので、`foo_bar` では `_` の前後で止まります。ダブルクリックでは `foo_bar` の全体を 1 つの単語として選びます。

### 文書の端と、選択しているときの動き

Windows の標準に合わせて、次のように動きます。

- キャレットが文書の最後の行（折り返しているときは、その最後の画面の行）にあるときに `↓` を押すと、文書の末尾へ移動します。
- キャレットが文書の最初の行（折り返しているときは、その最初の画面の行）にあるときに `↑` を押すと、文書の先頭へ移動します。
- 範囲を選んでいるときに `Shift` なしで `←` を押すと、選択の始まりにキャレットが移動して選択が解除されます。`→` なら選択の終わりへ移動します。
- 範囲を選んでいるときの `↑`・`Home`・`PgUp` は選択の始まりから、`↓`・`End`・`PgDn` は選択の終わりから移動します。

## 消す

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| キャレットの前の文字を消す | `Backspace` | 前の 1 文字を消します。 |
| キャレットの後ろの文字を消す | `Delete` | 後ろの 1 文字を消します。 |
| 前の単語を消す | `Ctrl+Backspace` | `Ctrl+←` で止まるところまでを消します。 |
| 後ろの単語を消す | `Ctrl+Delete` | `Ctrl+→` で止まるところまでを消します。 |

- 範囲を選んでいるときは、どのキーでも選んだ範囲を消します。
- 行頭で `Ctrl+Backspace` を押すと、前の行との間の改行を消します。字下げした行の行頭からなら、字下げと改行と、その上の空の行までをまとめて消します。`Ctrl+Z` の 1 回で戻ります。
- 検索の入力欄と `Ctrl+P` の一覧では、まだ単語ごとに移動したり消したりできません。

## ウェブページの文章を貼り付ける

ブラウザやワープロからコピーした文章は、文字だけの形と、見出しやリンクを含んだ HTML の形の両方で、クリップボードに入っています。NeNe Nib の `Ctrl+V` は、開いている文書の種類によって貼り方を変えます。

| 開いている文書 | `Ctrl+V` で貼られるもの |
|---|---|
| Markdown（`#` や `**` などの記号で見出しや太字を書く文書の形式。`.md` など） | HTML を Markdown に直して貼ります。見出しは `#`、太字は `**…**`、リンクは文字を `[ ]`、行き先を `( )` で囲んだ形、箇条書きは `- ` になります。 |
| HTML・JavaScript・TypeScript | HTML をタグごと貼ります。 |
| そのほかの文書 | 文字だけを貼ります。 |

- `Ctrl+Shift+V` は、どの文書でも文字だけを貼ります。Markdown の文書に見た目を持ち込みたくないときに使います。
- どの文書でも HTML をタグごと貼りたいときは、`F1` の一覧から「HTML のまま貼り付け」を選びます。この操作にはキーが割り当てられていません。
- HTML を Markdown に直せなかったときは、文字だけを貼ります。
- 貼り付けは、どの貼り方でも `Ctrl+Z` の 1 回で戻せます。

## 検索・置換・行へ移動

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 文字を探す | `Ctrl+F` | 画面の下に「検索: 」と出ます。探す文字を打って `Enter` を押すと、次に見つかったところへ移動します。 |
| 次を探す | `F3` | 最後に探した文字の、次に見つかったところへ移動します。 |
| 前を探す | `Shift+F3` | 最後に探した文字の、前に見つかったところへ移動します。 |
| 置き換える | `Ctrl+H` | 「検索: 」に続けて、置き換える文字を聞きます。 |
| 行へ移動する | `Ctrl+G` | 「行: 」に行の番号を打って `Enter` を押すと、その行へ移動します。 |
| 入力欄を閉じる | `Esc` | 「検索: 」などの入力欄を閉じます。 |

### 探す

- 打っている間から、見つかるところを本文の中で示します。
- 見つかったところには色が付き、キャレットのあるところは枠で示します。
- 「検索: 」の `Enter` は、入力欄を閉じずに次のところへ進みます。終わったら `Esc` で閉じます。
- 打った文字は、そのままの文字として探します。`.` や `*` も、その文字そのものを探します。
- 大文字と小文字は区別します。区別しないで探す方法は「設定」の章で説明します。
- 見つからなかったときと、文書の末尾から先頭へ戻って探し続けたときは、画面の下に 1 行のメッセージが英語で出ます。

### 置き換える

1. `Ctrl+H` を押します。「検索: 」に前回探した文字が入っています。
2. 探す文字を確かめて `Enter` を押します。
3. 「置換後 (探す文字): 」に、置き換える文字を打ちます。
4. 次のどちらかを押します。

| 押すキー | どうなるか |
|---|---|
| `Enter` | 今のところを 1 つ置き換えて、次に見つかったところへ移動します。続けて `Enter` を押すと、1 つずつ置き換えていけます。 |
| `Ctrl+Enter` | 文書の中の全部を置き換えます。`Ctrl+Z` の 1 回で全部が戻ります。 |

置き換える文字も、そのままの文字として入ります。

### 行へ移動する

「行: 」には、行の番号か、「行:桁」の形（`120:5` など）を半角の数字で打ちます。文書の行数より大きな番号を打つと、最後の行へ移動します。

### 「Vim」モードのとき

「Vim」モードでは、`Ctrl+F`・`Ctrl+H`・`Ctrl+G` は Vim の働きのままです。`F1` の一覧から「検索」「置換」「行へ移動」を選ぶと、同じことができます。探した文字は 2 つのモードで共通なので、「通常」モードで探した文字を「Vim」モードの `n` で続けて探せます。

## そのほかのメモ帳と同じ操作

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| 日付と時刻を入れる | `F5` | 今の日付と時刻をキャレットのところに入れます。 |
| 文字を大きくする・小さくする | `Ctrl++`・`Ctrl+-`・`Ctrl` を押しながらホイール | 本文の文字の大きさを 0.5 pt ずつ、8〜40 pt の間で変えます。 |
| 文字の大きさを戻す | `Ctrl+0` | 本文の文字を既定の大きさに戻します。 |
| 印刷する | `F1` の一覧から「印刷」 | プリンターを選んで、今の文書を印刷します。 |

印刷にはキーが割り当てられていません。メモ帳の `Ctrl+P` は印刷ですが、NeNe Nib の `Ctrl+P` は「ファイルとタブの一覧」を開くキーです。

## 詳しく知りたい人へ: アクセントや濁点の付いた文字

アクセントや濁点を、別の文字として後ろに付けて書いた文字があります。たとえば「か」の後ろに結合用の濁点を置いて「が」と見せる書き方です。人名の漢字などで字形を選ぶ異体字セレクターも、同じように前の文字の後ろに付きます。

「通常」モードでは、こうした文字を次のように扱います。

| 押すキー | どうなるか |
|---|---|
| `←`・`→` | 元の文字と、後ろに付いたアクセント・濁点・最初の異体字セレクターを、まとめて 1 文字として越えます。 |
| `Delete` | 同じまとまりを 1 回で消します。続く異体字セレクターも一緒に消します。 |
| `Backspace` | アクセントや濁点を 1 つずつ消します。「が」なら濁点だけを消して「か」を残します。異体字セレクターは、その前の文字と一緒に消します。 |

つないで 1 つに見せる絵文字（家族の絵文字など）・肌の色を変えた絵文字・国旗は、まだ 1 文字として扱いません。
