# インストールと初回起動

NeNe Nib は Windows 11 用のテキストエディタです。ふだんは「通常」モードで、メモ帳と同じように書けます。`Ctrl+Shift+Space` を押すと「Vim」モードに切り替わり、Vim の操作で書けます。この章では、インストールしてから最初の文書を保存するまでと、2 つのモードの切り替え方を説明します。

> 間違えて「Vim」モードになり、文字を打っても入らないときは、`Ctrl+Shift+Space` を押すと「通常」モードに戻れます。

## 動作環境

- Windows 11（22H2 以降）の x64 版で動きます。
- Windows 10 には対応していません。
- 追加のランタイム（アプリを動かすために別にインストールする部品）は要りません。実行ファイル 1 つで動きます。

## インストール

インストールの方法は 2 通りあります。どちらも中の実行ファイルは同じです。迷ったら Microsoft Store を選んでください。新しいバージョンに自動で更新されます。

### Microsoft Store からインストールする

1. [Microsoft Store の NeNe Nib のページ](https://apps.microsoft.com/detail/9nclgdtfq529)を開きます。
2. ページの案内に沿ってインストールします。
3. スタートメニューから NeNe Nib を起動します。

新しいバージョンは、Store から自動で更新されます。

<!-- 画面: Microsoft Store の NeNe Nib のページの写真（あとで入れる） -->

### GitHub の ZIP を使う

1. [GitHub の Release のページ](https://github.com/hideyukiMORI/nene-nib/releases/tag/v1.2.0)から `NeNeNib-1.2.0-windows-x64.zip` を保存します。
2. 好きなフォルダに展開します。
3. `NeNeNib.exe` を起動します。

- ZIP に入っているのは `NeNeNib.exe`・`README.txt`・`LICENSE`・`THIRD_PARTY_NOTICES.txt` の 4 つです。
- インストーラーと自動の更新はありません。新しいバージョンを使うときは、GitHub の Release のページから新しいバージョンの ZIP を取り直して入れ替えてください。
- exe には署名（配った人を確かめるための電子的な印）がありません。
- ファイルが壊れていないかは、同じページの `SHA256SUMS`（ファイルごとの検査用の値の一覧）と見比べて確かめられます。

ZIP 版では、エクスプローラーの右クリックのメニューと「プログラムから開く」に NeNe Nib を登録できます。`F1` の一覧から「Windows の右クリックに登録する」を選んでください。登録をやめるときは「登録を外す」を選びます。管理者の権限は要りません。Store 版では、登録と登録を外す操作は一覧に出ません。

## 初回起動

はじめて起動すると、空の「無題」のタブに起動画面が出ます。

<!-- 画面: 起動画面の写真（あとで入れる） -->

起動画面には、上から次のものが並びます。

| 見出し | 中身 |
|---|---|
| 最近使ったファイル | 最近閉じたファイルが 10 件まで並びます。はじめは「まだ履歴がありません。ファイルを開くか、そのまま打ち始めてください」と出ます。 |
| ブックマーク | ブックマークを付けたファイルがあれば、10 件まで並びます。 |
| はじめる | 「新しいファイル」（`Ctrl+T`）・「ファイルを開く」（`Ctrl+O`）・「フォルダを開く」（`Ctrl+Shift+R`）の 3 つです。 |
| ショートカット | 「ファイルとタブの一覧」（`Ctrl+P`）・「ヘルプ」（`F1`）・「エクスプローラーを出す・消す」（`Ctrl+Shift+E`）のキーです。 |

タイトルの横にはバージョンの番号が、下には著作権と GitHub の場所が出ます。

- `↑` `↓` で項目を選び、`Enter` を押すか項目をクリックすると、その項目を実行します。
- 何か文字を打つか、文書を開くと、起動画面は消えます。そのまま書き始めてかまいません。

2 回目からは、前回開いていたタブ（保存してあるファイルだけ）が、並び順・キャレット（文字を入れる位置を示す縦線。カーソルとも言います）の位置・スクロールの位置ごと戻ります。前回のファイルが無くなっていたときは、1 行のメッセージを出して、そのタブを閉じます。

## 書く・開く・保存する

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 新しい文書を作る | `Ctrl+T` または `Ctrl+N` | 空の「無題」のタブが開きます。 |
| ファイルを開く | `Ctrl+O` | ［開く］ダイアログが開きます。選んだファイルが開きます。 |
| 上書きで保存する | `Ctrl+S` | 今のファイルに上書きします。まだ名前の無い文書では、［名前を付けて保存］ダイアログが開きます。 |
| 名前を付けて保存する | `Ctrl+Shift+S` | 名前が付いていても、毎回［名前を付けて保存］ダイアログが開きます。 |
| タブを閉じる | `Ctrl+W` または `Ctrl+F4` | 今のタブを閉じます。 |

- エクスプローラーからファイルをウィンドウへドラッグ＆ドロップしても開けます。いくつかまとめてドラッグ＆ドロップすると、それぞれのタブで開きます。すでに開いているファイルなら、そのタブに移動します。
- 保存していない変更があるタブは、タブ名の前に「● 」が付きます。
- 保存していない変更があるままタブやウィンドウを閉じようとすると、「変更が保存されていません。保存しますか。」と聞かれます。「保存する(Y)」「保存しない(N)」「キャンセル」から選んでください。
- `Esc` を押しても NeNe Nib のウィンドウは閉じません。「通常」モードの `Esc` は、選択を解除するだけです。
- 保存していない変更は、30 秒ごとに別の場所へ退避しています。アプリが異常終了したときは、次の起動で「前回の未保存の編集が残っています。戻しますか。」と 1 回だけ聞かれます。

保存するときの文字コードと改行の形は、ステータスバーの右にある文字コード（`UTF-8` など）と改行（`CRLF` か `LF`）をクリックすると選べます。`CRLF` は Windows で標準の改行の形、`LF` は macOS や Linux で標準の改行の形です。開いたファイルは、開いたときの文字コードと改行の形のまま保存します。

## 「通常」モードと「Vim」モードを切り替える

NeNe Nib には 2 つのモードがあります。

- 「通常」モードは、メモ帳と同じキーで書くモードです。起動したときは、いつも「通常」モードです。
- 「Vim」モードは、Vim の操作で書くモードです。Vim には、キーでキャレットを動かしたり命令を出したりする NORMAL、文字を打ち込む INSERT、範囲を選ぶ VISUAL という状態があります。

`Ctrl+Shift+Space` を押すと、どちらのモードからでも、もう一方のモードに切り替わります。ステータスバーの左にある「通常 | Vim」をクリックしても切り替えられます。

<!-- 画面: ステータスバーの左の「通常 | Vim」の切り替えとモードの名前の写真（あとで入れる） -->

今どちらのモードかは、ステータスバーの左で見分けます。

- 「通常 | Vim」の切り替えでは、今のモードの側に色が付きます。
- その右に、今のモードの名前が出ます。「通常」モードのときは `通常`、「Vim」モードのときは `NORMAL`・`INSERT`・`VISUAL` などです。

文字を打っても本文に入らないときは、「Vim」モードの NORMAL になっていないか、ステータスバーを見てください。`Ctrl+Shift+Space` で「通常」モードに戻れます。

- モードを切り替えても、本文・元に戻すの履歴・キャレットの位置はそのまま続きます。
- 「Vim」モードに切り替えると、NORMAL から始まります。
- 日本語の変換中は、`Ctrl+Shift+Space` は効きません。変換を確定するか取り消してから押してください。

2 つのモードでは、同じキーでも働きが違うものがあります。たとえば「Vim」モードの `Ctrl+O` は前にいた位置へ戻る Vim のキーなので、「Vim」モードでファイルを開くキーは `Ctrl+Shift+O` です。「Vim」モードでキーが割り当てられていない操作は、次の `F1` の一覧から使えます。

## 操作の一覧（F1）

キーを覚えていなくても、`F1` で操作を探して実行できます。

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| 操作の一覧を開く | `F1` を押す | 操作の名前・短い説明・キーが並んだ一覧が開きます。 |
| 一覧を絞る | 文字を打つ | 名前に合う操作だけが残ります。日本語の画面では、読みのひらがな（「ほぞん」など）でも探せます。 |
| 操作を実行する | `↑` `↓` で選んで `Enter` を押す | 選んだ操作がその場で実行されます。 |
| 一覧を閉じる | `Esc` を押す | 一覧が閉じます。 |

<!-- 画面: F1 の操作の一覧の写真（あとで入れる） -->

- 一覧には、今のモードで使える操作が並びます。印刷・「文字コードを選ぶ」・「改行を選ぶ」のようにキーが割り当てられていない操作も、ここから実行できます。
- 一覧を開いた直後は、日本語の入力がオフです。ひらがなで探すときは、入力をオンにしてから打ってください。
- `Ctrl+P` を押してから `?` を打っても、同じ一覧になります。

## 画面の言語

画面の文字は、日本語・英語・中国語（簡体字）から選べます。はじめは Windows の表示言語に合わせます。変えるときは、`F1` の一覧から「表示言語を選ぶ」を選んでください。選ぶとすぐに切り替わり、次の起動でもそのままです。

Vim のモードの名前（`NORMAL` など）、Vim のメッセージ、テーマの名前は、どの言語でも英語のままです。

## 設定

設定は、`Ctrl+,` で右に開く「設定」で変えられます。閉じると保存します。詳しくは「設定」の章で説明します。

NeNe Nib は個人の情報を集めず、アプリ自身はネットワークに接続しません。

## 詳しく知りたい人へ: 設定と記録の置き場所

設定・前回のタブ・最近閉じたファイル・ブックマーク・自動の退避は、`%LOCALAPPDATA%\NeNeNib` に置きます。`%LOCALAPPDATA%` は、ユーザーごとのアプリのデータを置く Windows のフォルダ（ふつうは `C:\Users\ユーザー名\AppData\Local`）です。エクスプローラーのアドレスバーに `%LOCALAPPDATA%\NeNeNib` と打つと開けます。

| ファイル | 中身 |
|---|---|
| `settings.v6` | 設定 |
| `session.v2` | 前回開いていたタブと、その位置 |
| `history.v1` | 最近閉じたファイル（100 件まで） |
| `bookmarks.v1` | ブックマーク（1,024 件まで） |

このフォルダを消すと、NeNe Nib は初回起動のときの状態に戻ります。Microsoft Store 版では、Windows がこのフォルダをアプリ専用の保存場所に置くことがあり、その場合はアンインストールすると消えます。ZIP 版のフォルダがすでにあれば、Store 版でもそのフォルダをそのまま使うことがあります。
