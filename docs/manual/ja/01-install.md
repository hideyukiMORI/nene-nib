# 入れ方と最初の起動

NeNe Nib は Windows 11 用のテキストエディタです。ふだんはメモ帳と同じように書けて、`Ctrl+Shift+Space` を押すと Vim の操作に切り替わります。この章では、入れてから最初の文書を保存するまでと、2 つの編集のしかたの切り替え方を説明します。

## 動く環境

- Windows 11（22H2 以降）の x64 版で動きます。
- Windows 10 には対応していません。
- 追加のランタイムは要りません。実行ファイル 1 つで動きます。

## 入れ方

入れ方は 2 通りあります。中の実行ファイルは同じです。

### Microsoft Store から入れる

1. [Microsoft Store の NeNe Nib のページ](https://apps.microsoft.com/detail/9nclgdtfq529)を開きます。
2. ページの案内に沿って入れます。
3. スタートメニューから NeNe Nib を起動します。

新しい版が出ると、Store が更新します。

<!-- 画面: Microsoft Store の NeNe Nib のページの写真（あとで入れる） -->

### GitHub の ZIP を使う

1. [GitHub の Release のページ](https://github.com/hideyukiMORI/nene-nib/releases/tag/v1.2.0)から `NeNeNib-1.2.0-windows-x64.zip` を保存します。
2. 好きなフォルダに展開します。
3. `NeNeNib.exe` を起動します。

ZIP に入っているのは `NeNeNib.exe`・`README.txt`・`LICENSE`・`THIRD_PARTY_NOTICES.txt` の 4 つです。インストーラーと自動の更新はありません。新しい版は、GitHub の Release のページから新しい版の ZIP を取り直して入れ替えてください。exe には署名がありません。ファイルが壊れていないかは、同じページの `SHA256SUMS` と見比べて確かめられます。

ZIP 版では、エクスプローラーの右クリックのメニューと「プログラムから開く」に NeNe Nib を載せられます。F1 の一覧から「Windows の右クリックに登録する」を選んでください。外すときは「登録を外す」を選びます。管理者の権限は要りません。Store 版ではこの 2 つの操作は一覧に出ません。

## 最初の起動

はじめて起動すると、空の「無題」のタブに起動画面が出ます。

<!-- 画面: 起動画面の写真（あとで入れる） -->

起動画面には、上から次のものが並びます。

| 見出し | 中身 |
|---|---|
| 最近使ったファイル | 最近閉じたファイルが 10 件まで並びます。はじめは「まだ履歴がありません。ファイルを開くか、そのまま打ち始めてください」と出ます。 |
| ブックマーク | ブックマークを付けたファイルがあれば、10 件まで並びます。 |
| はじめる | 「新しいファイル」（Ctrl+T）・「ファイルを開く」（Ctrl+O）・「フォルダを開く」（Ctrl+Shift+R）の 3 つです。 |
| ショートカット | 「ファイルとタブの一覧」（Ctrl+P）・「ヘルプ」（F1）・「エクスプローラーを出す・消す」（Ctrl+Shift+E）のキーです。 |

題の横には版の番号が、下には著作権と GitHub の場所が出ます。

- ↑ ↓ で行を選び、Enter を押すか行をクリックすると、その行を実行します。
- 何か文字を打つか、文書を開くと、起動画面は消えます。そのまま書き始めてかまいません。

2 回目からは、前回開いていたタブ（保存してあるファイルだけ）が、並びとキャレットの位置とスクロールの位置ごと戻ります。前回のファイルが無くなっていたら、そのタブは 1 行の知らせを出して外れます。

## 書く・開く・保存する

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 新しい文書を作る | Ctrl+T または Ctrl+N | 空の「無題」のタブが開きます。 |
| ファイルを開く | Ctrl+O | ファイルを選ぶ窓が開きます。選んだファイルが開きます。 |
| 上書きで保存する | Ctrl+S | 今のファイルに上書きします。まだ名前の無い文書では、保存する場所を選ぶ窓が開きます。 |
| 名前を付けて保存する | Ctrl+Shift+S | いつも保存する場所を選ぶ窓が開きます。 |
| タブを閉じる | Ctrl+W または Ctrl+F4 | 今のタブを閉じます。 |

- エクスプローラーからファイルを窓へドラッグして落としても開けます。いくつかまとめて落とすと、それぞれのタブで開きます。もう開いているファイルなら、そのタブに移ります。
- 保存していない変更があるタブは、題の前に「● 」が付きます。
- 保存していない変更があるままタブや窓を閉じようとすると、「変更が保存されていません。保存しますか。」と聞かれます。「保存する(Y)」「保存しない(N)」「キャンセル」から選んでください。
- Esc を押しても窓は閉じません。
- 保存していない変更は 30 秒ごとに別の場所へ退避しています。アプリが途中で落ちたときは、次の起動で「前回の未保存の編集が残っています。戻しますか。」と 1 回だけ聞かれます。

保存するときの文字コードと改行の形は、ステータスバーの右の文字コード（`UTF-8` など）と改行（`CRLF` か `LF`）をクリックすると選べます。読んだファイルは、読んだときの文字コードと改行の形のまま保存します。

## 通常と Vim を切り替える

Nib には 2 つの編集のしかたがあります。画面ではそれぞれ「通常」と「Vim」と呼びます。

- 「通常」は、メモ帳と同じキーで書くしかたです。起動したときはいつも「通常」です。
- 「Vim」は、Vim の NORMAL・INSERT・VISUAL の操作で書くしかたです。

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 「通常」と「Vim」を切り替える | Ctrl+Shift+Space | どちらのモードからでも、もう一方に切り替わります。 |

ステータスバーの左の「通常 | Vim」をクリックしても切り替えられます。

<!-- 画面: ステータスバーの左の「通常 | Vim」の切り替えとモードの名前の写真（あとで入れる） -->

今どちらのモードかは、ステータスバーの左で見分けます。

- 「通常 | Vim」の切り替えでは、今のモードの側に色が付きます。
- その右に、今のモードの名前が出ます。「通常」のときは `通常`、「Vim」のときは `NORMAL`・`INSERT`・`VISUAL` などです。

文字を打っても本文に入らないときは、「Vim」の NORMAL になっていないか、ステータスバーを見てください。`Ctrl+Shift+Space` で「通常」に戻れます。

- 切り替えても、本文・元に戻すの履歴・キャレットの位置はそのまま続きます。
- 「Vim」に切り替えると、NORMAL から始まります。
- 日本語の変換中は、`Ctrl+Shift+Space` は効きません。変換を確定するか取り消してから押してください。

「通常」と「Vim」では、同じキーでも働きが違うものがあります。たとえば「Vim」の Ctrl+O は前にいた位置へ戻る Vim のキーなので、「Vim」でファイルを開くのは Ctrl+Shift+O です。「Vim」でキーの無い操作は、次の F1 の一覧から使えます。

## 操作の一覧（F1）

キーを覚えていなくても、F1 で操作を探して実行できます。

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 操作の一覧を開く | F1 | 操作の名前・短い説明・キーが並んだ一覧が開きます。 |
| 一覧を絞る | 文字を打つ | 名前に合う操作だけが残ります。日本語の画面では、読みのひらがな（「ほぞん」など）でも探せます。 |
| 操作を実行する | ↑ ↓ で選んで Enter | 選んだ操作がその場で実行されます。 |
| 一覧を閉じる | Esc | 一覧が閉じます。 |

<!-- 画面: F1 の操作の一覧の写真（あとで入れる） -->

- 一覧には、今のモードで使える操作が並びます。印刷・「文字コードを選ぶ」・「改行を選ぶ」のようにキーの無い操作も、ここから実行できます。
- 一覧は開いたときに日本語の入力がオフになっています。ひらがなで探すときは、入力をオンにしてから打ってください。
- Ctrl+P を押して `?` を打っても、同じ一覧になります。

## 画面の言語

画面の文字は、日本語・英語・中国語（簡体字）から選べます。はじめは Windows の表示言語に合わせます。変えるときは、F1 の一覧から「表示言語を選ぶ」を選んでください。選ぶとすぐに切り替わり、次の起動でもそのままです。

Vim のモードの名前（`NORMAL` など）、Vim の知らせ、テーマの名前は、どの言語でも英語のままです。

## 設定と記録の置き場所

設定は Ctrl+, で右に開く「設定」で変えられます。閉じると保存します。詳しくは「設定」の章で説明します。

設定・前回のタブ・最近閉じたファイル・ブックマーク・自動の退避は、`%LOCALAPPDATA%\NeNeNib` に置きます。

| ファイル | 中身 |
|---|---|
| `settings.v6` | 設定 |
| `session.v2` | 前回開いていたタブと、その位置 |
| `history.v1` | 最近閉じたファイル（100 件まで） |
| `bookmarks.v1` | ブックマーク（1024 件まで） |

このフォルダを消すと、Nib ははじめて起動したときの状態に戻ります。Microsoft Store 版では、Windows がこのフォルダをアプリ専用の保存場所に置くことがあり、その場合はアンインストールすると消えます。ZIP 版のフォルダがすでにあれば、Store 版でもそのフォルダをそのまま使うことがあります。

Nib は個人の情報を集めず、アプリ自身はネットワークに接続しません。
