# ファイルとプロジェクト

NeNe Nib では、開いたファイルはそれぞれタイトルバーのタブになります。この章では、タブの扱い方、`Ctrl+P` でファイルを探して開く方法、フォルダを開いてプロジェクト（ひとまとまりのファイルを入れたフォルダ）全体を扱う方法、本文を 2 つの枠に分ける方法を説明します。

> どこにあるファイルを開けばよいか分からないときは、まず `Ctrl+P` を押してください。開いているタブ・ブックマーク・最近閉じたファイル・今のファイルと同じフォルダのファイルが、1 つの一覧にまとめて出ます。

## タブ

タブは、ウィンドウのいちばん上のタイトルバーに横に並びます。

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| 新しいタブを開く | `Ctrl+T`（「通常」モードでは `Ctrl+N` も）、またはタブの帯の `+` | 空の「無題」のタブが開きます。 |
| タブを切り替える | タブをクリック | そのタブの文書に切り替わります。 |
| 最近使った順に切り替える | `Ctrl+Tab`（逆向きは `Ctrl+Shift+Tab`） | `Ctrl` を押したまま `Tab` を押すたびに、最近使った順に次のタブへ進みます。`Ctrl` を離したところのタブに決まります。 |
| タブを閉じる | `Ctrl+F4`（「通常」モードでは `Ctrl+W` も）、タブの ×、またはタブの上でホイールを押す（中クリック） | そのタブを閉じます。 |
| タブの一覧から選ぶ | タブが帯に入りきらないときに出る `∨` | 開いているタブの一覧が出ます。 |
| ファイルの場所を見る | タブの上にマウスを止める | 少し待つと、タブの下にファイルのフルパス（ドライブから始まる完全な場所）が小さく出ます。長いパスは、真ん中を「…」で縮めます。 |

<!-- 画面: タブの帯と、フルパスの小さな表示の写真（あとで入れる） -->

### タブの右クリックのメニュー

タブ（その × の上でも）を右クリックすると、次のメニューが出ます。「通常」モードでも「Vim」モードでも同じです。

| 項目 | どうなるか |
|---|---|
| エクスプローラーで場所を開く | Windows のエクスプローラーで、そのファイルを選んだ状態のフォルダを開きます。 |
| パスをコピー | ファイルのフルパスをクリップボードへコピーします。 |
| ファイル名をコピー | ファイル名をクリップボードへコピーします。 |
| 保存 | そのタブの文書を上書きで保存します。 |
| 名前を付けて保存 | そのタブの文書を別の名前で保存します。 |
| タブを閉じる | そのタブを閉じます。 |
| ほかのタブを閉じる | そのタブを残して、ほかのタブを閉じます。 |
| 右のタブを閉じる | そのタブより右にあるタブを閉じます。 |

- 「無題」のタブでは、パスが無いので「エクスプローラーで場所を開く」「パスをコピー」「ファイル名をコピー」は薄く表示され、選べません。
- いくつかのタブをまとめて閉じるときは、保存していないタブごとに保存するかを聞きます。「キャンセル」を選ぶと、そこで止まります。
- このメニューはキーボードからは開けません（`Shift+F10` とメニューキーは本文の右クリックのメニューを開きます）。「エクスプローラーで場所を開く」「パスをコピー」「ファイル名をコピー」「ほかのタブを閉じる」「右のタブを閉じる」は、`F1` の一覧からも今のタブに対して実行できます。

### 次の起動でのタブ

ファイルを指定せずに起動すると、前回開いていたタブ（保存してあるファイルだけ）が、並び順・表示していたタブ・キャレットとスクロールの位置ごと戻ります。詳しくは「インストールと初回起動」の章を見てください。

## `Ctrl+P` でファイルとタブを探す

`Ctrl+P` を押すと「ファイルとタブの一覧」が開きます。入力欄は空で、次のものが 1 つの一覧に並びます。

- 開いているタブ
- ブックマーク
- 履歴（最近閉じたファイル）
- 今のファイルと同じフォルダにあるファイル

<!-- 画面: Ctrl+P の一覧と、右のプレビュー欄の写真（あとで入れる） -->

ファイル名の一部を打つと、あいまい検索（打った文字が順に含まれていれば、続いていなくても見つかる探し方）で候補を絞ります。ファイル名で見つからないときは、フォルダの名前でも探します。

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 候補を選ぶ | `↑`・`↓` | 選ぶ候補が移動します。 |
| 開く | `Enter` | 選んだファイルを開きます。開いているタブなら、そのタブへ切り替わります。 |
| 閉じる | `Esc` | 一覧を閉じます。 |
| プレビュー欄の置き方を変える | 一覧を開いている間に `Ctrl+Shift+P` | プレビュー欄が、右 → 下 → 出さない の順に切り替わります。 |

- 選んだ候補の中身は、一覧の右のプレビュー欄に出ます。ウィンドウの幅が足りないときは、一覧の下に出ます。選んだ置き方は、次の起動でも同じです。
- 開いているタブは、まだ保存していない中身を出します。開いていないファイルは 16 MiB までを読んで出します。OneDrive などのクラウドにあってまだこの PC に無いファイルは、プレビューのためには取り寄せません。
- 一覧を開いた直後は、日本語の入力がオフです。ひらがなで探すときは、入力をオンにしてから打ってください。

### 先頭の記号で絞り込む

入力欄の先頭に記号を 1 つ打つと、その種類だけに絞り込めます。

| 先頭の記号 | 出るもの |
|---|---|
| `#` | 開いているタブ |
| `*` | ブックマーク |
| `@` | 履歴（最近閉じたファイル） |
| `/` | 今のファイルと同じフォルダのファイル |
| `!` | プロジェクトの全文検索（下の「プロジェクト全体から探す」） |
| `:` | 設定の命令（「設定」の章で説明します） |
| `?` | 操作の一覧（`F1` と同じ） |

`^`・`&`・`%` は言語サーバーの一覧です。「言語サーバー」の章で説明します。

## 最近閉じたファイルとブックマーク

### 履歴

タブを閉じたファイルは、履歴に 100 件まで残ります。`Ctrl+P` の一覧に出るほか、`@` で履歴だけを出せます。起動画面の「最近使ったファイル」にも 10 件まで出ます。

履歴のファイルが無くなっていたときは、1 行のメッセージを出して、履歴から外します。

### ブックマーク

よく開くファイルは、ブックマークに付けておくと `Ctrl+P` の `*` ですぐに出せます。

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 今のファイルにブックマークを付ける・外す | 「通常」モードは `Ctrl+D`、「Vim」モードは `Ctrl+Shift+D` | 「ブックマークに追加しました」か「ブックマークを解除しました」と出ます。 |
| 一覧の中のファイルにブックマークを付ける・外す | `Ctrl+P` の一覧で候補を選んで、同じキー | 選んだファイルを、開かずに付け外しします。 |

- ブックマークを付けられるのは、保存してあるファイルだけです。「無題」のタブでは「保存済みのファイルを選んでください」と出ます。
- ブックマークは 1,024 件まで付けられます。
- ブックマークしたファイルを移動したり消したりしても、ブックマークは残ります。要らなくなったら、`Ctrl+P` の `*` の一覧で選んで、同じキーで外してください。
- 起動画面の「ブックマーク」にも 10 件まで出ます。
- 「Vim」モードの `Ctrl+D` は、Vim と同じ半画面の移動のままです。

## フォルダを開く（プロジェクトのルート）

NeNe Nib では、プロジェクトのフォルダを「ルート」（エクスプローラーと全文検索のいちばん上のフォルダ）として選びます。エクスプローラーは、画面の左に出る、ファイルをツリーで表示する欄です。Windows のエクスプローラーとは別のものです。

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| フォルダを開く | `Ctrl+Shift+R`、起動画面の「フォルダを開く」、または `F1` の一覧から「ルートのフォルダを選ぶ」 | フォルダを選ぶダイアログが開きます。選んだフォルダがルートになり、左にエクスプローラーが出ます。 |
| 今のファイルのフォルダをルートにする | `:set root=.` | 今の文書のフォルダがルートになります。 |
| フォルダを名前で指定する | `:set root=` に続けてフォルダのパス | そのフォルダがルートになります。 |

- `:set` の命令は、`Ctrl+P` を押して `:` に続けて打っても使えます。
- 選んだルートは設定に保存され、次の起動でも同じです。
- フォルダを選ぶダイアログには、インストールしてある WSL（Windows で Linux を動かす仕組み）のディストリビューションも `\\wsl.localhost\<名前>` の場所として出ます。

## エクスプローラー

エクスプローラーは、ルートの下のフォルダとファイルを、本文の左にツリーで表示する欄です。はじめは表示されていません。

<!-- 画面: 左のエクスプローラーと、斜体のプレビューのタブの写真（あとで入れる） -->

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| 出す・消す | `Ctrl+Shift+E`（または `:set explorer`・`:set noexplorer`） | 表示されていなければ表示して、エクスプローラーへ移ります。出ていてエクスプローラーにいるときは消します。出ていて本文にいるときは、エクスプローラーへ移るだけです。 |
| ファイルを開く | ファイルの行をクリック | ファイルを開きます。エクスプローラーにいたままなので、続けて `↑`・`↓` でほかのファイルを見ていけます。 |
| 開いて本文へ移る | ファイルの行をダブルクリック、または `Enter` | ファイルを開いて、本文へ移ります。 |
| フォルダを開く・閉じる | フォルダの行をクリック | フォルダの中身を出したり、しまったりします。 |
| 欄の幅を変える | 欄と本文の境目をドラッグ | 幅が変わります。境目のダブルクリックで元の幅に戻ります。ドラッグの途中で `Esc` を押すと、ドラッグする前の幅に戻ります。変えた幅は次の起動でも同じです。 |

エクスプローラーにいるときは、次のキーが使えます。どちらのモードでも同じです。

| 押すキー | どうなるか |
|---|---|
| `↓`・`↑`（または `j`・`k`） | 選ぶ行が移動します。 |
| `→`（または `l`） | フォルダを開きます。 |
| `←`（または `h`） | フォルダを閉じます。閉じているフォルダやファイルでは、その上のフォルダへ移動します。 |
| `Enter` | ファイルなら開いて本文へ移ります。フォルダなら開きます。 |
| `Esc` | 欄は出したまま、本文へ移ります。 |

### クリックで開いたタブ（プレビューのタブ）

エクスプローラーのクリック 1 回で開いたタブは、タブの名前が斜体になります。これは「プレビューのタブ」で、次にほかのファイルをクリックすると、新しいタブを足さずに同じタブの中身を入れ替えます。ファイルを順に眺めても、タブが増えすぎません。

次のどれかをすると、ふつうのタブになって残ります。

- 本文を編集する
- 保存する
- エクスプローラーでダブルクリックするか、`Enter` を押す
- タブの名前をダブルクリックする

`Ctrl+P`・`Ctrl+O`・ドラッグ＆ドロップで開いたタブは、はじめからふつうのタブです。Markdown のプレビュー（次の章）とは別のものです。

### エクスプローラーの見た目

- ファイルの行には、そのファイルの言語の色の小さな点が付きます。
- 保存していない変更があるファイルには、色の付いた丸が付きます。
- 隠しファイルも、薄い色で出ます。

## プロジェクト全体から探す

ルートの下にあるすべてのファイルから、文字を探せます。

1. `Ctrl+Shift+F` を押します（どちらのモードでも使えます。`F1` の一覧の「プロジェクトを検索」でも同じです）。`Ctrl+P` の一覧が、先頭に `!` が入った状態で開きます。
2. 探す文字を打ちます。打つたびに探し直し、見つかった行が一覧に増えていきます。探している間は「探しています…」と、探し終えたファイルの数が出ます。
3. `↑`・`↓` で選んで `Enter` を押すと、そのファイルが開き、見つかった行と桁へキャレットが移動します。

<!-- 画面: Ctrl+Shift+F で探している途中の一覧の写真（あとで入れる） -->

- 探す場所は、エクスプローラーのルートの下です。ルートを選んでいないときは、今の文書のフォルダの下を探します。どちらも無いときは「探す場所がありません。ルートを選ぶか、保存した文書から探してください」と出ます。
- 打った文字は、そのままの文字として探し、大文字と小文字を区別しません。先頭に `/` を付けると、Vim の検索と同じ書き方のパターンとして探します。
- 1 つの行では、最初に見つかった 1 か所だけを出します。1,000 件見つかったところで打ち切ります。
- 正しい UTF-8 でない行（Shift_JIS のファイルの行など）は探せません。Shift_JIS のファイルの中を探すときは、そのファイルを開いて `Ctrl+F` で探してください。開いた文書の中の検索は、Shift_JIS のファイルでも使えます。

## 枠を分ける

本文を 2 つの枠に分けて、同じ文書の離れたところや、2 つの文書を並べて見られます。

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 左右に分ける | `Ctrl+\` | 本文を左右 2 つの枠に分けて、両方に同じ文書を出します。 |
| 上下に分ける | `Ctrl+Shift+\` | 本文を上下 2 つの枠に分けて、両方に同じ文書を出します。 |
| もう一方の枠へ移る | `F6`、または枠をクリック | 操作する枠が切り替わります。 |
| 枠を閉じる | `Ctrl+Shift+F4` | 今の枠を閉じて、1 つに戻します。文書は閉じません。 |
| 枠の大きさを変える | 枠の境目をドラッグ | 境目が動きます。ダブルクリックで同じ大きさに戻ります。ドラッグの途中で `Esc` を押すと元に戻ります。 |

- 枠は 2 つまでです。
- タブの切り替え・新しいタブ・ファイルを開く・`Ctrl+P` は、今操作している枠に効きます。
- `F1` の一覧の「枠を広げる」「枠を狭める」「枠を等分に戻す」でも、大きさを変えられます。1 回で動かす量は、設定の「枠を広げる・狭める量」（はじめは 5）で変えられます。
- 枠の分け方と大きさは、ウィンドウを閉じるまで続きます。次の起動では、1 つの枠に戻ります。

## 「Vim」モードのとき

「Vim」モードでは、上のキーのほかに、Vim と同じ命令でも同じことができます。詳しくは「[Vim の操作](03-vim.md)」の章を見てください。

| やりたいこと | Vim の命令 |
|---|---|
| タブを移る | `gt`・`gT`、`:tabnext`・`:tabprevious` |
| タブを開く・閉じる | `:tabnew`・`:tabclose` |
| 開いているタブを一覧で見る | `:tabs`、`:ls`・`:files`・`:buffers`、`:b`（`:b memo` のように続けて打つと絞り込めます） |
| ファイルの一覧を開く | `:e`（`Ctrl+P` と同じ一覧） |
| プロジェクト全体から探す | `:grep` に続けて探す文字 |
| 枠を分ける・移る・閉じる | `Ctrl+W` `s`・`Ctrl+W` `v`・`Ctrl+W` `w`・`Ctrl+W` `c`・`Ctrl+W` `o`・`:only` など |
| 枠の大きさを変える | `Ctrl+W` `>`・`Ctrl+W` `<`・`Ctrl+W` `+`・`Ctrl+W` `-`・`Ctrl+W` `=`、`:resize`・`:vertical resize` |

## まだできないこと

- タブをドラッグして並べ替えることは、まだできません。
- ウィンドウの位置と大きさは、次の起動に引き継ぎません。
- エクスプローラーでは、ファイルの名前の変更・削除・新しいファイルの作成はできません。
- ほかのアプリでフォルダの中身が変わっても、エクスプローラーには、そのフォルダを開き直すまで反映されません。
- タスクバーのジャンプリスト（タスクバーのアイコンの右クリックで出る一覧）には、まだ履歴とブックマークが出ません。

## 詳しく知りたい人へ: 一覧と検索の上限

| 項目 | 上限・決まり |
|---|---|
| `Ctrl+P` の同じフォルダのファイル | 8,192 件を読んだところで、一覧を閉じるまでメッセージが出ます（下の箇条書きも見てください）。 |
| `Ctrl+P` のプレビュー欄 | 開いていないファイルは 16 MiB まで読みます。それより大きいファイルとテキストでないファイルは「プレビューしません」と出ます。 |
| 履歴 | 100 件まで。`%LOCALAPPDATA%\NeNeNib\history.v1` に置きます。 |
| ブックマーク | 1,024 件まで。`%LOCALAPPDATA%\NeNeNib\bookmarks.v1` に置きます。 |
| エクスプローラー | 1 つのフォルダに 2,000 件まで出します。読めないフォルダは「（読めません）」と出ます。 |
| プロジェクトの全文検索で飛ばすもの | 隠しフォルダ、`.git`・`node_modules`・`build`・`out` のフォルダ、ジャンクションとフォルダへのシンボリックリンク（どちらも、別の場所のフォルダを指す、ショートカットに似た仕組み）、16 MiB を超えるファイル、先頭の 8 KiB に NUL（値が 0 の文字）があるファイル |
| プロジェクトの全文検索の件数 | 1 行に 1 件、全部で 1,000 件まで |
| 枠の大きさの 1 回分 | 設定の「枠を広げる・狭める量」で 1〜40（下の箇条書きも見てください）。 |

- `Ctrl+P` の同じフォルダのファイルには、隠しファイル・システムファイル・テキストでないと分かっている種類のファイルは出ません。拡張子の無いファイルや、知らない拡張子のファイルは出ます。
- ブックマークの読み書きに失敗したときは、前の一覧を残して 1 行のメッセージを出します。
- 枠の大きさの 1 回分は、`:set paneresizestep=` でも変えられます。
- 「Vim」モードの `Ctrl+W` `>`・`<`・`+`・`-` は、回数を付けないと、Vim と同じく 1 文字分（または 1 行分）だけ動かします。`:set paneresizestepvim` にすると、「枠を広げる・狭める量」に従います。
