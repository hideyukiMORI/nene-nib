# 言語サーバー

言語サーバーは、プログラムの言語ごとに用意された別のアプリで、書いているソースコードを読んで、誤りの指摘・補完（打ちかけの名前の続きの候補）・定義の場所などを示します。NeNe Nib は言語サーバーにつなぐと、これらを本文の中に出します。言語サーバーは NeNe Nib に入っていないので、使う言語のものを別にインストールします。この章では、clangd（C と C++ の言語サーバー）を例に、つなぎ方と使い方を説明します。

> 言語サーバーは、はじめはオフです。インストールしただけでは何も出ません。「設定」で言語サーバーをオンにし、使う言語のサーバーを選んでください。

## 言語サーバーをつなぐ

`Ctrl+,` で右に開く「設定」から、つなぐのが簡単です。

1. 使う言語の言語サーバーをインストールします。C と C++ なら clangd です。
2. NeNe Nib で `Ctrl+,` を押して「設定」を開きます。
3. 「機能」の節の「言語サーバー（LSP）」をオンにします。
4. 「言語サーバー」の節に、言語ごとの行が並びます。インストールした言語サーバーが見つかると「見つかりました」と出るので、右の「使う」を押します。
5. 「設定」を閉じます。閉じると保存します。
6. その言語のファイルを開くと、言語サーバーが起動します。

<!-- 画面: 「設定」の「言語サーバー」の節と「使う」の写真（あとで入れる） -->

「言語サーバー」の節の行には、次の状態が出ます。

| 状態 | 意味 |
|---|---|
| 探しています… | PC の中を探している途中です。 |
| 見つかりました | インストールされています。「使う」を押すと、この言語で使います。 |
| 見つかりません | 見つかりませんでした。2 行目に、インストールの命令が出ます。Lua と Markdown では、命令の代わりに「インストールしてから「設定」を開き直すと、ここに出ます」という案内が出ます。 |
| 設定済み | この言語で使う言語サーバーが決まっています。「外す」を押すと、使うのをやめます。 |
| 起動中 | 言語サーバーが起動している途中です。 |
| ● 動いています | 言語サーバーが動いています。 |
| 止めました | 何度か続けて起動に失敗したので止めました。`:set lsp` で起動し直せます。 |

- はじめは 5 つの言語の行が並びます。ほかの言語は「ほかの N 言語を見る」を押すと出ます。
- C と C++ は 1 つの行です。「使う」を押すと、両方で同じ clangd を使います。
- 言語サーバーをインストールしても「見つかりません」のときは、「設定」を開き直してください。PATH（Windows がアプリを探すフォルダの一覧）を変えたときは、NeNe Nib を起動し直してください。
- 言語サーバーのオンとオフは、`:set lsp` と `:set nolsp` でも切り替えられます。`:set` の命令は「設定」の章で説明します。
- 名前の無い「無題」の文書には、言語サーバーは働きません。一度保存してください。

ステータスバーの右には、開いている文書の言語が出ます。言語サーバーが起動している途中は、その様子もステータスバーに出ます。

## 誤りと警告を見る（診断）

言語サーバーが誤りや警告を見つけると、本文のその場所に波線が付きます。これを診断と呼びます。

- ステータスバーの右に、誤りと警告の数が `E2 W1` のように出ます。`E` は誤り、`W` は警告の数です。
- キャレット（文字を入れる位置を示す縦線。カーソルとも言います）を波線の上に置くと、ステータスバーの左に、その診断の文が出ます。

<!-- 画面: 波線とステータスバーの E と W の数の写真（あとで入れる） -->

| やりたいこと | 「通常」モード | 「Vim」モード | どうなるか |
|---|---|---|---|
| 次の診断へ移動する | `F8` | `F8` または `]d` | 次の誤りや警告へ移動します。 |
| 前の診断へ移動する | `Shift+F8` | `Shift+F8` または `[d` | 前の誤りや警告へ移動します。 |
| 診断の文の全部を見る | `F1` の一覧から「診断を表示」 | `gl` | キャレットの位置の診断の文を、小さな枠で出します。 |
| 診断の一覧を見る | `F1` の一覧から「診断の一覧」 | 同じ | 開いているタブの診断が `Ctrl+P` の一覧に並びます。 |

`Ctrl+P` を押してから `^` を打っても、診断の一覧になります。

## 補完する

打ちかけの名前の続きを、候補の一覧から選んで入れられます。候補には、言語サーバーの候補が先に、開いている文書の中の単語が後に並びます。言語サーバーがオフのときは、文書の中の単語だけが並びます。

### 「通常」モード

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 候補の一覧を開く | `Ctrl+Space`（または `Ctrl+I`） | キャレットの前の打ちかけの名前に合う候補が並びます。 |
| 候補を選ぶ | `↑`・`↓` | 選んだ候補に色が付きます。本文はまだ変わりません。 |
| 選んだ候補を入れる | `Enter` または `Tab` | 打ちかけの名前を、選んだ候補に置き換えます。 |
| 一覧を閉じる | `Esc` | 何も入れずに閉じます。 |

- 一覧を開いたまま文字を打つと、候補が絞られます。
- 言語サーバーが動いているときは、`.` のような決まった文字を打つと、一覧が自動で開きます。
- 自動で開いた一覧では、`Tab` で選んでいる候補か一番上の候補を入れます。`Enter` で入るのは、`↑`・`↓` で選んだ候補だけです。選ばずに `Enter` を押すと、ふつうの改行になります。候補をクリックしても入れられます。
- 日本語入力が `Ctrl+Space` を使う設定になっているときは、`Ctrl+I` を使ってください。

### 「Vim」モード

INSERT で次のキーを使います。

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 候補の一覧を開いて、次の候補を入れる | `Ctrl+N` | 一覧を開き、候補を順に入れていきます。 |
| 前の候補を入れる | `Ctrl+P` | 逆の順に入れていきます。 |
| 今の候補で決める | `Ctrl+Y` | 一覧を閉じます。 |
| やめる | `Ctrl+E` | 打ちかけの名前に戻して、一覧を閉じます。 |

- INSERT でも、言語サーバーの決まった文字を打つと一覧が自動で開きます。開いている間は、`↑`・`↓`・`PgUp`・`PgDn` で候補を選べます。
- 一覧が開いている間の `Ctrl+P` は、候補を選ぶキーです。ファイルとタブの一覧は開きません。

## 名前の情報を見る・定義へ移動する

| やりたいこと | 「通常」モード | 「Vim」モード | どうなるか |
|---|---|---|---|
| 名前の情報を見る | `F1` の一覧から「情報を表示」 | `K` | キャレットの位置の名前の型や説明を、小さな枠で出します。 |
| 定義へ移動する | `F12` | `F12` または `gd` | キャレットの位置の名前が定義されたところへ移動します。別のファイルなら、そのファイルを開きます。 |
| 引数の情報を見る | `F1` の一覧から「引数の情報を表示」 | 同じ | 関数の呼び出しの引数を、キャレットの行の上に出します。 |

- 情報の枠は、次にキーを押すかクリックするかスクロールすると消えます。
- 定義が 2 か所以上あるときは、最初の場所へ移動して「定義 1 / 3」のように知らせます。
- 関数の名前の後に `(` や `,` を打つと、引数の情報が自動で出ます。今打っている引数は強調されます。

## 使っているところを探す（参照）

| やりたいこと | 「通常」モード | 「Vim」モード | どうなるか |
|---|---|---|---|
| 名前を使っているところの一覧を見る | `Shift+F12` | `Shift+F12` または `grr` | キャレットの位置の名前を使っているところが、`Ctrl+P` の一覧に並びます。 |

一覧で選んで `Enter` を押すと、そのところへ移動します。一覧には 1,000 件まで並びます。`Ctrl+P` を押してから `&` を打つと、最後に探した参照の一覧がもう一度出ます。

## 関数や型の一覧を見る（記号の一覧）

| やりたいこと | 「通常」モード | 「Vim」モード | どうなるか |
|---|---|---|---|
| 今の文書の関数や型の一覧を見る | `F1` の一覧から「記号の一覧」 | `gO` | 今の文書の関数・型などが、`Ctrl+P` の一覧に並びます。 |

一覧で選んで `Enter` を押すと、その場所へ移動します。一覧には 1,000 件まで並びます。`Ctrl+P` を押してから `%` を打っても、記号の一覧になります。

## 名前を変更する

関数や変数の名前を、使っているところも含めてまとめて変えられます。

| やりたいこと | 「通常」モード | 「Vim」モード | どうなるか |
|---|---|---|---|
| 名前を変更する | `F2` | `F2` または `grn` | 画面の下に「新しい名前: 」と出ます。新しい名前を打って `Enter` を押すと、名前が変わります。 |

- ほかのファイルで使っているところも変わります。開いていなかったファイルは新しいタブで開き、変更は保存しないままにします。タブ名の前の「● 」を見て、確かめてから保存してください。
- 変えられないところが 1 つでもあると、どこも変えずに 1 行のメッセージを出します。
- 「Vim」モードでは、INSERT の間は名前を変えません。`Esc` で NORMAL に戻ってから押してください。
- 元に戻すときは、変わったタブごとに `Ctrl+Z`（「Vim」モードでは `u`）を押します。

## 書式を整える（整形）

言語サーバーに、字下げや空白の書式を整えてもらえます。キーは割り当てられていないので、`F1` の一覧から選びます。

| やりたいこと | 操作 | どうなるか |
|---|---|---|
| 文書の全体を整える | `F1` の一覧から「文書を整形」 | 文書の全体の書式を整えます。 |
| 選んだ範囲を整える | `F1` の一覧から「選択範囲を整形」 | 選んだ範囲の書式を整えます。何も選んでいなければ、キャレットの行を整えます。 |

整えた結果は `Ctrl+Z`（「Vim」モードでは `u`）の 1 回で戻せます。「Vim」モードの INSERT の間は整形しません。

## 言語サーバーが動かないとき

- 言語サーバーが答えない機能では、「この言語サーバーは参照に答えません」のような 1 行のメッセージが出ます。言語サーバーによって、使える機能は違います。
- `F1` の一覧から「言語サーバーの記録を開く」を選ぶと、言語サーバーが出したメッセージを「無題」のタブで見られます。「Vim」モードでは `:LspLog` でも開けます。
- 言語サーバーが何度か続けて起動に失敗したときは止めます。原因を直してから、`:set lsp` で起動し直してください。

## 詳しく知りたい人へ: 設定ファイルに書く

「設定」の「使う」は、設定ファイル `settings.v6`（「インストールと初回起動」の章の終わりを見てください）に次の行を書きます。手で書くこともできます。

```
lsp=on
lsp.cpp.command=C:\llvm\bin\clangd.exe
```

- `lsp=on` は、言語サーバーをオンにする行です。
- `lsp.言語.command=` の後ろに、言語サーバーを起動する命令を書きます。言語の名前は `c`・`cpp`・`python`・`rust`・`go`・`typescript`・`javascript`・`cs` などです。C と C++ を同じ clangd で使うときは、`lsp.c.command=` と `lsp.cpp.command=` の 2 行を書きます。
- 実行ファイルは、ドライブ名から始まるフルパスで書きます。フォルダの名前に空白があるときは、`"` で囲みます。後ろに空白で区切って引数を書けます。
- `.cmd` や `.bat` は使えません。npm でインストールした言語サーバーは、`node.exe` とスクリプトのパスを並べて書きます。
- 手で書くときは、NeNe Nib を閉じてから書いてください。開いている間に書き換えると、NeNe Nib は「別の処理で設定ファイルが変更されました」と出して、そのファイルに上書きしません。
- 書き方を間違えると「設定ファイルの形式が正しくありません」と出て、直すまで設定を保存できなくなります。

「設定」の「言語サーバー」の節に並ぶのは、C / C++・Python・TypeScript / JavaScript・Rust・Go・C#・Lua・シェル・JSON・CSS・HTML・YAML・Dockerfile・PHP・Markdown の言語サーバーです。確かめたのは clangd・rust-analyzer・gopls・pyright です。

言語サーバーは言語ごとに 1 つずつ動き、タブを切り替えても止まりません。同じ命令で動く C と C++、TypeScript と JavaScript は、同じプロジェクトなら 1 つの言語サーバーを共用します。プロジェクトの範囲は、文書のフォルダから上へ `.git` や `Cargo.toml` のような目印のファイルを探して決めます。

名前の変更には、次の制限があります。

- 32 個を超えるファイルにまたがる変更、ファイルを作る・名前を変える・消す変更は行いません。
- 開いていないファイルのうち、BOM なしの UTF-8 でないファイルと、4 MiB を超えるファイルは変えません。
- 言語サーバーがまだ読んでいないファイルの中の名前は変わりません。言語サーバーを起動した直後に名前を変えたときは、「3 個のファイルの 12 か所を変えました」のようなメッセージで、変わったファイルの数を確かめてください。
- 変更が及ぶタブに保存していない変更があり、そのタブの中身を言語サーバーにまだ渡していないときは、名前の変更の全体を行いません。たとえば、言語サーバーが起動する前から開いていたタブや、ほかの言語サーバーが受け持つタブ、まだ一度も表示していないタブです。そのタブを保存してから、もう一度行ってください。
