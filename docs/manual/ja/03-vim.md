# Vim の操作

`Ctrl+Shift+Space` を押すと、NeNe Nib は「Vim」モードに切り替わり、Vim と同じキーで書けます。この章の前半は、Vim を使ったことがない人が最初に覚える操作です。後半は、Vim を知っている人向けに、NeNe Nib で使えるキーと命令を表にまとめます。

> 「Vim」モードに切り替えた直後は NORMAL で、文字を打っても本文に入りません。`i` を押すと INSERT になり、文字が入ります。「通常」モードに戻るときは、もう一度 `Ctrl+Shift+Space` を押します。

## Vim を知らない人の最初の一歩

### モードの考え方

Vim では、同じキーでも、今の状態によって働きが変わります。この状態を Vim では「モード」と呼びます。NeNe Nib の「通常」モード・「Vim」モードと区別するため、この章では NORMAL・INSERT・VISUAL と画面の表記のまま書きます。

状態によって、ステータスバーの表示とキャレット（文字を入れる位置を示す縦線。カーソルとも言います）の形が変わります。

| 状態 | 何をするところか | ステータスバーの表示 | キャレットの形 |
|---|---|---|---|
| NORMAL | キーで移動したり、消す・コピーするなどの命令を出したりします。打った文字は本文に入りません。 | `NORMAL` | 文字を覆う四角 |
| INSERT | 打った文字が本文に入ります。メモ帳と同じように書けます。 | `INSERT` | 縦線 |
| VISUAL | 範囲を選びます。選んだ範囲に命令を出せます。 | `VISUAL`・`VISUAL LINE`・`VISUAL BLOCK` | — |

今の状態は、ステータスバーの左の「通常 | Vim」の右に出ます。迷ったら、まずここを見てください。

- 「Vim」モードに切り替えると、いつも NORMAL から始まります。
- どの状態からでも、`Esc` を押すと NORMAL に戻ります。
- 日本語の入力は、NORMAL では自動でオフになり、INSERT に入るとオンに戻ります。

### 書き始める・NORMAL に戻る

NORMAL で次のキーを押すと INSERT になり、文字を打てるようになります。書き終わったら `Esc` で NORMAL に戻ります。

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| キャレットの前から書く | `i` | キャレットのある文字の前で INSERT になります。 |
| キャレットの後ろから書く | `a` | キャレットのある文字の後ろで INSERT になります。 |
| 下に新しい行を作って書く | `o` | 今の行の下に空の行を作り、そこで INSERT になります。 |
| 上に新しい行を作って書く | `O` | 今の行の上に空の行を作り、そこで INSERT になります。 |
| 行頭・行末から書く | `I`・`A` | 行の最初の文字の前・行末で INSERT になります。 |
| NORMAL に戻る | `Esc` | 書くのをやめて NORMAL に戻ります。 |

### 移動する

NORMAL では、文字のキーでキャレットを移動します。矢印キー・`Home`・`End`・`PgUp`・`PgDn` も使えます。

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 左・下・上・右へ 1 つ移動する | `h`・`j`・`k`・`l` | 左へ 1 文字、下へ 1 行、上へ 1 行、右へ 1 文字移動します。 |
| 次の単語・前の単語へ移動する | `w`・`b` | 次の単語の先頭・前の単語の先頭へ移動します。 |
| 行頭・行末へ移動する | `0`・`$` | 行の最初・行の最後の文字へ移動します。 |
| 文書の先頭・最後の行へ移動する | `gg`・`G` | 文書の最初の行・最後の行へ移動します。 |
| 決まった行へ移動する | `:120` と打って `Enter` | 120 行目へ移動します。 |

キーの前に数字を打つと、その回数だけ繰り返します。たとえば `5j` は 5 行下へ移動します。

### 消す・コピーする・貼り付ける・元に戻す

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 1 文字消す | `x` | キャレットのある文字を消します。 |
| 1 行消す | `dd` | 今の行を消します。消した行は貼り付けに使えます。 |
| 1 行コピーする | `yy` | 今の行をコピーします。 |
| 貼り付ける | `p`・`P` | コピーしたり消したりした文字を、キャレットの後ろ（行なら下）・前（行なら上）に貼ります。 |
| 元に戻す | `u` | 直前の編集を取り消します。 |
| やり直す | `Ctrl+R` | 取り消した編集をもう一度行います。 |
| 同じ編集を繰り返す | `.` | 直前の編集を、キャレットのところでもう一度行います。 |

「Vim」モードでも、右クリックのメニューの「コピー」「貼り付け」は Windows のクリップボードを使うので、ほかのアプリと行き来できます（中では `"+y` `"+p` などの Vim のキーを実行します）。

`dd` で消した文字や `yy` でコピーした文字は、NeNe Nib の中だけで使う場所（Vim ではレジスタと呼びます）に入り、Windows のクリップボードへは入りません。

### 範囲を選ぶ

| やりたいこと | 押すキー | どうなるか |
|---|---|---|
| 文字の範囲を選ぶ | `v` を押してから移動する | VISUAL になり、移動した分だけ選びます。 |
| 行の単位で選ぶ | `V` を押してから移動する | VISUAL LINE になり、行ごと選びます。 |
| 選んだ範囲を消す・コピーする | `d`・`y` | 選んだ範囲を消すかコピーして、NORMAL に戻ります。 |
| 選ぶのをやめる | `Esc` | 選択を解除して NORMAL に戻ります。 |

ダブルクリックで単語を、トリプルクリックで行を選ぶと、VISUAL になります。

### 保存する・閉じる

NORMAL で `:` を打つと、画面の下に命令を打つ行が出ます。命令を打って `Enter` を押すと実行します。

| やりたいこと | 打つ命令 | どうなるか |
|---|---|---|
| 上書きで保存する | `:w` | 今のファイルに上書きします。`Ctrl+S` でも保存できます。 |
| 保存してタブを閉じる | `:wq` | 保存してから、今のタブを閉じます。 |
| タブを閉じる | `:q` | 今のタブを閉じます。保存していない変更があるときは閉じません。 |
| 保存せずにタブを閉じる | `:q!` | 変更を捨てて、今のタブを閉じます。 |
| 命令をやめる | `Esc` | 命令を打つ行を閉じます。 |

### 「通常」モードに戻る

`Esc` を押しても「通常」モードには戻りません。`Esc` で戻るのは NORMAL までです。「通常」モードに戻るときは、どの状態からでも `Ctrl+Shift+Space` を押すか、ステータスバーの左の「通常 | Vim」をクリックします。本文・元に戻すの履歴・キャレットの位置は、そのまま続きます。

### 「通常」モードとキーが違うもの

「Vim」モードでは Vim のキーを優先するので、「通常」モードと働きが違うキーがあります。

| やりたいこと | 「通常」モード | 「Vim」モード |
|---|---|---|
| 保存する | `Ctrl+S` | `Ctrl+S`（同じ）か `:w` |
| 元に戻す・やり直す | `Ctrl+Z`・`Ctrl+Y` | `u`・`Ctrl+R` |
| ファイルを開く | `Ctrl+O` | `Ctrl+Shift+O`（`Ctrl+O` は前にいた位置へ戻る Vim のキー） |
| タブを閉じる | `Ctrl+W` | `Ctrl+F4` か `:q`（`Ctrl+W` は Vim の画面の分割のキー） |
| 新しいタブ | `Ctrl+T`・`Ctrl+N` | `Ctrl+T`（`Ctrl+N` は Vim のキー） |
| ブックマーク | `Ctrl+D` | `Ctrl+Shift+D` |
| 検索・置換・行へ移動 | `Ctrl+F`・`Ctrl+H`・`Ctrl+G` | `/`・`:s`・`:120` など（`Ctrl+F`・`Ctrl+H`・`Ctrl+G` は Vim の働き） |

キーが割り当てられていない操作は、どちらのモードでも `F1` の一覧から使えます。

## Vim を知っている人向けの対応表

ここから先は Vim を使ったことのある人向けです。Vim を知らない人は、前半だけで十分に使えます。

NeNe Nib の Vim の操作は、Vim を組み込んだものではなく、一から作ったものです。本物の Vim 9.1 で同じキーを打った結果と見比べる試験を 6,892 件（このほかに、折り返して表示したときの試験を 402 件）用意して、同じ結果になることを確かめています。

### 移動

| 種類 | キー |
|---|---|
| 文字と行 | `h` `j` `k` `l` `0` `^` `$` `_` `g_` `{N}\|`、`Home` `End` |
| 単語 | `w` `b` `e` `ge` `W` `B` `E` `gE` |
| 行の中の文字へ | `f` `F` `t` `T` `;` `,` |
| 文書と画面 | `gg` `G` `{N}%` `H` `M` `L` |
| 対の括弧 | `%` |
| 段落と文 | `{` `}` `(` `)` |
| 折り返した画面の行 | `gj` `gk` `g0` `g^` `g$` `gm` `gM` |
| スクロール | `Ctrl+D` `Ctrl+U` `Ctrl+F` `Ctrl+B` `Ctrl+E` `Ctrl+Y`、`zt` `zz` `zb` `z<CR>` `z.` `z-` `z+` `z^` |
| 横のスクロール（折り返さないとき） | `zl` `zh` `zL` `zH` `zs` `ze` |

アクセントなどを後ろに付けて書いた文字は、付いた記号ごと 1 文字として移動します。

### オペレーターとテキストオブジェクト

オペレーター（`d` のように、後に続く移動や範囲に対して働く命令）は、移動・テキストオブジェクト（`iw` のように、単語や括弧の中などのまとまりを指す書き方）と組み合わせて使えます。回数は Vim と同じく掛け算になります（`2d3w` は 6 単語）。

| 種類 | キー |
|---|---|
| オペレーター | `d` `c` `y` `>` `<` `g~` `gu` `gU` |
| 行の単位と行末まで | `dd` `cc` `yy` `D` `C` `Y` |
| 1 文字の編集 | `x` `X` `r` `s` `S` `~` |
| 行をつなぐ | `J` `gJ` |
| 貼り付け | `p` `P` |
| 数を増やす・減らす | `Ctrl+A` `Ctrl+X`、VISUAL の `g Ctrl+A` |
| テキストオブジェクト | `iw` `aw` `iW` `aW`、引用符（`i"` `a"` など）、括弧（`i(` `a{` など。`b` `B` も使えます）、`ip` `ap` `is` `as` `it` `at` |
| INSERT に入る | `i` `a` `I` `A` `gI` `o` `O`（回数を付けられます）、`gi` |
| INSERT の中 | `Ctrl+W` `Ctrl+U` `Ctrl+R {レジスタ}`、`Ctrl+O`（NORMAL の命令を 1 つ） |
| 繰り返し・取り消し | `.`（VISUAL でも）、`u`、`Ctrl+R` |

`:set autoindent`（`ai`）を有効にすると、INSERT の `Enter` と `o` `O` `cc` `S` で、今の行の字下げを次の行にも付けます。はじめは無効です。

### VISUAL と矩形

矩形（行をまたいで、同じ桁の範囲を四角く選ぶこと）は `Ctrl+V` で選びます。

| 種類 | キー |
|---|---|
| 選び始める | `v` `V` `Ctrl+V`、前の選択に戻る `gv`、選択の端を替える `o` `O` |
| 選択への命令 | `d` `x` `y` `c` `r` `J` `gJ` `X` `D` `Y` `C` `R` `s` `>` `<` `~` `u` `U` |
| 選択を貼り付けで置き換える | `p` `P`（`P` はレジスタを変えません） |
| 矩形での命令 | `$` `I` `A` `c` `C` `d` `x` `y` `r` `>` `<` `~` `u` `U`、矩形の `p` `P`、`.` |

矩形の `p` `P` で、貼る桁が全角の文字の途中になるときは、その文字を割らずに前を空白で埋めます。

### レジスタとマクロ

| 種類 | キー |
|---|---|
| 無名レジスタ | レジスタを指定しないときに使います |
| 名前付きレジスタ | `"a`〜`"z`、追記は `"A`〜`"Z` |
| 番号付きレジスタ | `"0`〜`"9` |
| 小さな削除・捨てる | `"-`・`"_` |
| Windows のクリップボード | `"+` `"*`、`:set clipboard=unnamed`（無名レジスタをクリップボードと共有します） |
| マクロ | `q{レジスタ}` で記録を始めて `q` で終わる、`@{レジスタ}` `@@`（回数を付けられます） |

マクロを記録している間は、ステータスバーのモードの右に `recording @a` のように出ます。

### 検索と置換

| 種類 | キー・命令 |
|---|---|
| 検索 | `/` `?` `n` `N` `*` `#`、打っている間の `Ctrl+G` `Ctrl+T`、`:noh` |
| 最後の検索で見つかったところを選ぶ | `gn` `gN`（`cgn` と `.` で 1 つずつ変える） |
| 大文字と小文字 | `:set ignorecase`・`:set smartcase` |
| 置換 | `:[範囲]s/探す/置き換え/[フラグ] [回数]` |
| 置換の繰り返し | `:&` `:&&` `:~`、NORMAL の `&` `g&` |
| 行を消す・コピーする | `:[範囲]d` `:[範囲]y` |
| パターンに一致する行・一致しない行 | `:g/探す/d` `:v/探す/d` `:g/探す/s//置き換え/` |

- `hlsearch`（見つかったところに色を付ける）と `incsearch`（打っている間から探す）は、はじめは有効です。
- `:` と検索の行では、`↑` `↓` で前に打った命令や文字を呼び出せます。
- 置換の範囲には `%` `N,M` `.` `$` `'<,'>` `'a,'b` `.,.+N` が、フラグには `g` `i` `I` `n` `e` `&` `c` が使えます。区切りは `/` のほか、英字でない文字なら使えます。
- 置き換えの側では `&` `\0`〜`\9`（`\(` `\)` の群）、`~` `\r` `\u` `\U` `\l` `\L` `\e` が使えます。
- 置換は、1 回の命令が `u` の 1 回で戻ります。
- パターンの書き方の範囲は、章末の「詳しく知りたい人へ」にまとめます。

### マークとジャンプ

| 種類 | キー |
|---|---|
| マークを付ける・戻る | `m{a-z}`、`'{a-z}` `` `{a-z} `` |
| 特別なマーク | `''`（ジャンプの前）・`'.`（最後に変えたところ）・`'^` `` `^ ``（最後に INSERT を出たところ） |
| ジャンプの履歴 | `Ctrl+O` `Ctrl+I` |
| 変更の履歴 | `g;` `g,` |

マークは、上の行を消したり足したりすると、それに合わせて位置が動きます。

### easymotion

NORMAL と VISUAL で `\\`（`\` を 2 回）を押し、続けて次のキーを押すと、画面に見えている行き先の左上に小さな札が出ます。札の文字を打つと、そこへ移動します。`Esc` でやめます。

<!-- 画面: easymotion の札が出ているところの写真（あとで入れる） -->

| 続けて押すキー | 札が出るところ |
|---|---|
| `w`・`b` | キャレットより後ろ・前の単語の先頭 |
| `e` | キャレットより後ろの単語の末尾 |
| `j`・`k` | キャレットより下・上の行の、最初の空白でない文字 |
| `l` | 見えているすべての単語の先頭 |
| `f`・`F`・`s` と 1 文字 | その文字のあるところ（`f` は後ろ、`F` は前、`s` は両方） |

- 単語の区切り方は `w` と同じなので、日本語の文にも札が出ます。
- 移動すると、移動の前の位置が `''` で戻れる位置になります。
- `d\\w` のように、オペレーターの後には使えません。画面を分割しているときは、今の画面だけに札が出ます。

### 使える `:` の命令

| 種類 | 命令 |
|---|---|
| 保存と終了 | `:w` `:w 名前` `:w! 名前` `:saveas 名前` `:saveas! 名前` `:q` `:q!` `:wq` `:x` |
| 行へ移動 | `:{N}` |
| 置換と行の命令 | `:s` `:&` `:&&` `:~` `:d` `:y` `:g` `:v`（上の「検索と置換」） |
| 検索の色を消す | `:noh` |
| キーの割り当て | `:map` `:nmap` `:imap` `:vmap` `:xmap` `:omap`、`noremap` と `unmap` の形、`:let mapleader=` |
| 設定 | `:set`（下の表と「設定」の章） |
| タブ・画面の分割・ファイル | `:tabnext` `:tabprevious` `:tabnew` `:tabclose` `:tabs`、`:only`、`:e` `:b` `:ls`、`:grep`（「ファイルとプロジェクト」の章） |

`:map` で決めた割り当ては、設定ファイルに保存され、次に起動したときも「Vim」モードで使えます。

`:set` は、Vim の短い名前（`hls` `is` `ic` `scs` `rnu` `so` `ws` `cb` `et` `sw` `ts`）と、Vim と同じ書き方（`:set ic scs` のように 1 行に複数・`name?` `noname?` `name&` `name<` `name:val` `+=` `-=` `^=`・`:se` `:setl` `:setg`）を受け付けます。Vim の操作にかかわる主な設定は次のとおりです。

| 設定 | 働き | 既定値 |
|---|---|---|
| `hlsearch`・`incsearch` | 見つかったところに色を付ける・打っている間から探す | 有効 |
| `ignorecase`・`smartcase` | 大文字と小文字を区別しないで探す | 無効 |
| `wrapscan` | 文書の末尾まで探したら先頭に戻って探す | 有効 |
| `relativenumber` | 行番号を、キャレットの行からの距離で表示する | 無効 |
| `scrolloff=` | キャレットの上下に残す行の数 | 0 |
| `autoindent` | 改行で字下げを次の行にも付ける | 無効 |
| `clipboard=unnamed` | 無名レジスタを Windows のクリップボードと共有する | 無効 |

### まだできないこと

次の操作は、今のバージョンではまだできません。

- 大文字のマーク（`'A`〜`'Z`）と `:marks`
- `:sort`、`d` と `s` 以外を使う `:g` `:v`
- 読み出し専用のレジスタ（`".` `":` `"/` `"%`）
- NORMAL の `R` と、VISUAL の `S`
- 「Vim」モードで、マウスのドラッグで VISUAL にすること
- commentary と surround
- `:w` などのファイル名での `%` や `*` の展開

## 詳しく知りたい人へ: Vim との細かい違い

### パターンの書き方

検索と `:s` は、同じパターン（探す文字の書き方）の決まりを使います。`magic` の書き方のうち、次のものが使えます。

- `.` `*` `^` `$` と、文字の集まり `[...]`
- 1 つの文字や群に付く回数 `\+` `\=` `\?` `\{n}` `\{n,}` `\{,m}` `\{n,m}` と、最短の `\{-n,m}`
- 選択 `\|`、群 `\(` `\)` と `\%(` `\)`
- 一致したところの始まりと終わりを置き直す `\zs` `\ze`

次の書き方は、まだ使えません。

- `\v` `\V` `\M` で書き方を切り替えること
- 行をまたぐパターン（`\n` `\_s` `\_.` など）
- パターンの中の後方参照（`\(a\)\1` など）

パターンを広げた結果がとても大きくなるとき（1 文字の繰り返しが 1,024 を超えるなど）は、Vim の E363 と同じメッセージを出して探しません。

### 置換の確認

`c` フラグを付けると、見つかったところごとに `y`（置き換える）・`n`（飛ばす）・`a`（残りを全部置き換える）・`q`（やめる）・`l`（これを置き換えてやめる）で聞きます。`:g` の中の `:s` に `c` フラグを付けると、今は断るメッセージを出して実行しません。打っている間に置換の結果を先に見せる機能はありません。

### 値を変えられない設定

NeNe Nib の字下げは、いつもタブ文字で、幅は 8 です。`:set` で今と同じ値（`noet` `sw=8` `ts=8` `magic`）を置くのは受け付けますが、違う値（`et` `sw=4` `nomagic` など）は断ります。`:set number` と `:set all&` も断ります。断った行は、マクロや `.` の繰り返しの中では、そこで繰り返しを打ち切ります。

### そのほか

- `:set clipboard=unnamed` は、ウィンドウを閉じるまで有効です。設定ファイルには保存しません。
- マクロや `.` の繰り返しで流すキーは、1 回の実行で 100,000 個までです。超えたら残りを捨てて、1 行のメッセージを出します。
- 改行で終わるファイルでは、最後の改行の後ろに空の行があるとは見なしません（Vim の `eol` と同じ数え方です）。`G` や `:$` は、最後の改行のある行へ移動します。保存するときの中身は変わりません。
- INSERT の中で `Ctrl+O` を押して NORMAL の命令を待っている間は、ステータスバーに `(insert)` と出ます。
- Vim のメッセージは、画面の言語にかかわらず英語で出ます。
