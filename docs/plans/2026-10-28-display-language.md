# 表示言語の計画（6 言語・D69）

2026-10-28 / hide の判断「言語は 6 言語目標」/ 設計席（Nibリナ）。前段は #456・ADR 0123（提案・言語は設定に持ち「Windows に合わせる」を明示操作のときに解決する）。本計画は ADR 0123 の形を保ち、文の表と 6 言語の工程を足す。

## 0. 要点

| 問い | 設計席の決め |
|---|---|
| 言語 | 日本語・英語（先）→ 簡体字中国語・韓国語・スペイン語・ドイツ語（後）。閉じた enum `DisplayLanguage` の 6 値 ＋ 設定の希望値「Windows に合わせる」 |
| 文の置き場 | core の表 1 つ `ui_texts`（`UiMessage` の閉じた enum × `DisplayLanguage` → `std::string_view`）。`constexpr` の 2 次元の表で、行が欠けていればコンパイルが落ちる（網羅性）。操作の名前と説明（`operation_texts`）も同じ表に畳む（1 本） |
| 引く所 | 画面の文字を作る所は全部 `ui_text(message, language)` を通す。文字列のリテラルを ui / application / core の描画の道に書かない（CNF-016・planned: `src/**` の日本語のリテラルを conformance が数え、表の外の文を 0 にする） |
| 既定 | 「Windows に合わせる」（`GetUserDefaultUILanguage` を adapter で読み、6 言語に無ければ英語）。解決は起動と `:set language=` のとき（ADR 0123 の決定） |
| 切り替え | `:set language=ja|en|zh|ko|es|de|auto`・`:set language?`・設定モーダル（D68）。即時に反映（frame を作り直す・layout の保持は書式の鍵に言語を含めて捨てる） |
| 幅 | ステータスバーの枠（固定幅）とタブの帯の文字は言語ごとに幅が違う。全言語の全文を DirectWrite で測り、枠に収まることを `nib_window_tests` で確かめる（収まらない文は短い言い回しに直す・ドイツ語が要注意） |
| Vim の文 | Vim の鍵・Ex の命令名・Vim のエラー（`E486: Pattern not found` 等）は Vim と同じ英語のまま（訳さない・学習の連続性） |
| 訳の質 | 日英は設計席が書く。残り 4 言語は設計席の機械の訳で、表の見出しに「機械の訳・レビュー歓迎」と書き、`docs/i18n/REVIEW.md` に未レビューの一覧を置く |

## 3. 速さ

表は `constexpr`・引くのは添字 2 つ。言語の切り替えだけ layout の保持を捨てる。打鍵の道は変えない。
