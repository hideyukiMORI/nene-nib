# 旅のメモ

秋の週末に、海沿いの小さな町を歩いた記録。この文書は NeNe Nib のスクリーンショットのための見本です。

## 一日目

朝早くの電車に乗り、窓の外の田んぼが少しずつ海の景色に変わっていくのを眺めた。駅を出ると潮の香りがして、商店街の入り口では魚屋さんがその日の朝に揚がった魚を並べていた。地図を持たずに路地へ入り、古い木造の家と小さな神社の間を抜けて、気がつくと港の端まで来ていた。

昼は港の食堂で焼き魚の定食を食べた。ご飯のおかわりは自由で、店の人が「今日はアジがいいよ」と教えてくれた。

## 二日目

岬の灯台まで歩いた。片道一時間ほどの道で、途中の坂の上から町の全体が見下ろせた。灯台の下のベンチで、持ってきた本を少しだけ読んだ。風が強く、ページを押さえながら読むことになった。

帰りの電車では、撮った写真を見返しながら次に来る季節のことを考えた。

## 持っていくものの覚え書き

- 歩きやすい靴
- 薄手の上着（海沿いは風が冷たい）
- 小さな水筒
- 文庫本を一冊
