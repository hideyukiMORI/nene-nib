## 実装の要点（差分）

- 速さ: 窓が `timing_.mark(input_received)`（`WM_CHAR` / `WM_KEYDOWN`）と `mark(frame_presented)`（`Present` が返った直後・`draw_frame`）を打つ。`Win32TimingAdapter` は `--measure <out.json>` で `bind` されたときだけ QPC を積み、デストラクタで JSON を書く。`eng/window_driver.py` が `verify-window.py` と `measure-speed.py` の共通の駆動器
- 描画: `send()` は `apply` → `InvalidateRect` → 題名 → 通知。描くのは `WM_PAINT` の `paint()`（`ValidateRect` → `present(controller_.frame())`）。製品側にスリープ・タイマーは無い
- UTF-8 ↔ UTF-16 は `core::to_utf16` / `core::to_utf8`（`Utf16.hpp`）。OS の変換は `Win32CodePageAdapter` の CP932 だけ
- `eng/check.ps1` は CTest の後に Release の `NeNeNib` target を `build-release/` に差分 build して `measure-speed.py --check`
