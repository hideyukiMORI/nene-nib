## 実装の要点（差分）

- 起動（ADR 0013）: `EditorWindow::initialize` は `apply_backdrop` → `ShowWindow` → `mark(window_shown)` → `start_rendering` → `update_title` → `announce`。renderer が無い間の門は `place_caret` / `present` / `resize` / `change_dpi` / `refresh_appearance` に既にある。`measure-speed.py` の `--adopt --bench <name>` は 1 本だけ書く（`adopt_one`）。`verify-window.py` の `verify_first_paint` が起動直後の画素の列を取る（画面中央に他の窓があると測れない）
- IME（ADR 0014・PR #32）: `core::Composition`（`utf8` / `clauses` / `cursor`）と純関数 `composition_underlines`。意図 `ComposeText` / `CommitText` / `CancelComposition`。`EditorState::composition()`・`EditorFrame::composition`（`CompositionView`）と `vim_mode`。窓は `compose_message` で `WM_IME_*` を受け、`follow_ime` が Vim NORMAL で IME を切って INSERT で戻す（控えは `ImeOpenState` の 3 値）。renderer は `draw_composed_line` と `caret_rectangle()`。`eng/window_driver.py` に `send_keys`（前景を取って `SendInput`）
- タブの帯（D16・#31 済み）: `Palette::title_bar`（RgbColor・不透明）。`draw_title_bar` は `fill(band, title_bar)` の 1 行。`TitleBarBackdrop` / `backdrop_` / `set_backdrop` / `fill_translucent` は無い。`apply_backdrop` は `DwmSetWindowAttribute` を 2 本掛けたまま結果を控えない。`verify-window.py` の `TITLE_BAR` / `TAB_ACTIVE` の表と `active_tab_point`
- 計測器（#30 済み）: `keys_trial` → `(single, burst, span, delivered)`、`burst_failure` が理由、`bench_keys` が 3 条件を `BURST_ATTEMPTS` の中で測り直して駄目なら burst は `None`。`summarise(samples, missing)`・`compare` → `(findings, unmeasurable)`・`exit_code` 0/1/2・`MIN_VALID_SAMPLES = 3`。`window_driver.covered_by`。テストは `tests/conformance/test_speed.py`
- 速さの基準値の鍵は 5 つ（`startup-first-frame` / `startup-window-shown` / `key-to-frame-single` / `key-to-frame-burst-200` / `open-large-file-16mib`）。`startup-window-shown` の余裕が狭い（基準 34.9・上限 43.7・忙しい回に 50 ms の試行）

ベンチとゲートは画面中央を空け、**同じ機械で並行の処理をしない**（#32 で設計リナの grep で落ちた。#30 以後は 3 回とも届かなければ欠測・終了 2 になるが、ゲートは落ちる）／`gh pr update-branch` を使わない（merge commit が GIT-003 で落ちる。rebase で追いつかせる）／ブランチ名は GIT-002 の形 `<type>/<issue番号>-<kebab>`（docs でも先に Issue を切る。番号を抜くとローカルのゲートが落ち、PR は head を変えられないので閉じて作り直し。今日の PR #39 → #40）／`build_boards.py` の再生成で帯とタブ以外の差分が出たら生成器のずれ／`verify-window.py` の IME の節は IME の開閉を変えて戻すが、途中で止めると IME が切れたままになる／PR 本文は GIT-004 の形／ADR の番号は受理順（草稿の番号は merge 時にずれうる）／設計の草稿や絵を作業ツリーの未追跡ファイルとして置くと conformance が読む（scratchpad に置く）／長いヒアドキュメントは shell が読めないことがある（文書は Write で）／`--adopt` は全部の鍵を書き直すので、1 本だけ足すときは `--adopt --bench <name>`。
