## 実装の要点

- 5 層: `src/core`（値・piece table・Vim エンジン予定・レイアウトの純関数・配色トークン）→ `src/application`（`EditorState` が本文・選択・履歴・スクロール・モード・外観を所有。`EditorController::apply` が `std::variant` の意図を `std::visit`）→ `src/adapters/win32`（外観・クリップボード。時刻・ファイル・スレッドを持てる唯一の区画）→ `src/ui/win32`（`EditorWindow` はキーとクリックを意図に写すだけ。`Direct2DRenderer::render` だけが描く）→ `src/app`（`wWinMain`）
- 本文は UTF-8。位置は `Offset`（バイト）・`LineNumber`（1 始まり）・`Column`（code point・1 始まり）
- ファイル: `OpenDocument{FilePath}` → `FilePort::read(path, 64 MiB)` → `core::detect_encoding` → BOM 除去か `CodePagePort::to_utf8` → `TextBuffer::from_utf8` → `core::detect_line_ending`。`SaveDocument{path, encoding}` → 符号化 → `FilePort::write`（`.nib-tmp` → `FlushFileBuffers` → `ReplaceFileW` / `MoveFileExW`）→ `EditHistory::sealed()` と `Document::saved_position`。失敗は `DocumentView::last_failure`（次の意図で消える）。ダイアログと確認は ui/win32 の `FileDialog` と `EditorWindow`（`WM_CLOSE` 1 本）。起動引数は `wWinMain` が `CommandLineToArgvW` で最初の描画前に apply
- 窓は `WS_OVERLAPPEDWINDOW` ＋ `WM_NCCALCSIZE` → 0・`WM_NCACTIVATE` → TRUE・`WM_NCPAINT` → 0・`WS_EX_NOREDIRECTIONBITMAP`・`DWMWA_SYSTEMBACKDROP_TYPE` と `DWMWA_USE_IMMERSIVE_DARK_MODE`
- 提示: D3D11 → DXGI composition swap chain（flip・waitable）→ DirectComposition → D2D device context。1 打鍵ごとに vsync を待つ
- 色は `core::Palette` の 16 トークンだけ。ui に色のリテラルを書かない
- Esc は窓を閉じない。終了は閉じるボタンか Alt+F4

## 地雷（CLAUDE.md 第 2 節にもある）

公開 aggregate に `= default` の `operator==` を書かない（非メンバーで）／`reinterpret_cast` は `std::bit_cast` と `ComPtr<IUnknown>`＋`As()`／`.cpp` の無名名前空間の `struct` も 1 ファイル 1 型／`std::optional` は `value()`／core で `std::lround` や `<chrono>` を呼ばない／`-Werror=vla` は C++ では効かない（`-Werror=vla-cxx-extension`）／Ctrl と Shift は `PostMessageW` で駆動できない（`AttachThreadInput` ＋ `SendInput` なら駆動できる）／`MB_OK` の箱は `WM_CLOSE` で閉じる／`EditorController` のコンストラクタはポート 4 本で CPP-012 の上限ちょうど（次にポートが増えるなら束ねる型）／表示値の `last_failure` は最初の描画の意図で消える。
