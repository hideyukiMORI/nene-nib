- 席が `worktree add -B <branch>` で止まるのは、同じ branch を別の worktree が checkout しているとき。席は別の local 名で作って `push origin HEAD:<branch>` で送った（正しい動き）。差し戻しの依頼書には「前の worktree を先に消す」か「別の local 名で」を書く。
