## 直近の変更

Issue #60（C2・ADR 0020）。本文設定の所有者は `EditorState::settings`、controllerの唯一の入口は `EditorPorts`。設定形式/場所/競合検査は adapters/win32、バイト置換は既存 FilePort。`FontSize` は8〜40 pt、DIPと既定比率は名前付き純関数。本文の配置・クリックは4引数の `body_layout` を共用する。

- `settings.v1` は version / colorscheme / font_family / font_size がそれぞれ必須。UTF-8、4096 bytes上限、未知版・欠落・重複・未知キー・不正値は拒否。欠落だけが既定値での正常起動。
- `Win32SettingsAdapter` は最後に読んだ/書いたbytesを控え、lockを共有無しで開き、比較してから書く。読込失敗後は保存を拒否し元ファイルを保つ。外部エディタの比較後の競合は保証外。
- 保存成功後にだけ設定を変更する。設定失敗は文書失敗と別。起動時エラーは VisibleLines 等で消さず、窓が起動時/設定操作時だけ告知する。
- Ctrl+`+` / `-` / `0` と Ctrl+wheel は通常/Vim共通。上限・下限・既定復帰のno-opと保存失敗は表示高通知を送らず、ユーザーのスクロール位置を保つ。
- `EditorFrame` は設定/フォント名を所有する。rendererは描画資源のキャッシュだけを持ち、描画とクリック前に設定へ同期する。OS→テーマは `theme_for` の1経路。
