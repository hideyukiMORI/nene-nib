## 試したこと・失敗・学び

- **操作を足した PR の probe の期待値の漏れ。** #1813 が操作を 5 つ足したのに `tests/performance/OperationChoiceProbe.cpp` の手書きの期待値が前のまま。席も設計席も `nib_probe_expectations` を回しておらず、まとめ枝の全件の検証で落ちた。push 済みのまとめ枝は書き換えず、`b` を積み直した。席の約束に「操作を足したら `ctest -R nib_probe_expectations`」を足した。
- **席が本体の checkout に書いた。** PowerShell の `[IO.File]::WriteAllText` に相対パスを渡し、.NET が本体の cwd で解いた（4 ファイル・席が Edit で戻した・本体は clean を確かめた）。席の約束に名指しで足した。
- **A/B の 1 回目は無効。** `measure-speed.py` は `--record` が要り、`--bench` は 1 本だけ受ける（8 回とも出力なし）。直して 1 回だけ測り直した。
- **独立レビューが安全の穴を見つけた。** リンクの宛先で、実体参照から入る空白と引用符・装置の名前（`COM1:` の `:`）・authority の `%` と `@`・見えない字。2 回のレビューで塞いだ。
- **`--every-scope` は contracts の表と同じ関数の scope を飛ばす。** 足した scope は単独で回す（数が動かない理由）。
- **ゲートの probe の照合の時間。** CPU 100% の間は 74 秒で上限 60 秒の TIMEOUT、静かな機械では 32 秒（上限は変えていない）。
- **まとめ枝の commit の本文に `Closes` の行を入れ忘れた**（設計席・手で `commit-tree` した）。`merge-pr.py` が CI の前に断った（PR #1888）。同じ木のまま本文だけ直した枝で PR #1889 を出し直した（検証とゲートは同じ木の結果を使った）。手で積むときも `stack-shadow.sh` の本文の形（件名・空行・`Closes #N`）を使う。
- **直しの前の木で全件の検証を始めた。** 再確認の必須 2 が出て、ctest の途中で止めた（無効・約 25 分）。再確認が戻ってから検証を始めるほうが安い。止めた検証が残した process は番号で止めた（名前では止めない・施主の Store 版の Nib が同じ名前で動いていた）。
