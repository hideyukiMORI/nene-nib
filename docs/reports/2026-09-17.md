## 施主決定と設計判断

- **oracle の設定に `set backspace=indent,eol,start` を足す**（施主承認「推しで」2026-09-16）。`-u NONE` の Vim は INSERT の Backspace が挿入開始位置より前を消せず、`defaults.vim` を読む「利用者が触る既定の Vim」と違う。`defaults.vim` そのものは読まない（ADR 0012 の決定 8）
- 起動の内訳は**測るだけ**で直さない（Issue #19 の方針どおり）。直す Issue #24 は #22 の後ろに置いた: 起動の残り 160 ms は製品側の仕事ではなくドライバの固定費で、Vim の縦切りでエンジンの形を固めるほうが先
- `VimEffect` は 6 → 8（`VimRemoveLines` / `VimNewLine`）。行削除はキャレットの行き先が違い、改行の形は `line_ending()` が決める。controller に推測させない（実装リナの提案を採用）
- NORMAL のキャレットは鍵のあとだけでなく、クリックと Ctrl+矢印のあとも文字の上へ寄せる（Vim も行末より右のクリックは最後の文字に置く）
- `Direct2DRenderer` に `TimingPort&` をメンバーで持たせず `create` → `initialize` の引数で通す（`std::expected` で返されて move される型に参照メンバーを足さない。実装リナの提案を採用）
- ADR の番号は受理順。Issue #19 の本文で「直すときに 0012」と書いた番号は Vim に使った

## 実測で分かったこと（規則ではなく道具の癖）

起動（`docs/quality/speed-reference.md`「起動の内訳」）:

- 実機（RTX 3090 / 120 DPI・Release）: `origin`（loader・CRT・COM）11.6 ms / 窓 2.8 / Mica 0.6 / **`D3D11CreateDevice` 159.6** / swap chain 1.6 / DirectComposition 0.8 / D2D 0.6 / DirectWrite とフォント集合 0.8 / 最初の layout と `Present` 4.7 ms。CI（WARP）は `device_created` 3.6 ms。**差 156 ms がそのまま実機と CI の差**
- フォント集合・DirectComposition・Mica はどれも 1 ms 未満で、予想の 2 番目以降は全部外れた。16 MiB の読み込みは実機 47.5 ms・CI 60.0 ms（CPU の差）

Vim（`docs/quality/gate-proofs.md` 5-g・ADR 0012「正直に」）。oracle で確かめて実装を Vim 側に合わせた 12 点の主なもの:

- 語の切れ目は文字の種類で決まる（`fwd_word` / `bck_word`）。「あいう、カタ abc」は 4 語、「漢字かな」は 2 語、「ＡＢabc」は 1 語、「a.b,c」は記号も 1 語。既存の `moved_caret`（空白で切る）は通常モード用で変えていない
- `dw` は行末で止まり次の行へ渡らない。最後の語では行末まで消える（`fwd_word` の eol 特例）。`d$` `dl` は inclusive、`dh` `d0` `db` `dw` は exclusive
- `dd` の無名レジスタは「行＋改行」で、削除範囲（最終行なら前の行の末尾から）と別物
- `u` / Ctrl-r のあとのキャレットは「変わったところの先頭」（既存の undo は戻した文字列の後ろ）
- `j` `k` は欲しい列（curswant）で戻り、`$` は「行末」を貼り付ける。回数は失敗ではなく丸め（`5l` は行末）。回数の途中の `0` は桁
- **oracle の限界**: `:normal!` の 1 回はまるごと 1 つの undo の単位（`xxu` は `hello` に戻る）。失敗した鍵のあとの鍵を捨てることがある（`hx`）。CRLF は `fileformat=dos` で CR が落ちる。`&encoding` は `-u NONE` でも `utf-8`（Windows 版 9.1）。Ex モードの開始位置は先頭でないので `call cursor(1,1)` が要る。`writefile` はレジスタの改行を NUL で書く
- `where vim` は Git 同梱の 9.0 を返す。oracle は `C:\Program Files\Vim\vim91\vim.exe` をフルパスで
