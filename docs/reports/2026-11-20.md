## 設計席の決め

- #1894: 本文の行で補間する案は採らない（1 行で書いた長い段落と画像が跳ぶ）。位置は DIP で持ち ui が畳む。下の端は「最後の要素の上端が枠の上端」と「文書の下端が枠の下端」の深い方。
- 囲みのコードの切れは 64 行（32 行は得が小さく layout の保持を早く使う）。
- 巨大な行の窓（ADR 0139 / 0140）は普通の nowrap に広げない（色分け・診断・括弧の対応が消える・第 2 のしきい値になる）。frame の行の使い回しは打鍵の frame に費用が増えるので入れない。
- 本文の行の端数（#1898）: 端数は application の `ScrollState` に 1/120 行の単位。ホイールとタッチパッドは Vim のモードでも端数を許し、Vim の鍵・打鍵・追従の後は行に揃える。段 1 は text 形だけ。動き（animation）は入れない。
- 通常モードの横のホイール（#1901）は D82 の範囲として足す（ADR 0145 の追補・未着手）。
- LSP: `lsp.<name>.command` の name は形だけ厳密に読み、表に無い名前の行は使わず書き戻しで残す（1.1.0 の公開の前に入れる）。`.cmd` `.bat` は起こさず断る。言語サーバーは port 1 本のまま席の番号で 4 本まで・失敗は言語ごと。
