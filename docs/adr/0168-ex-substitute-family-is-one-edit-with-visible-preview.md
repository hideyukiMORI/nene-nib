# ADR 0168 — Ex の `:s` の族は 1 回の `Edit` で、入力中の当たりは見えている行だけの preview

- 状態: 受理（施主決定 D67・FR-027・2026-10-28。実装は 2〜3 席・受理は D41 の形・fixture は oracle で Vim 9.1 と合わせる）
- 日付: 2026-10-28
- Issue: #1007・計画 `docs/plans/2026-10-28-editing-features-roadmap.md` §1 の 9
- 規則: FR-027、ARC-001 / ARC-003 / ARC-004、CPP-002 / CPP-005 / CPP-011 / CPP-012、QLT-014、ADR 0012（oracle）/ 0022（Ex の評価は core の 1 本）/ 0030（`.`）/ 0032（検索の照合器 `VimPattern`・`magic` の部分集合）/ 0041（incsearch の preview は engine の外）/ 0052（undo のキャレット）/ 0057（Ex の失敗の形）/ 0152（`''`）

## 文脈

Nib の Ex は設定・タブ・文書・窓の命令だけで、`:s` が無い（ヴァニラの穴・hide の指摘で一番痛い）。照合器 `VimPattern` は `magic` の部分集合で、群 `\(` `\)` と後方参照は未対応。incsearch は入力中の当たりを engine の外の preview として見せる形（ADR 0041）がある。oracle は `:normal!` に `:s` を流せるので fixture で Vim と合わせられる。

## 決定

1. **受ける形。** `:[range]s/{pat}/{rep}/[flags]`・`:[range]s` と `:&`・`:&&`（直前の置換の繰り返し）・`g&`（全行で `:s//~/&`）・`:[range]g/{pat}/d`・`:[range]g/{pat}/s//{rep}/`・`:[range]v/{pat}/d`・`:[range]sort [i][u][n]`・`:[range]d [x]`・`:[range]y [x]`・`:[range]normal {keys}`（後続）。区切りは `/` のほか `#` `|` `@`（Vim と同じ・`pat` に `/` を含めるため）。`{range}` は `%`・`N`・`N,M`・`.`・`$`・`'<,'>`（VISUAL から `:` で入る）・`'a,'b`・`N;M`（後続）・相対 `+N` `-N`。
2. **flags。** `g`（行の全部）・`i` `I`（大小）・`c`（確認・決定 6）・`n`（数えるだけ・報せ）・`&`（前の flags を保つ）・`e`（当たりが無くてもエラーにしない）。既定は行の最初だけ（`gdefault` は持たない）。
3. **`{rep}` の特殊。** `&`（当たり全体）・`\0`〜`\9`（群）・`~`（前の `{rep}`）・`\n`（NUL → Nib では改行として受けない・限界: Vim の `\n` は NUL）・`\r`（改行を入れる）・`\t`・`\`・`\&`・`\u` `\l` `\U` `\L` `\e` `\E`（大小）。`magic` の既定。
4. **照合器に群を足す（ADR 0032 の範囲の拡張）。** `VimPattern` に `\(` `\)`（最大 9 群・入れ子可）と後方参照 `\1`〜`\9`（照合の中・後続）を足し、`matched` が群の範囲を返す。性質の試験（`--vim-pattern-property`）に群の往復（群の範囲は当たりの中・入れ子の包含）を足す。既存の検索（`/` `?` `*`）の答えは変わらない（契約で固定）。
5. **置換は 1 回の `Edit`。** 範囲の行を順に走り、行ごとに当たりを `{rep}` で置き換えた本文を組み、全体を 1 つの `Edit`（undo 1 単位・`restore` は `:` を打ったときのキャレット・ADR 0052）にする。キャレットは最後に置換した行の最初の非空白（Vim の実測・fixture）。当たりが無ければ `E486: Pattern not found: {pat}`（`e` 無し）。`''` を置く（jump・Vim の `:s` は `''` を置く・fixture で確かめる）。`:g` は 1 回走って該当の行の集合を決め、`d` はその行を 1 つの `Edit` で消す・`s//` は決定 5 の置換を該当の行に。`:sort` は範囲の行を並べ替えた本文を 1 つの `Edit`（`i` は大小を畳む・`u` は重複を消す・`n` は数で・安定・`std::stable_sort` は使わず自前の併合で決定的に）。`:d` `:y` はレジスタ `x`（省けば無名・ADR 0050 の規則で `"1` へ）。
6. **`c`（確認）。** 当たりごとにステータスバーに `replace with {rep} (y/n/a/q/l)?` の問い（Vim の文言のまま英語）を出し、`y`（置く）`n`（飛ばす）`a`（残り全部）`q` / Esc（止める）`l`（置いて止める）。確認の途中はコマンド入力の状態（Vim の鍵は通らない・IME は閉じる）。置いた分は決定 5 と同じ 1 つの `Edit` に畳む（途中で止めても 1 単位）。
7. **入力中の preview。** `:s/pat` を打っている間、見えている行の `pat` の当たりを incsearch と同じ面（`search`）で見せ、`/rep/` まで打てば当たりの右に置換後の本文を薄く（`muted`・engine の外の preview・本文は変えない・Neovim の `inccommand=nosplit` の形）。Esc で消える。preview の計算は見えている行だけ（60 行・D67）。
8. **oracle の fixture。** `ex-substitute-` の接頭辞で Vim 9.1 と合わせる（`:s/a/b/`・`g`・`i`・`%`・`'<,'>`・`&`・`\1`・`~`・`\r`・`\U`・`:g/x/d`・`:v`・`:sort u`・`:2,3d a`・`E486`・キャレットと `''`）。`c` は oracle で測れない（対話）→ 契約。
9. **費用。** 置換は範囲の行数 × 当たりの数に比例（`:%s` の 16 MiB は数百 ms の見込み・1 回の `Edit` なので undo も 1 回・巨大な文書の `:%s` は段 5 の worker の後続）。打鍵の道は変えない（`:` の入力行の中だけ）。preview は見えている行だけ。
10. **限界（後続）。** `:[range]normal`・後方参照の照合（`\1` を `pat` の中で）・`\n` の NUL・`:s` の `p` `#` `l` の表示 flags・`:global` の中の `normal`・`gdefault`・巨大な文書の worker 化。

## 強制

- Ex の評価が core の 1 本（`evaluate_ex`）に載ること・置換が 1 回の `Edit`: **active**（契約）。
- fixture: **active**（oracle・`c` 以外）。
- 群を足した照合器の既存の答えの不変: **active**（fixture 全件 ＋ `--vim-pattern-property`）。
- 8 本の速さ: **active**（QLT-014・打鍵の道は不変）。

## 結果

得られるもの: Vim の置換の日常（`:%s/a/b/g`・`:'<,'>s`・`:g/x/d`・`:sort`）が Vim と同じ答えで動く。入力中に当たりと置換後が見える。
失うもの・残る穴: 巨大な文書の `:%s` は止まる（段 5 まで）。`c` の対話は oracle で測れず契約の値。

## 却下した選択肢

| 選択肢 | 却下の理由 |
|---|---|
| 行ごとに `Edit` を積む | undo が行の数になる。Vim は 1 単位 |
| 外部の正規表現（`std::regex` / PCRE） | `std::regex` は例外と遅さ・PCRE は外部。`VimPattern` に群を足す方が ADR 0032 の 1 本を保つ |
| preview を別の窓（`inccommand=split`） | 2 枠の仕組みと衝突。見えている行の中だけで足りる |
