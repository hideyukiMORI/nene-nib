# ADR 0114 — 折り返した画面行は本文の文字組みを共有して求める

- 状態: 提案（実装・対象検証の完了時に受理を判断）
- 日付: 2026-10-11
- Issue: #410
- 影響: ARC-001/003/004/006/010/011/012、CPP-002/003/004/007/012/014/017/019、QLT-001/012/014、FR-002/003/012/014/015

## 文脈

ADR 0009の最初の編集実装は長行を切り、折り返しを別の描画実装へ送った。現在の`ScrollState`・クリック・本文の矩形は論理行と画面行を同一視している。DirectWriteだけを折り返しに変えるとキャレット・選択・IME・スクロールが異なる位置を扱う。通常モードの本文ドラッグも未接続である。

2026-10-11 hideは、折り返しとカーソル・選択・IME・スクロール、通常モードのドラッグ選択を先に実装し、ベータタグとZIP公開まで進めるよう指示した。split・大容量ファイル・Markdownは後続のまま。

## 方針

1. 本文・undo・選択の正本は`EditorState`のまま。折り返しは表示だけであり、本文に改行を挿入しない。論理行と画面行を型・名前で区別する。スクロール先頭は論理行と、その行内の画面行で表す。タブ切替でもこの組を保持する。
2. 本文の文字組みの所有を`Direct2DRenderer`からui/win32の`BodyTextLayouts`へ一度だけ移す。合成ルートが1個を所有し、applicationへ型のある`TextLayoutPort`、rendererへ同じ具象を明示的に渡す。旧本文layoutキャッシュは同じ変更で削除する。core/applicationはWin32・COMを知らない。UI専用の文字書式・描画先はrendererに残す。
3. ポートは検証済み表示文字列、本文幅・行高・DPI・フォント・折り返し設定を受け、画面行数、文字位置の画面行と横位置、点から文字位置を結果型で返す。製品の正典はDirectWriteの同じlayout。別の文字幅表、文字数だけの折り返し、分割した文字列の再整形を使わない。
4. 折り返しは既定オン。文字クラスタの間で折る`DWRITE_WORD_WRAPPING_CHARACTER`を使い、単語折り返しの`linebreak`とは区別する。本文の行高は既存`BodyLayout`に揃えた一定間隔とし、描画・座標変換は同じ値を使う。折り返し境界のキャレットには前の画面行の末尾／次の画面行の先頭の向きを持たせ、クリック・End・上下移動で位置を失わない。
5. applicationが表示範囲、画面行単位の移動、カーソル追従と選択を決める。窓は本文内の座標と選択の意図を渡す。UI内で文書位置やスクロール状態を補正しない。通常の上下・ページ・Home/Endは表示に従い、Vimの`j/k`と`0/$`は論理行の意味を保つ。画面行へのVim操作は同じ位置解決を使い、対応範囲を検証と利用者文書へ明記する。
6. 全文書の画面行索引は作らない。表示範囲、カーソルを見せる範囲、要求された移動に必要な論理行だけを文字組みする。変更行は全文の文字組みが必要というADR 0069の限界を残す。異常に大きな移動量の加減算と反復には境界を設ける。
7. 保持するのは現在/直前の描画およびその間の入力で必要になった本文資源。キーは完全な表示文字列と全幾何/書式で、古い幅や文字列は再利用しない。行高や幅の変更、字体/DPI、折り返し設定は同じキー/無効化経路で扱う。字体選択と字形の保持はADR 0071/0073の同じ実装を使う。
8. IMEはADR 0014のまま本文の外に持つ。差し込み後の表示文字列をapplicationとrendererが共有し、そのlayoutで節・下線・キャレット・候補位置を求める。選択・検索・制御文字の着色はDirectWriteの複数の行/双方向の矩形をすべて扱い、固定8矩形で切り捨てない。
9. 通常モードのドラッグは押下で既存の選択を置き、捕捉中の移動でanchorを保ってcaretを動かす。Shift押下は既存anchorを保つ。逆方向・折り返し・複数論理行に共通の経路を使う。画面外では窓のタイマー入力からスクロールと選択を継続し、ボタン解放・捕捉喪失・失焦・破棄で終了する。窓に選択範囲の写しを保存しない。
10. 文字組みの失敗は成功した一行として扱わず、型のある失敗を描画/窓へ返す。状態遷移・保存は既存の一経路。本文が必要ない意図の反映にframe全体を追加しない（ADR 0084）。
11. 設定/セッションの変更が必要なら版と旧形式の読み取りを先に記録し、既存ファイルを勝手に書き換えない。ベータ公開は別Issueで配布物・既知の制限・タグ・再取得照合を扱う。品質ゲートの閾値や例外を変更しない。

## 検証

対象は画面行の境界、上下/ページ/行端移動、選択、ドラッグの捕捉、スクロール追従、リサイズ/字体/DPI、タブ切替、本文とIMEの差し込み/確定/取消。純粋な契約とDirectWriteの窓を作らない契約を先に実行する。型/境界を変えた呼出元の検証は具体的な退行の理由をPRへ残す。

実機の画面・IME・性能は他プロジェクトとの並行実行を避け、hideへ条件と所要時間を事前に伝えて調整する。比較条件と回数を事前に固定し、欠測/失敗/全標本を保存する。旧版の折り返しなしと新機能の差は、同じ動作でない部分を明記する。成功済み検証の再実行は関連実装/入力の変更がある場合だけ。

## 却下した選択肢

- rendererだけで折り返してカーソルやスクロールをその場で直す: applicationとUIに状態遷移が分かれる。
- 文字数/推定幅で部分文字列を描き直す: 字体・結合文字・双方向・タブの文字組みと当たり判定が分かれる。
- 毎打鍵で全文書を折り返す: 大容量対応の基盤を壊し、無関係な行の費用が入力へ乗る。
- 折り返し用に別の文書/編集controllerを持つ: 本文/undo/選択の所有が複製される。
