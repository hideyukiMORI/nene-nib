# ADR 0179 — プレビューのタブは窓に 1 つの印で、置き換えは「同じ位置に開いて前の文書を外す」の 1 本

- 状態: 受理（施主決定 D83・2026-11-10 深夜「クリックで開いたタブは Cursor とあわせて」。細部の 4 点（下の「設計席が決めた細部」）は設計席の決めで、試用で直す）
- 日付: 2026-11-11
- Issue: #1397
- 規則: FR-005 / FR-022、ARC-001 / ARC-004 / ARC-005 / ARC-011、CPP-002 / CPP-005 / CPP-011、QLT-014、ADR 0056（タブ・決定 5 開く / 決定 6 閉じる / 決定 9 帯のマウス）/ 0058（最近使った順）/ 0059（復元・`reach_tab`）/ 0060（開く道は `open_document` の 1 本・一覧からは `open_listed`・履歴は閉じたときだけ）/ 0137（タブの名指しは通し番号）/ 0148（split）/ 0162（エクスプローラー・D80 のクリック 1 回）

## 文脈

D80（#1388）でエクスプローラーの面のファイルの行はクリック 1 回で開く。クリックのたびにタブが増えるので、ファイルを順に眺めると帯がタブで埋まる。Cursor / VS Code は、クリック 1 回で開いたタブを「プレビューのタブ」（題名が斜体）にし、次のクリックで同じタブの中身を置き換える。施主決定 D83 はこれに合わせる。

言葉: この ADR の「プレビューのタブ」は帯のタブの種類で、Markdown プレビュー（ADR 0155）とは別のもの。コードの名前は `transient`（仮のタブ）にして、`preview` を型と関数の名前に使わない（`MarkdownPreview` と取り違えない）。

## 決定

1. **印は窓に 1 つ。** `EditorState` に `transient_`（`std::optional<タブの通し番号>`・番号は `autosave_ids()` と同じ通し番号・ADR 0137）を 1 つ足す。帯の位置・パス・題名で名指ししない。プレビューのタブは同時に 1 本まで。
2. **不変条件: プレビューのタブの文書は保存済み。** `save_state_of` が保存済みでなくなった文書は、その意図の終わりまでに固定される（決定 4）。だから置き換えで未保存の本文を失う道は無い。置き換えの関数は、印の文書が保存済みでないときは置き換えず新しいタブを足す（守りの二重化・契約で固定）。同じ意図の中の置き換えは、意図の出口の固定（決定 4-1）より先に走るので、この置き換えの関数の中の守りが不変条件を守る（裏で揃って留めた読み（ADR 0159 の追補 2）は、IME の確定・`:` の入力行の確定・Vim の待ちを終える鍵の同じ意図の中で採られ、INSERT の `map` の待ちは入口の流しが本文を変えてから開く。この 4 つの順・#1427 の L3）。
3. **開き方は閉じた enum `OpenedAs { pinned, transient }`。** `open_listed` に渡す。エクスプローラーの面のクリック 1 回（`ExplorerPointing::released` でファイルを開く道）だけが `transient`、ほか（面のダブルクリックと Enter・Ctrl+P の面・「∨」の一覧）は `pinned`。Ctrl+O・起動引数・ドロップ・`:e` の `accept(OpenDocument)` の道は今までどおり（`pinned` と同じ）。`transient` で開くときの順:
   1. 同じファイルが既に開いている（普通のタブでもプレビューのタブでも）→ そのタブへ切り替えるだけ。印は変えない。
   2. プレビューのタブがあり、別のファイルを指している → **置き換え**: 先に新しいファイルを読む（読めなければ 1 行の知らせで終わり、プレビューのタブは元のまま）。読めたら、新しい文書をプレビューのタブの**帯の位置**に置いてアクティブにし、前の文書を外す。新しい文書は新しい通し番号を持ち、印はその番号に移る。
   3. プレビューのタブが無い → ADR 0056 決定 5 の (b)(c) のとおりに開き（何も書いていない無題ならそのタブ・それ以外はアクティブの右）、開いたタブに印を付ける。
   `pinned` で開くとき、指したファイルがプレビューのタブなら固定する（切り替えて印を消す）。
4. **固定（印を消す）のきっかけ。** どれも印を消すだけで、文書は変えない。
   1. **未保存になった**: 意図の出口の 1 か所（`begin_intent` と対の終わり）で「アクティブなタブが印のタブで、`save_state_of` が保存済みでない」なら印を消す。本文の編集・文字コードと改行の形の変更・undo で保存時点から離れる、の全部がここで拾える。編集の経路ごとに書かない。
   2. **保存した**（Ctrl+S・`:w`・名前を付けて保存）。保存の成功の 1 か所で消す。
   3. **面のダブルクリックと Enter**（決定 3 の `pinned`）。
   4. **題名のダブルクリック**: 新しい意図 `PinTab { std::size_t index }`（使う人の操作・`detail::is_signal` は偽・`keeps_tab_walk` は偽）。ui は帯のタブの上の左のダブルクリックを、切り替えの `SwitchTab` の代わりに `PinTab` の 1 意図として送る。controller は `SwitchTab { index }` と同じ切り替えをして、切り替えが成った（アクティブがそのタブの通し番号になった）ときだけ、そのタブが印のタブなら固定する。位置ではなく通し番号で比べるのは、切り替えがまだ読んでいない読めないタブを帯から外すと位置がずれ、隣のタブを固定してしまうから（#1427 の L1）。明示の「開く」（決定 4-5・3 の `pinned`）が既に開いているタブを指したときも同じ `PinTab` を通す。印のタブでなければ切り替えるだけ。
   5. **明示の「開く」で同じファイルを指した**（Ctrl+P・Ctrl+O・起動引数・ドロップ・`:e`）。
5. **置き換えで外した文書は履歴に書かない。** 履歴 `history.v1` は「閉じたとき」だけ書く（ADR 0060 決定 8）。置き換えは使う人が閉じた操作ではなく、眺めただけのファイルで履歴 100 件を埋めないため、`remember` を呼ばない（クリックの道でファイルに書かない・`verify_quiet_paths` に欄を足す）。プレビューのタブを × や Ctrl+W で閉じたときは普通の閉じる流れ（履歴に書く）。
6. **最近使った順（ADR 0058）。** 置き換えは「外す文書を `TabRecency` から抜き、新しい文書を先頭に置く」。Ctrl+Tab の歩きの途中のクリックは使う人の操作なので、入口の今の規則どおり歩きを終わらせてから処理する。
7. **復元（ADR 0059）と自動退避（ADR 0137）。** `session.v2` の形は変えない。窓を閉じるときプレビューのタブは普通のタブとして覚え、次の起動では普通のタブで戻る（印は覚えない）。プレビューのタブは保存済みなので自動退避の対象にならない（不変条件 2）。置き換えで外した通し番号の台帳の行は、タブを閉じたときと同じ道で消す。
8. **まだ読んでいない文書と切り替え。** プレビューのタブがアクティブでないとき（ほかのタブを見ている間）のクリックも決定 3-2 のとおりで、置き換えた位置のタブへ切り替える。切り替えの入口の規則（先に `reach_tab`）はそのまま。印のタブが `UnloadedDocument` になることは無い（復元は印を覚えない）。
9. **split（ADR 0148）。** 置き換えの結果は「プレビューのタブを閉じて、同じ帯の位置に新しいタブを開いて切り替える」の合成と同じ（もう 1 つの枠が印の文書を見ている場合を含む）。置き換えは `EditorState` の 1 関数で、閉じると開くの既存の関数の合成で書く。違う結果になる場面が見つかったら、実装の席は推測で進めず止まって報告する。
10. **表示。** `DocumentView` に `bool transient` を足し、`EditorFrame.tabs` に載る。renderer は題名を斜体で描く（`tab_format_` の斜体の書式を 1 つ足す・`PaletteRowLayouts` の鍵は書式の同一性を含むので保持は分かれる）。色は変えない。Ctrl+P の `#` の一覧と「∨」の一覧では区別しない。
11. **Vim。** `gt` `gT` `:tabnext` `:tabclose` `:tabs` は印を見ない（`tab_destination` は不変）。Vim の INSERT に入っただけ（本文を変えていない）では固定しない。
12. **LSP（ADR 0160 / 0161）。** 置き換えは閉じると開くの合成なので、`didClose` と `didOpen` は既存の所から出る。新しい通知の口を足さない。

## 設計席が決めた細部（試用で直す）

| 点 | 決め | Cursor / VS Code |
|---|---|---|
| 置き換えた文書を「閉じたファイルの履歴」に入れるか | 入れない（決定 5） | 「最近開いたファイル」には入る |
| 明示の「開く」で同じファイルを指したら固定するか | 固定する（決定 4-5） | Quick Open は固定しない設定が既定の版もある |
| 復元でプレビューの印を覚えるか | 覚えない（決定 7） | 覚える |
| プレビューのタブの位置 | 置き換えは同じ位置・新しく作るときはアクティブの右（決定 3） | 同じ |

## 強制

- 不変条件 2（印の文書は保存済み・置き換えで未保存を失わない）: **active**（#1397。application の契約 `nib_tests --transient-tab`（`tests/unit/TransientTabTests.cpp`・置き換え・固定の 5 つ・既に開いているファイル・保存済みでない印は置き換えない・留めた読みと `map` の待ちの 4 つの順で置き換えない（`verify_held_read_orders` `verify_mapped_click`）・読めないタブを外す切り替えで隣を固定しない（`verify_dropped_pin`）・復元・最近使った順・履歴に書かない）と、固定 seed の性質の試験 `--transient-tab-property`（`tests/unit/TransientTabPropertyTests.cpp`・クリック・ダブルクリック・編集・保存・切り替え・閉じる・undo・題名のダブルクリック・新しいタブ・IME の変換中に裏の読みが揃うクリック（守り B の道）のランダムな列の後、印のタブは高々 1 本で保存済み、かつ帯と本文が「印なしで同じ列を流して置き換えを閉じる＋開くに読み替えた」結果と一致）。どちらも既定実行の契約に載る）。
- 開き方の閉じた enum と意図 `PinTab` の写し漏れ: **active**（#1397。`OpenedAs` は `mark_opened` と `reach_open_tab` の `default` の無い `switch`、`PinTab` は `EditorIntent` の `std::visit` の網羅性で、値が増えるとコンパイルが落ちる・CPP-002）。
- クリックの道でファイルに書かない: **active**（#1397。`verify_quiet_paths` の欄 `verify_quiet_transient_clicks`（`tests/unit/HistoryTests.cpp`）が、クリックで置き換える列の後に履歴の読み書き 0・ファイルの書き込み 0・自動退避に触れない・読みの port は開いたファイルの数だけ、を見る）。
- 8 本の速さに退行なし（1 打鍵の道に足すのは決定 4-1 の比較 1 つ）: **active**（QLT-014）。

## 結果

得られるもの: エクスプローラーでファイルを順に眺めてもタブが増えない。編集か保存かダブルクリックで、そのタブは残る。
失うもの・残る穴: 眺めただけのファイルは履歴に残らない。復元で印は消える。プレビューのタブで読んだ位置（スクロール）は置き換えで失う。split で両方の枠が印の文書を見ている場面は決定 9 の合成に従う。

## 却下した選択肢

| 選択肢 | 却下の理由 |
|---|---|
| 文書の束 `DocumentState` に印を持たせる | 束は不変で脇に置くもの。印は窓に 1 つなので、束ごとに持つと「どれが印か」が 2 か所になる（ARC-001） |
| 帯の位置で印を覚える | 閉じる・足すで位置がずれる。名指しは通し番号（ADR 0137） |
| 編集の経路ごとに固定を書く | 経路が多い（打鍵・貼り付け・Vim・置換・IME）。未保存の判定の 1 か所（`save_state_of`）を意図の出口で読む |
| プレビューのタブの中身だけを差し替える（文書の欄を書き換える） | 開く道が 2 本になる（ARC-001）。「同じ位置に開いて前を外す」なら `open_document` の 1 本のまま |
| 置き換えた文書も履歴に書く | クリックのたびに `history.v1` を「読む → 足す → 書く」ことになる（HDD で 30〜40 ms）。眺めただけのファイルで 100 件が埋まる |
