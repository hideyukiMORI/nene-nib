# ADR 0172 — 起動画面は、何も書いていない無題の文書の本文の面に最近のファイルと入口の操作を出す

- 状態: 受理（施主決定 D70・FR-030・2026-10-28。既定オン。見た目は `docs/design/2026-10-28-settings-and-start-screen.md` の採用（題を出す・フルパス・鍵は 1 列）・実装は 1 席・受理は D41 の形）
- 日付: 2026-10-28
- Issue: #1018
- 規則: FR-030、ARC-001 / ARC-004 / ARC-011、CPP-002 / CPP-005 / CPP-011、QLT-014、ADR 0008（色のトークン）/ 0013（窓を先に見せる起動・最初の frame）/ 0060（履歴を読むのは面を開くときの 1 回・開く道は `open_listed`）/ 0063（ブックマーク）/ 0078（操作の表・F1 の案内 `untouched_untitled`）/ 0150（面の行の保持）/ 0162（ルートを選ぶ）

## 文脈

IDE の「ようこそ」の面。Nib は引数も前回のタブも無い起動で空の無題の文書を出し、F1 の案内（`GuideContext::untouched_untitled`・ADR 0078）を本文に描く。履歴（`history.v1`）は Ctrl+P の面を開くときだけ読む（ADR 0060 の決定 8・起動では読まない）。D67 / D70: 起動の道に分岐を足さない・`startup-first-frame` の基準値を守る。

## 決定

1. **出る条件は F1 の案内と同じ。** `GuideContext::untouched_untitled`（パス無し・本文 0 バイト・履歴 0）のとき、本文の案内の代わりに起動画面を描く（案内の 3 行は起動画面の中の「鍵の案内」の節に畳む・2 つを同時に出さない）。文字を打つ・文書を開く・タブを足すと消える（条件が偽になるだけ・状態を持たない）。`guide=hidden` の設定（D42）のときは起動画面も出さない。
2. **中身は 4 つの節。** (a) 最近使ったファイル（履歴の新しい順・10 件・パスの末尾を「…」で切る）(b) ブックマーク（登録順・10 件）(c) はじめる: 「新しいファイル（そのまま打ち始める）」「ファイルを開く Ctrl+O」「フォルダを開く（ルートを選んでエクスプローラーを出す）」(d) 鍵の案内: Ctrl+P・F1・Ctrl+Shift+E・Ctrl+,（設定）を **1 列**で。題「NeNe Nib」は出す・パスはフル（末尾を「…」）（採用 2026-10-28）。(a)(b) は無ければ節ごと出さない。
3. **履歴は最初の frame の後に 1 回だけ読む。** 起動の道（`window_shown` → 最初の `frame_presented`）は変えない: 最初の frame は (c)(d) だけ（履歴とブックマークは `std::nullopt`）で描き、その直後の `WorkCompleted` の形の合図（既存の worker の仕事として `HistoryPort::read` と `BookmarkPort::read` を 1 回頼む・ADR 0062 の形）で (a)(b) を足して 1 回描き直す。履歴の読みの道は Ctrl+P と同じ読み口（2 本にしない）。`startup-first-frame` と `startup-window-shown` の A/B を PR 本文に（+1% の線・読みは frame の後なので 0 の見込み）。
4. **操作。** 面の行を j / k / ↑ / ↓ で選び Enter・クリックで実行（`open_listed` の 1 本・失敗は 1 行の知らせ・ブックマークの無いファイルは ADR 0063 の規則）。「フォルダを開く」は操作 `choose_explorer_root`（ADR 0162）。文字の鍵は本文へ（打ち始めると消える）。Vim モードでも同じ（NORMAL の j / k は面の選びに使う・ほかの鍵は本文へ・面が消えれば普通の Vim）。IME はそのまま（打てば本文）。
5. **見せ方。** 本文の面の中央寄せの 1 列（幅 480 DIP・窓が狭ければ本文の幅）。節の見出しは `muted`・項目は `text`・選んだ行は `current_line`・鍵は F1 の案内と同じ鍵の枠の描き方（`draw_keycap`）。色のトークンは足さない。行の layout は `PaletteRowLayouts` の保持。見た目の案 `docs/design/2026-10-28-start-screen-look.md`。
6. **契約。** application: `--start-screen`（条件 4 つ・節の有無・10 件・選ぶ鍵・Enter と `open_listed`・消える条件・`guide=hidden`・履歴の読みが最初の frame の後の 1 回だけ（`verify_quiet_paths` の欄）・Vim モードの j / k）。ui: `nib_window_tests` の画素と `eng/verify-window.py --start-screen`。
7. **費用。** 起動の最初の frame は (c)(d) の固定の文字だけ。履歴の読みは frame の後の裏の 1 回。打鍵の道は不変（条件が偽なら何も描かない）。
8. **限界（後続）。** 最近のルート（エクスプローラーのルートの履歴）・ピン留め・画像やロゴ・英語以外の文（ADR 0123 の T3）。

## 強制

- 履歴とブックマークは最初の frame の合図の後の 1 回だけ読み、起動・開く・切り替え・新しいタブ・保存・打鍵の道では読まない: **active**（`verify_quiet_paths` が合図を送ってから port の回数を数える・契約 `--start-screen`・#1442）。
- 起動の道に分岐を足さない（`startup-first-frame` / `startup-window-shown` の A/B・QLT-014）: **未測定**（設計席が段 2 の前後に静かな機械で測る）。
- 開く道が `open_listed` の 1 本: **active**（契約）。
- 描画と窓のクリックの当たりが同じ配置 `core::start_screen_layout` の 1 本を読む（列の幅・中央寄せ・DPI 100 / 150 / 200%・狭い窓・当たりは行の中だけ）: **active**（`nib_tests --start-screen` の配置の契約・#1455・追補 14）。
- 題と見出しの墨・選んだ行の `current_line`・選んでいない行の本文の地・名前と頭を切った場所（列の右の余白の手前で終わる）・「はじめる」の補足は名前のすぐ後ろ・「ファイルを開く」の鍵の枠は右端・ショートカットの鍵の枠は項目の左端・行の文字組みの保持（最初の frame 15 個・読みの後に増えるのは自分の行だけ）: **active**（`nib_window_tests --start-screen`・ダークとライト・#1455）。
- 起動画面が出ている frame で本文とステータスバーの F1 の案内を描かない: **planned**（renderer の `draw` の 1 か所で案内の文脈を `hidden` にする実装はあるが、frame を描いて見る機械の検査は無い）。
- 窓の確かめ `eng/verify-window.py --start-screen`（↓ で選ぶ・行のクリックで実行・Esc・打鍵で消える）: **planned**（節は書いたが、窓を前面に出す道具なので段 2 の席は回していない）。

## 結果

得られるもの: 起動してすぐ、最近のファイルを 2 打鍵で開ける。フォルダを開いてエクスプローラーに入れる。
失うもの・残る穴: F1 の案内 3 行は起動画面の中に移る（空の無題で F1 を押せば操作の一覧は今のまま）。

## 却下した選択肢

| 選択肢 | 却下の理由 |
|---|---|
| 起動時に履歴を同期で読む | `startup-first-frame` が伸びる（D52 の基準値） |
| 専用の「ようこそ」タブ | タブの帯に文書でないものが並ぶ。無題の文書の面で足りる |
| 常に出す設定 | 打ち始めれば消えるので要らない。`guide=hidden` で消せる |

## 追補 2026-11-11（#1018・設計席の決め・試用で直す）

実装の席（段 1）が決定 1〜8 で決まらない 5 つの場面を挙げ、設計席が次のとおり決めた。

1. **タブを足したとき** — 条件は「アクティブな文書が何も書いていない無題」だけで、状態を持たない。新しい無題のタブにも出す。決定 1 の「タブを足すと消える」は「別の文書がアクティブになれば出ない（その文書が条件を満たせば出る）」と読む。
2. **split** — 操作中の枠に描き、鍵もその枠で受ける（今の F1 の案内と同じ）。もう 1 つの枠（受け身の `PaneView`）には描かない。
3. **全面プレビュー** — 全面の間は出さず、鍵は `preview_full_route` のまま。
4. **エクスプローラーに焦点があるとき** — 描いたまま。鍵は面へ行くので起動画面の選びは動かない。選んだ行の塗りは焦点の有無で変えない。
5. **鍵の扱い**:
   - 最初は何も選んでいない。↓ / ↑（Vim の NORMAL では `j` / `k` も）で最初の行 / 最後の行から選び始める。
   - 行を選んでいるときの Enter はその行を実行する（`open_listed` / 操作）。何も選んでいないときの Enter は本文へ行く（通常モードは改行が入って条件が偽になり消える・Vim の NORMAL は今までどおりの `<CR>`）。クリックは選びの有無に依らず押した行を実行する（押した行と離した行が同じとき・ADR 0056 決定 9）。
   - Vim は NORMAL のときだけ出す。INSERT・VISUAL・オペレータ待ち・`:` と検索の入力行・Ctrl+P の面が開いている間は出さない（条件に足す・状態は持たない）。NORMAL へ戻って条件が真なら、また出る（選びは「何も選んでいない」に戻る）。
   - 通常モードは条件が真の間ずっと出す。文字の鍵・貼り付け・IME の確定は本文へ行き、本文が空でなくなれば消える。Esc は選びを外す（何も選んでいなければ何もしない）。
   - 選びの状態（選んだ行の位置）は application の状態に 1 つ（`std::optional`）。条件が偽になったら消す。

段 1 の実装（#1442・core と application と adapter）で決めた細部。どれも上の決めと決定 1〜8 の読みで、6 の知らせの扱い・8 の「新しいファイル」と端で回る選び・9 の Ctrl+, を出さないことは設計席が受けた（2026-11-11・試用で直す）。

6. **出る条件の細部** — guide=hidden・入力行（`:`・検索・Ctrl+P の面）・IME の変換中・録画中（`q{a-z}`・F1 の案内と同じ）・全面プレビューの間は出さない。Vim の NORMAL は「次の鍵を待っていない」（回数・オペレータ・文字待ち・レジスタの選び・`map` の待ちが無い）ときだけ。知らせの 1 行（開けなかったファイルの知らせなど）は条件に入れない（F1 の案内は知らせで隠れるが、起動画面は知らせを出したまま残す）。判定は `EditorController::start_screen_shown` の 1 本。
7. **読みは最初の frame の合図で 1 回** — ui が最初の frame を出した後に送る合図 `FirstFramePresented`（`is_signal`）で、そのとき起動画面が出ていれば `StartListPort::request` を 1 回だけ頼む。adapter はワーカーで Ctrl+P と同じ `HistoryPort::read` と `BookmarkPort::read` を呼び（読み口は 1 本）、結果は `WorkCompleted` の道で採る。引数や前回のタブで起動したときは頼まず、その後に無題のタブを足しても読まない（起動画面は「はじめる」と鍵だけ・決定 3 の「最初の frame の後に 1 回」と ADR 0060 の決定 8 の「新しいタブの道で履歴を読まない」を両方守る）。読みが届いたら行の列が変わるので選びは外す。起動画面の鍵は合図の後だけ受ける（最初の frame の前の鍵は本文へ）。
8. **行の実行** — 最近使ったファイルは `open_listed`（出どころ = 履歴・開けなければ履歴から外し、読んだ列からも外す）、ブックマークは `open_listed`（出どころ = ブックマーク・知らせて残す・ADR 0063）。「ファイルを開く」は操作 `open_file`、「フォルダを開く」は `choose_explorer_root` を `operation_request` で頼む（ui が `run_operation`・ADR 0078 の決定 8）。「新しいファイル（そのまま打ち始める）」は選びを外すだけ。選びは端で反対の端へ回る（Ctrl+P の面の ↑ ↓ と同じ）。クリックは意図 `ChooseStartEntry{index}`。
9. **鍵の節** — Ctrl+P（何でも探す）・F1（操作の一覧）・Ctrl+Shift+E（エクスプローラー）の 3 行を操作の表から引く（`operation_guide_entry`）。決定 2 の Ctrl+,（設定）は、設定画面の操作がまだ操作の表に無いので、表に入ったときに行を足す。
10. **段** — 段 1（#1442・#1018 の前半）は core（`start_entries`・`start_selection_stepped`・`start_key_entries`）・application（条件・選び・鍵の振り分け・行の実行・frame の `start_screen`・契約 `--start-screen`・`verify_quiet_paths` の欄）・adapter（`Win32StartListAdapter`）。ui は合図を送らず frame の `start_screen` も描かないので、段 1 だけでは見た目も鍵も変わらない（今の F1 の案内のまま）。段 2 は ui の描画と hit test と合図の送り・`nib_window_tests` の画素・`eng/verify-window.py --start-screen`。
11. **裏で読む最近のファイル（2026-11-11・レビュー V-1454 の R-1・設計席の決め）** — 履歴から外すのは `forget` の 1 か所で、そこが起動画面の読んだ列（`start_lists_`）からも外す（同期の失敗も裏の読みの失敗も同じ道）。開く道の結果を `run_start_entry` で推し量らない。64 MiB を超えて裏で読んでいる間（無題のまま `readings` に開く要求がある間）は、条件は状態を持たないので起動画面を出し続ける。読めたら文書が替わって消える。その間に別の行を開くと前の読みは取り消される（`open_document` の規則のまま）。
12. **map との順（レビューの軽い 1・設計席の決め: そのまま）** — 起動画面の鍵の振り分けは `map` の表を引く前の生の鍵を見る（Ctrl+P の面と同じ「面の鍵は生の鍵」）。`nnoremap j gj` や `nmap <Down> …` があっても、起動画面が出ている間の `j` `k` `<Down>` `<Up>` は選びになり、`j` `k` で始まる左辺（`nnoremap jj …`）は起動画面の間は届かない。
13. **判定の 1 本（レビューの R-2）** — 「何も書いていない無題」は application の `detail::untouched_untitled` の 1 本で、F1 の案内（`guide_context`）と起動画面（`start_screen_shown`）が同じ述語を呼ぶ。録画中の判定も `recording_name` の 1 つを読む。

## 追補 2026-11-11（段 2・#1455・ui の描画と hit test と合図）

段 2 の席（#1455）が決定 5 の見せ方を次の形にした。採用案（`docs/design/2026-10-28-start-screen-look.md`）に無い寸法は、F1 の案内と Ctrl+P の面の値に合わせて席が決めた（試用で直す）。

14. **配置は core の 1 本** — `core::start_screen_layout(body, dpi, shape, key_width)` が列・題・見出し・選べる行（`StartRowLayout`: 全幅の行・印 ▸ の升・項目。右端の補足の欄は 20 で外した）・鍵の 3 行を物理画素で返し、`core::start_screen_row_at` が点の下の行を返す。renderer の描画と窓のクリック（押した行と離した行が同じときだけ `ChooseStartEntry`・ADR 0056 の決定 9）が同じ 1 本を読む。窓はマウスの動くたびには読まない（押しと離しのときだけ `EditorController::start_screen()` を引く）。節の形は `start_screen_shape(entries, lists_read)`（空の知らせは読み終えて両方空のときだけ）。
15. **凍結した寸法（DIP）** — 列の幅 480（本文の欄の幅 − 32 が狭ければそちら）・列は本文の欄（行番号の右）の中央・本文の上端から題まで 36・題の高さは本文の行の 1.5 倍・題の後 22・節の間 16・見出しの高さ 20 と後 4・行の高さは本文の行の高さ・行の左右の余白 6・印の升 18・印と項目の間 8・鍵の枠の列は測った幅（最小 64）・鍵の枠と説明の間 12。採用案の HTML（`docs/design/2026-10-28-start-screen.html`）の値を 1 DIP = 1 px で写した。
16. **字と色** — 題は UI の字体（Segoe UI Variable Display）で本文の字の 1.5 倍・`muted`。節の見出しと空の知らせは UI の字体 12 DIP・`muted`。項目（パスと「はじめる」の名前）は本文の字体と大きさ・`text`・末尾を文字単位の「…」で切る。選んだ行は列の全幅を `current_line` で塗り、先頭に ▸ を `muted`。「はじめる」の補足は UI の字体 12 DIP の右寄せ・`muted`、「ファイルを開く」の補足は鍵の枠（鍵は操作の表の `open_file`・Vim では Ctrl+Shift+O）。鍵の案内は本文の案内と同じ鍵の枠（面 `panel`・縁 `panel_border`・字 `text`）と説明（UI の字体 13.5 DIP・`muted`）。色のトークンは足していない。枠を描くのは `paint_keycap` の 1 本（本文の案内・Ctrl+P の面の鍵と共用）。（行の字と「はじめる」の補足の置き方は追補 20・21 で改めた: 行の字はエクスプローラーの面の UI の書式、補足は名前のすぐ後ろ、右端は「ファイルを開く」の鍵の枠だけ。）
17. **案内と同時に出さない** — 起動画面のある frame では、renderer が本文とステータスバーの F1 の案内の文脈を `hidden` にして描かず、案内の鍵の幅も測らない（決定 1）。全面プレビューの間は起動画面も出ない（application の条件）。
18. **文字組みの保持** — 行の layout は `PaletteRowLayouts`（上限 128・`StartScreenPainter::retained`）の別の実体に持ち、書式の作り直しと起動画面が消えた frame で捨てる。最初の frame（読みの前）は 15 個（題 1・見出し 2・「はじめる」の名前 3・補足 2・鍵の枠 1・ショートカットの枠 3 と説明 3）と、鍵の枠の列の幅を測る 3 個（`guide_key_width`・鍵が同じなら測り直さない）。今までの F1 の案内（鍵の枠 3・説明 3・注 1・幅を測る 3）より最初の frame で 8 個多い。読みの後はパスの行ごとに名前・場所の全文（幅を測る）・描いた場所の 3 つと「…」1 つ。書式は題の 1 つを本文の書式と一緒に作る（renderer の作成で 1 つ増える・追補の 21）。
19. **合図** — ui は最初の frame の present が返り、節目 `frame_presented` を打った後に `FirstFramePresented` を 1 回だけ送る（`EditorWindow::draw_frame` の成功の後・WARP の覆いの子窓の frame が最初・本物の device の採用と device lost の作り直しの後の frame では送らない）。起動の節目の前の道は変えていない。

## 追補 2026-11-11（段 2 の講評・設計席の決め・試用で直す）

設計席の講評（`/design`・PNG を見て）で、段 2 の見せ方の次の 3 点を改めた。上の 16 の字と補足の置き方はこちらが勝つ。

20. **パスの行は名前と場所** — 採用案の「フルパス（末尾を「…」）」を改める（末尾で切るとファイル名が消える）。最近使ったファイルとブックマークの行は、名前（`tab_title_for`・`text`）と、その右に 12 DIP 空けて場所（`tab_folder_for`・`muted`）。どちらも Ctrl+P の面と同じ core の関数から作る。場所が入り切らなければ**頭側**を「…」で切る（renderer が全文の幅を測り、同じ文字組みの当たりで落とす位置を引く）。名前は切らず、名前だけで入り切らないときだけ名前の末尾を「…」で切って場所は出さない。「はじめる」の補足（そのまま打ち始める・ルートを選んでエクスプローラーを出す）も名前のすぐ後ろに 12 DIP 空けて `muted`。右端に置くのは「ファイルを開く」の鍵の枠だけ。配置の `StartRowLayout` から補足の欄を外し、行は項目の欄 1 つ（名前の幅で決まる横の位置だけを描画が測る・Ctrl+P の面の場所と同じ）。
21. **行の字は UI の字体** — 名前・場所・補足は、エクスプローラーの面の書式（UI の字体・本文の大きさに追従する 12 DIP）を共用する。本文の等幅の書式は使わない。
22. **ショートカットの節** — 見出しを「鍵」から「ショートカット」に。鍵の枠はほかの行の項目と同じ左端に左寄せで揃え、説明は測った鍵の枠の列の右から 12 DIP の後（説明の左端は 3 行で揃う）。
23. **限界（右から左の文字）** — 場所の頭を落とす位置は `HitTestPoint`（見た目の順）で引き、文字列は論理の順で切る。ヘブライ語やアラビア語の段を含む場所では、落とす位置が見た目の境と合わず、残りが欄を超えて尻にも「…」が付くか、短くなることがある（範囲の外は読まず、cluster の境で切るので壊れはしない・後続）。全文の幅を測る文字組みだけは書式の省略の印を外す（8192 物理画素を超える場所でも尻が残る・PR #1459 のレビュー M2 を試験で再現して直した）。

## 追補 2026-11-11（段 2 の再レビュー V-1459b・押しと離し）

24. **押した行は中身で比べる** — 窓は押したときに行の位置と中身（`core::StartPress`: 位置と `StartEntry` の種類と path）を覚え、離したときは同じ位置の今の行の中身が同じときだけ `ChooseStartEntry` を送る（`core::start_pressed` / `core::start_released` の 1 対・ADR 0056 の決定 9）。押してから離すまでに行の列が変わる（履歴の読みが届く・開けなかった行が外れる）と、同じ番号が別の行を指すので実行しない。押しの記憶は、窓の外へ出たとき（`WM_MOUSELEAVE`）・捕まえが変わったとき（`WM_CAPTURECHANGED`）・起動画面が消えたときにも消す（捕まえは取らない）。起動画面の行で始まった押しの列の 2 回目・3 回目（ダブル・トリプルクリック）は本文へ渡さない（1 回目の離しで開いた文書の語を選ばない）。契約は `nib_tests --start-screen` の反例 2 件（押したまま読みが届く・押したまま 1 つ上の行が外れる）で、送った意図と窓と同じ配置の関数だけで書く。

## 追補 2026-11-11（#1480・施主の試用・案 B・設計席の決め）

施主の試用で、前回のタブが戻る起動では起動画面が出ず、その後に Ctrl+T で開いた無題のタブには「はじめる」と鍵だけが出て、最近使ったファイルとブックマークの一覧をほぼ見ないことが分かった。施主の決定（案 B）: 無題のタブにも一覧を出す。上の決定 3 と追補 7 の「最初の frame の合図の時点で 1 回だけ・後で無題のタブを足しても読まない」を次で改める。

25. **読みは起動画面が出るたびに（前の読みから書いたときだけ）** — 読みを頼むのは意図の出口（`EditorController::settle_start_screen`）の 1 か所で、起動画面が「出ていない → 出ている」に変わったときだけ（`NewTab`・最後のファイルを閉じて無題が残った・無題のタブへ切り替えた・入力行や面や INSERT を閉じて出直した）。最初の frame の合図（`FirstFramePresented`）の前は「出ていない」に数えるので、起動のときは今までどおり最初の frame の合図の意図の出口で頼み、最初の frame までにファイルに触れない（ADR 0013 / 決定 3 の趣旨のまま）。さらに次の 2 つを両方満たすときだけ頼む。
    - **前の読みの後に履歴かブックマークを書いた** — 印 `start_lists_stale_` を application に 1 つ持ち、最初は立てておく。立てるのは履歴を書く `remember`（タブを閉じた・窓を閉じた）と `forget`（開けなかった行を外した）と、ブックマークを書く `ToggleBookmark` の成功の 3 か所（`mark_start_lists_stale`）。頼むときに倒す。**選んだ理由**: 切り替えで無題のタブへ戻るたびに読むと、何も変わっていない読みが worker に積まれる（Ctrl+Tab で無題を行き来するだけで毎回 2 ファイルを読む）。書いた所は 3 か所しか無く、変わっていなければ読まない形のほうが静かな道の契約も単純に保てる。ほかの窓が書いた履歴は、この窓が次に書くか起動し直すまで見えない（今までと同じ限界）。
    - **読みが走っていない** — 頼んだ読みが届くまでは 1 本（`start_lists_reading_`）。走っている間に出直しても重ねて頼まない。走っている間に書いたら印が立ったまま残り、届いた後の次の出直しで読み直す。
    届いた一覧は次に届くまで持ち、出直したときは**前の一覧を見せたまま**裏で読み直す（一覧が毎回消えて下の節が上下に動かない）。届いた一覧が前と同じ（最近とブックマークの列が等しい）なら何も変えず選びも保つ。違えば差し替えて選びを「何も選んでいない」に戻す（追補 7 の規則）。押しの覚えは中身が同じ行だけ実行する追補 24 の規則のままで守られる（契約 `verify_press_across_reread`）。`StartListPort` の口（`request` / `collect`）と worker の 1 本・`WorkCompleted` の道で `collect_start_lists` が引く形は変えない（引くのは読みが走っている間だけ）。起動・開く・切り替え・保存・打鍵の道は、起動画面が出直さない限り port を呼ばない（`verify_quiet_paths`）。
26. **上下も中央に寄せる（施主の要望）** — ブロック全体（題・最近使ったファイル・ブックマーク・空の知らせ・はじめる・ショートカット）の高さを測り、本文の欄（行番号の右・本文の上端から帯の下端まで）の上下の中央に置く。上の余白は `max(36 DIP, (欄の高さ − ブロックの高さ) / 2)`（整数の割り算）。ブロックが欄より高いときは今と同じ上から 36 DIP（下は帯で切れる）。規則は `core::start_screen_layout` の 1 本で、描画と窓の当たりが同じ配置を引く。一覧が届いて行が増えるとブロックが高くなって全体が上下に動く（施主は「下が動くのは気にならない」）。25 で前の一覧を見せたまま読み直すので、2 回目以降の読みで中身が同じなら動かない（契約）。
27. **「はじめる」の行の鍵は操作の表から** — 「新しいファイル」（`new_tab`・どちらのモードも表の最初の行の Ctrl+T・通常モードの Ctrl+N は出さない）・「ファイルを開く」（`open_file`・Vim では Ctrl+Shift+O）・「フォルダを開く」（`choose_explorer_root`）の鍵は、renderer が `operation_guide_entry`（`shown_chord` の今のモードで最初に当たる行・`key_chord_label`）で引いて `StartScreenText` に渡す。鍵があれば行の右端に鍵の枠を描き、名前と補足は枠の 12 DIP 手前までの欄に書く（今の「ファイルを開く」の並び）。鍵が無ければ（今の `choose_explorer_root`）補足だけで枠は描かない。文字列を別に書かない。「フォルダを開く」の鍵は施主に確認中で、決まったら `operation_bindings` に 1 行足せば出る。

強制（25〜27）:

- 起動画面が出るたびの読み（出ていない → 出ている・前の読みから書いたときだけ・走っている間は 1 本・前の一覧を見せたまま・同じなら選びを保つ・違えば外す）: **active**（`nib_tests --start-screen` の `verify_tabs_and_quiet_start`・`verify_reads_on_show`・`verify_press_across_reread`、`verify_quiet_paths` の欄・#1480）。
- 上下の中央（足りるとき上下の余白の差 1 px 以内・足りないとき上から 36 DIP・ちょうど・行 0 / 10 / 20・DPI 96 / 120 / 144 / 192・押せる行は描く行と同じ矩形）: **active**（`nib_tests --start-screen` の `verify_centered`・#1480）。
- 「はじめる」の行の鍵の枠（鍵がある行は右端に `panel` の枠・名前と補足は枠の手前）: **active**（`nib_window_tests --start-screen`・#1480）。

追補 25 の細部（#1495・レビュー V-1486 の L3）: 読みが走っている間に前の一覧の行を開けずに外した（`forget`）path は、application が届くまで覚え（`start_forgotten_`・頼むときに空にする）、届いた一覧からも外す（古い読みで外した行が戻らない）。外すのは `drop_start_entry` の 1 か所。「フォルダを開く」の鍵は Ctrl+Shift+R に決まった（ADR 0162 の追補 #1495）。契約: `nib_tests --start-screen` の `verify_forget_during_reread`・`verify_press_across_read_centered`（製品の中央寄せの形）・`verify_vim_insert_cycles`・`verify_folder_row_key`、`verify_quiet_paths` の `verify_quiet_after_start_lists`（読みを届けてから静かな道）。
