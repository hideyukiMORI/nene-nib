# ADR 0064 — Ex のファイル命令は共通の一覧を開く

- 状態: 受理
- 日付: 2026-10-03
- Issue: #280
- 影響する規則: FR-003 / FR-006 / ARC-001 / ARC-003 / ARC-004 / ARC-010 / ARC-012 / CPP-002 / CPP-004 / CPP-011 / CPP-012 / QLT-001 / QLT-012 / QLT-013

## 文脈

D5・D28 と FR-006 は Vim の `:e` `:b` `:ls` も Ctrl+P と同じ一覧に統合すると定めた。履歴・同じフォルダ・ブックマークは #278 までで接続済み。最後の入口を足すときに、Ex 専用の候補列・照合・ファイルを開く処理を作らない。
引数の扱いは既存仕様の「同じ一覧」に沿い、検索文字として渡す。2026-10-03 に hide へ選好を確認したが、回答前にこの仕様解釈で進めたもので、新しい施主決定 D 番号にはしない。

## 決定

1. **入口だけを足す**。`:e` / `:edit` は全ファイル、`:b` / `:buffer` と `:ls` / `:files` / `:buffers` はタブの一覧を開く。引数は前後の半角空白を除いて検索欄へ渡し、Enter で候補を確定する。数字も名前の検索文字であり、直接のタブ番号ではない。引数なしのタブ一覧は現在のタブを選択、ほかは先頭を選択する。
2. **省略の表は core の 1 か所**。`edit` は `e` から、`buffer` は `b` からの前方一致。`ls`・`files`・`buffers` は完全一致だけ。`file` / `fi` は Vim の別命令なので受けない。Vim 9.1 の固定した実行ファイルによる非対話 probe（`out/probes/ex-files-2026-10-03.json`）で確認した。`!`・先頭の数値範囲・空白を挟まない引数・`+cmd` は `Not supported: <入力>`。既存の単一行・UTF-8・256 bytes・`|` 拒否を共用する。
3. **評価器が要求を返す**。`ExResult.palette` は `ExPaletteRequest`（`PaletteScope` と所有する検索文字列）。core は OS に触れない。controller が `run_palette_request` で既存の `open_palette` に写す。ファイルは候補を確定するまで読まず、確定は `open_listed` → `open_document` の既存経路。未保存文書を再読込しない。
4. **記号の逆変換も同じ表**。出どころと検索文字から入力を作る `palette_input_for` は `palette_marks` を逆引きする。全ファイルで検索文字の先頭が記号なら半角空白を前置し、記号を検索文字として扱う。空白は既存の照合器が無視する。タブの `#` を別の表へ複製しない。`OpenTabList` もこの変換を使う。
5. **既存の面の動作を継承**。日本語入力、IME をオフで開くことと閉じた後の復元、裏のフォルダ列挙、候補の重複除去、ブックマークと履歴、Escape、消えたファイルの通知、同じファイルの既存タブへの切替は共通の経路。Ex の補完と Ctrl+P の設定候補には完全な命令名を加える。
6. **Vim との意図した差**。Vim の `:e` の再読込、引数による即時 open / buffer 切替、ファイル名の展開、bang・range・`+cmd` は実装しない。FR-006 の一覧を開く意味が優先する。候補にないファイルの作成・任意パスを直接開く機能は本件に含めない。

## 強制と検証

自動検証は **active**（2026-10-03、[gate-proofs 5-ce](../quality/gate-proofs.md#5-ce--exから共通のファイル一覧issue-280adr-0064)）。新規 `--ex-files` で省略と拒否、検索文字、記号の保持、一覧の出どころと選択、確定時だけ読むこと、本文・undo・レジスタの維持を検証する。共有評価器は `--ex-settings`、既存タブの一覧は `--tabs`、共有入力と照合は `--command-palette`。Debug の必要 target と整形・conformance・symbols・protected-diff を確認した。
Release の実機確認は exe と限定した手順を用意してから hide の了承を得る。候補生成・照合器・描画を変えなければ #278 の対象性能測定を再利用し、全件を回さない。

## 結果

Vim の入口でも同じ面でファイルを選べる。直接開く Vim の引数の意味は持たず、互換範囲は一覧を開くことと省略名に限定する。保存形式・port・スレッド・OS 側の入力経路は増えない。
