# ADR 0063 — ブックマークは明示操作で保存し、同じファイルの候補を一覧で共有する

## 文脈

Ctrl+Pの同じフォルダまでがmainに入り、明示的に登録したファイルへ戻る道が残っている。FR-010のCtrl+Dは、FR-003のVimの半画面移動と競合する。2026-10-03にhideへこの競合と、消えた登録の扱いを確認した。

| 決定 | 内容 |
| --- | --- |
| D36 | 通常モードはCtrl+D、VimモードはCtrl+Shift+Dでブックマークを付け外しする。VimのCtrl+Dは従来の動作を維持する |
| D37 | ブックマークしたファイルが消えたり移動したりして開けなくても登録を残し、1行で知らせる。履歴の自動除去と混同しない |

登録を残すには、開けないファイルも一覧から手動で外せる必要がある。また、開いているブックマークが `*` から消えると「登録してあるファイルを探す」という意味が崩れる。全体一覧の重複を避けながら両方を満たす。

## 決定

1. **値と更新はapplication**。`FileBookmarks` は登録順の `FilePath` の列。登録の有無は `bookmarks_contain`、付け外しは `bookmarks_toggled` の1本で決め、比較は既存の `FilePort::same_file`。新規は末尾、解除は同じファイルの綴りをすべて外す。開いた順で動かさない。1024件を上限とし、満杯なら新規登録を拒否して古い登録を消さない。無題は登録しない。登録するのは名前のある文書のパスで、本文に未保存の変更があっても登録できる。
2. **保存の口は `BookmarkPort`**。`read` と `write` は `std::expected` と閉じた `FileBookmarksFailure` で返す。実体は `Win32BookmarkAdapter`。履歴は失敗を黙って捨てるが、明示操作のブックマークは失敗を1行で知らせる。読めない登録を空として上書きしない。
3. **読む時機は面を開くときと付け外しの直前だけ**。付け外しは最新をread→純関数で変更→writeし、保存できたときだけ成功を知らせる。起動・文書を開く・保存・切り替え・本文の打鍵・終了にはI/Oを足さない。複数窓での逐次操作は最新を読んで保つ。完全同時のread-modify-writeの直列化は今回の範囲外で、キャッシュや別の書き手は作らない。
4. **保存形式はadaptersに閉じる**。`%LOCALAPPDATA%/NeNeNib/bookmarks.v1`、UTF-8、`version=1` と1行1絶対パス。書くのはLF、読むのはBOM・CRLFも受ける。1MiB・1024行まで。版違い・壊れたUTF-8・空行・相対パス・制御文字・上限超過は全体を拒否する。ファイルなしだけ空。既存の `text_lines`・`FilePath::parse`・`rooted_path_text` を使い、原子的な保存は既存の `FilePort::write` の1本。設定・履歴・前回タブの版は変えない。
5. **1つの候補に1つのファイル**。列はタブ（帯の順）→閉じているブックマーク（登録順）→履歴（新しい順）→同じフォルダ（届いた順）。履歴はタブとブックマークとの重なりを除き、同じフォルダの除外対象にもブックマークを含める。名前と場所の表示・照合は既存の経路。
6. **登録済みのタブを閉じた状態として表さない**。`PaletteOrigin` に `bookmark` と `bookmarked_tab`、`PaletteScope` と `palette_marks` に `bookmarks` / `*` を足す。`bookmarked_tab` は `#` と `*` の両方に入る。列にはタブの1行だけ。補足は「ブックマーク」「タブ・ブックマーク」。boolの組や第2の候補列を持たず、閉じたenumの分岐で守る。
7. **名前のあるタブもopenの候補へ揃える**。`CommandChoice` の `command` は、名前のあるタブ・ブックマーク・履歴・同じフォルダのいずれも検証済みパスの文字列で、`kind` は `open`。確定は既存の `open_listed`→`open_document`（開いていればそのタブへの切り替え）の1本。無題のタブだけ、既存の `execute` / `tabnext N` のまま。ADR 0060の決定6・7のタブの候補について、この点だけを置き換える。パスを別欄へ重ねて持たず、解除のためにExの文字列を解析する道も作らない。
8. **付け外しの意図は `ToggleBookmark`**。本文では今見ている文書、Ctrl+Pでは選んでいる `open` 候補のパスを対象にする。成功したら面を閉じて「ブックマークに追加しました」または「ブックマークを解除しました」と知らせる。候補を開いたりタブを切り替えたりしない。失敗したら面と入力・選択は残す。設定の候補・Ex・検索入力・IME変換中は付け外ししない。無題は保存してから登録するよう知らせる。次の通常の意図で知らせが消えるのは既存の規則のまま。
9. **キーは1つの純関数で決める**。coreの `BookmarkKey` と `toggles_bookmark` がD36の対応を持ち、Win32はCtrl・Shift・AltとDをその値へ写して意図を送る。Altを含む鍵は奪わない。キーを押し続けた自動反復では付け外しを繰り返さない。Vimの鍵列やマクロへブックマーク操作を混ぜず、本文・undo・Vimの待ち状態を変えない。
10. **消えた登録は残す（D37）**。開く失敗は `open_listed` の1行の知らせ。`not_found`で履歴を除く既存条件は `origin == history` だけのままなので、ブックマークを自動削除しない。`*`で選んで同じキーを押せば、ファイルを開かずに解除できる。
11. **道具のprofileを隔離する**。`eng/window_driver.py` の起動前の初期化は専用profileの `bookmarks.v1` も消す。本物のLOCALAPPDATAでは消さない。再起動の持続を確認するときは既存の `keep_session=True` を使って専用profileを維持する。
12. **範囲外**。タスクバーのジャンプリスト（FR-010後半）、別名・分類・並べ替えUI、フォルダ登録、名前の変更や移動の追跡、Vimのマーク、`:e :b :ls`、パスの表記差を正規化する変更。

## 強制と検証

2026-10-03の対象実行で、以下の自動検証は **active**。記録は [gate-proofs 5-cd](../quality/gate-proofs.md#5-cd--明示ブックマークとctrlpの共有候補issue-278adr-0063)。実機の鍵・表示・再起動と、5000候補の絞り込みもhideの了承後に成功した。

- 新規 `--bookmarks` の契約: 更新と上限、キーの対応、I/Oの時機、保存失敗、読込失敗の保護、本文とVim状態の維持、選択候補の付け外し、消えた登録の保持、登録済みタブの `#` / `*`、各出どころの重複。
- `nib_bookmarks`: codecの正例・反例と、専用ディレクトリの本物のadapterで往復・再作成・壊れた入力・保存失敗。
- 直接変わる `--command-palette` / `--tabs` / `--history` / `--background-work`: 名前ありのタブの確定経路、履歴とフォルダの候補、選択維持、静かな経路。
- Debugの必要なtarget（clang-tidy / ASan / UBSan）、変更ファイルの整形、conformance、core/applicationのsymbols。fixture等はprotected-diffの静的比較。全件のVim再生は選ばない。
- 道具のprofile初期化の対象試験（2 tests）。
- 実機はhideの了承後にキー・登録・再起動・一覧解除・失敗を限定確認済み（11枚）。絞り込みの分岐が変わるため `key-to-frame-palette-5000` を対象指定で測り、既存の基準値へ比較して退行なし（5有効試行・中央値2.708ms）。起動・本文の編集はI/O回数と不変の経路で確認し、全性能ベンチを繰り返さない。

## 残る制約

`same_file`の比較は既存どおりで、区切り文字の混在を同一視しない。ブックマークは面を開くときに読むため、ほかの窓の変更が開いている面へ自動反映されることはない。完全同時の変更は競合し得る。保存場所が使えないときは明示操作を拒否し、原子的な書込の既存経路が元のファイルを守る。登録解除後に履歴や同じフォルダとして出ることは正常で、`*`からだけ外れる。
